广东工艺流程题通用框架

广东考情：高频(近5年固定第18题)·压轴·广东特色工艺流程通用解题框架·真题锚定：2021广东选择性考试T18（废催化剂回收Al/Mo/Ni，绿色冶金情境）

核心内容

一、题型识别标志

看到"矿石/废催化剂/海水/稀土 → 酸浸/碱浸 → 除杂 → 沉淀/电解 → 产品"的箭头流程图 → 立刻识别为工艺流程题。

题干关键特征识别为首选切入
"焙烧/煅烧/酸浸/碱浸"原料预处理写出溶解反应，关注价态变化
"调pH除杂/沉X"沉淀分离用Ksp与沉淀pH判断
"加入氧化剂/还原剂目的"氧化还原把某元素氧化/还原到指定价态
"电解/电沉积"电化学分离电极反应 + 电子守恒
"循环物质/滤液回用"流程优化找可重复利用的试剂

二、通用解题框架（四步通法）

Step 1：读题干 → 锁定最终产品、原料成分、目标元素（常是金属）
Step 2：析流程 → 每一步"进什么 → 发生什么反应 → 出什么"
Step 3：想原理 → 速率 / 平衡 / 沉淀(Ksp) / 氧化还原 / 电化学
Step 4：答问题 → 用化学术语，分点规范表述（目的/原因/方程式/计算）

三、流程核心反应类型速查

类型常见考法关键判断
溶解酸浸/碱浸金属氧化物+酸→盐；两性氧化物+碱→盐
氧化还原加氧化剂除Fe²⁺强制弱、价态规律
调节pH沉淀除Fe³⁺/Al³⁺Ksp + 离子浓度<10⁻⁵视为完全
沉淀转化BaMoO₄ vs BaCO₃Ksp小的优先沉淀，需算共存条件
电解电沉积金属阴极还原，电子守恒

四、答题规范模板

问题类型答题模板
为什么粉碎？增大接触面积，加快反应速率，提高浸取率
为什么加H₂O₂？将Fe²⁺氧化为Fe³⁺便于沉淀除去，且产物为水不引入新杂质
为什么调pH到X？使杂质离子完全沉淀，而目标离子仍留在溶液中
用XX调pH？消耗H⁺且不引入新杂质（如CuO反应生成目标离子Cu²⁺）

五、真题母题（2021 广东选择性考试·第18题，节选）

广东卷以"废催化剂(含Al、Mo、Ni氧化物)回收"考查流程中的沉淀分离与Ksp控制。

已知：25℃时 Ksp(BaMoO₄)=3.5×10⁻⁸，Ksp(BaCO₃)=2.6×10⁻⁹；H₂CO₃的 Ka₂=4.7×10⁻¹¹；pH>6.0时Mo以MoO₄²⁻存在。

(3)"沉钼"中pH=7.0。②若控制不当BaCO₃也会沉淀。为避免BaMoO₄中混入BaCO₃，溶液中 c(HCO₃⁻):c(MoO₄²⁻)= ______（列出算式）时，应停止加入BaCl₂溶液。

解：

  • 刚析出BaMoO₄时：c(Ba²⁺)=Ksp(BaMoO₄)/c(MoO₄²⁻)
  • 不析出BaCO₃需：c(Ba²⁺)·c(CO₃²⁻) ≤ Ksp(BaCO₃)

    • → c(CO₃²⁻) ≤ Ksp(BaCO₃)·c(MoO₄²⁻)/Ksp(BaMoO₄)

  • 由 Ka₂=c(CO₃²⁻)·c(H⁺)/c(HCO₃⁻)，pH=7.0时 c(H⁺)=10⁻⁷

    • → c(HCO₃⁻)/c(MoO₄²⁻) ≤ Ksp(BaCO₃)·c(H⁺) / [Ksp(BaMoO₄)·Ka₂]

答：$\dfrac{2.6\times10^{-9}\times10^{-7}}{3.5\times10^{-8}\times4.7\times10^{-11}}$ （与官方答案一致）

💡 技巧：沉钼与沉碳酸钡是"Ksp竞争沉淀"，停止加BaCl₂的临界条件 = 两沉淀刚共存；先不急于代数字，先把不等式列对。

第1题（检验：氧化剂选择 + "不引入新杂质"原则） 某工艺浸取液含 $\mathrm{Fe^{2+}}$、$\mathrm{Cu^{2+}}$，需除杂 Fe。① 说明为何选择 $\mathrm{H_2O_2}$ 作氧化剂而不用 $\mathrm{KMnO_4}$；② 除杂时用 CuO 调 pH 而不用 NaOH，说明原因。

第2题（检验：Ksp竞争沉淀 + 临界算式） 已知 $K_{sp}(\mathrm{BaMoO_4})=3.5\times10^{-8}$，$K_{sp}(\mathrm{BaCO_3})=2.6\times10^{-9}$，$\mathrm{H_2CO_3}$ 的 $K_{a2}=4.7\times10^{-11}$。沉钼时 pH = 7.0，为避免 $\mathrm{BaCO_3}$ 与 $\mathrm{BaMoO_4}$ 共沉淀，求 $c(\mathrm{HCO_3^-})/c(\mathrm{MoO_4^{2-}})$ 的临界值（列出算式即可）。

参考答案

答案与题目分板块呈现，便于"先做后对"。每题给出规范解答 + 易错提醒，做完一题对一题。

▶ 第1题详解（氧化剂选择 + 不引入杂质原则）

① 选 $\mathrm{H_2O_2}$ 而非 $\mathrm{KMnO_4}$ 的原因：$\mathrm{H_2O_2}$ 还原产物为 $\mathrm{H_2O}$，不引入新杂质；$\mathrm{KMnO_4}$ 还原后生成 $\mathrm{Mn^{2+}}$，引入新杂质离子，需额外除杂。此外，$\mathrm{H_2O_2}$ 用量易控制、符合绿色化学理念。

② 用 CuO 调 pH 而不用 NaOH：CuO 消耗 $\mathrm{H^+}$ 使 pH 升高，反应产物 $\mathrm{Cu^{2+}}$ 即目标离子（不引入新杂质）；NaOH 会引入 $\mathrm{Na^+}$，污染产品。

易错提醒：试剂选择三原则——① 不引入新杂质；② 反应条件温和、易控制；③ 符合绿色化学（廉价、无毒、无有害副产物）。

▶ 第2题详解（Ksp竞争沉淀临界算式）

刚析出 $\mathrm{BaMoO_4}$ 时：$c(\mathrm{Ba^{2+}}) = \dfrac{K_{sp}(\mathrm{BaMoO_4})}{c(\mathrm{MoO_4^{2-}})}$

不析出 $\mathrm{BaCO_3}$ 需：

$$c(\mathrm{Ba^{2+}})\cdot c(\mathrm{CO_3^{2-}}) \le K_{sp}(\mathrm{BaCO_3})$$

联立得：

$$c(\mathrm{CO_3^{2-}}) \le \frac{K_{sp}(\mathrm{BaCO_3})}{K_{sp}(\mathrm{BaMoO_4})}\cdot c(\mathrm{MoO_4^{2-}})$$

由 $K_{a2} = \dfrac{c(\mathrm{CO_3^{2-}})\cdot c(\mathrm{H^+})}{c(\mathrm{HCO_3^-})}$（pH=7.0，$c(\mathrm{H^+})=10^{-7}$）：

$$\frac{c(\mathrm{HCO_3^-})}{c(\mathrm{MoO_4^{2-}})} \le \frac{K_{sp}(\mathrm{BaCO_3})\cdot c(\mathrm{H^+})}{K_{sp}(\mathrm{BaMoO_4})\cdot K_{a2}} = \frac{2.6\times10^{-9}\times10^{-7}}{3.5\times10^{-8}\times4.7\times10^{-11}}$$

答：$\dfrac{2.6\times10^{-9}\times10^{-7}}{3.5\times10^{-8}\times4.7\times10^{-11}}$（列出算式即可）。

易错提醒：竞争沉淀的临界条件 = 两沉淀刚共存（同时饱和）；"列算式不代数字"是广东卷特色（减少计算误差）。

▶ 第3题详解（结晶方法 + 趁热过滤）

① $\mathrm{KNO_3}$ 溶解度随温度变化大 ⇒ 采用 冷却结晶（热饱和溶液降温析出晶体）；NaCl 溶解度随温度变化不大 ⇒ 可用蒸发结晶分离。

② 趁热过滤的目的：防止目标物质在过滤过程中因温度降低而结晶析出，造成产率损失。若流程中需除去不溶性杂质而目标产物溶解度对温度敏感，必须趁热过滤保留目标物质在滤液中。

易错提醒：冷却结晶适用于溶解度随温度变化大的物质（$\mathrm{KNO_3}$）；蒸发结晶适用于溶解度随温度变化小的物质（NaCl）；趁热过滤 vs 冷却过滤的选择取决于"目标物质是否会在低温析出"。
