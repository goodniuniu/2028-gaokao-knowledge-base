电化学综合

⚠️待强化★★★★☆#高二深化#广东选择性考试来源：广东选择性考试电化学选择题（2023·广东T16）
广东考情：高频(近5年广东卷每年必考，选择题稳定为第16题)·中档~压轴·科技情境(锂电池/双极膜/电解制氨)·真题锚定：2023广东选择性考试T16（双极膜电解KNO₃制氨）

核心内容

一、题型识别标志

题干关键条件识别为首选方法
"有外接电源/电解池"电解池先判阴阳极，再按酸碱性配平
"Li⁺/Na⁺ 在正负极间移动"新型电池离子迁移方向=内电路电流方向
"转移电子数/质量变化"定量计算n(e⁻)=n(氧化剂)×得电子数；串联等电子
"燃料电池正负极反应"燃料电极燃料负极；酸性/碱性决定写法
"金属防腐(镶嵌锌块)"原电池/防护牺牲阳极法；Zn作负极

二、标准化解题路径（六步法）

Step 1：判装置 → 有外接电源=电解池；无=原电池
Step 2：定电极 → 原电池：活泼/燃料/失电子=负极；电解池：接正=阳极，接负=阴极
Step 3：写反应 → 负极/阳极失电子，正极/阴极得电子
Step 4：配平 → 电子守恒 → 电荷守恒(H⁺/OH⁻/H₂O) → 原子守恒
Step 5：判迁移 → 阳离子向阴极/正极，阴离子向阳极/负极
Step 6：算定量 → 串联电路各池转移电子数相等；质量变化=Δn×M

三、高频核心结论速记

  • 原电池：负极氧化、正极还原；电子负→正，电流正→负
  • 电解池：阳极氧化、阴极还原；阳极活性电极自溶，惰性按放电顺序
  • 阴极放电顺序：Ag⁺ > Fe³⁺ > Cu²⁺ > H⁺(酸) > Pb²⁺ > Fe²⁺ > Zn²⁺ > H⁺(水) > Al³⁺ …
  • 膜问题：阳离子交换膜只过阳离子；阴离子交换膜只过阴离子；双极膜界面水解离出H⁺和OH⁻

四、真题母题（2023 广东选择性考试·第16题，4分）

广东卷以"具有'卯榫'结构的双极膜电解KNO₃溶液制氨"考查电极判断与定量。

题目：用一种具有"卯榫"结构的双极膜组装电解池，可实现大电流催化电解KNO₃溶液制氨。工作时H₂O在双极膜界面处被催化解离成H⁺和OH⁻。下列说法不正确的是（ ） A. 电解总反应：KNO₃+3H₂O=NH₃·H₂O+2O₂↑+KOH B. 每生成1 mol NH₃·H₂O，双极膜处有9 mol的H₂O解离 C. 电解过程中，阳极室中KOH的物质的量不因反应而改变 D. 相比于平面结构双极膜，"卯榫"结构可提高氨生成速率

解：

  • 阴极：NO₃⁻+8e⁻+6H₂O=NH₃+9OH⁻；阳极：4OH⁻−4e⁻=O₂↑+2H₂O
  • 总反应：KNO₃+3H₂O=NH₃·H₂O+2O₂↑+KOH，A正确
  • 每生成1 mol NH₃·H₂O转移8 mol e⁻，双极膜解离8 mol H₂O（非9 mol），B错
  • 阳极每消耗4 mol OH⁻，双极膜补入4 mol OH⁻，n(KOH)不变，C正确
  • "卯榫"增大接触面积，促进H₂O解离，提高速率，D正确

答：B

💡 关键技巧：先配平阴阳极反应式 → 由目标产物反推转移电子数 → 双极膜解离H₂O的物质的量=转移电子数，而不是凭感觉写9。

自测训练（3道·覆盖电极判断与定量计算）

先独立完成，再展开卡片末尾「参考答案」核对。每题标注所检验的题型，方便对号查漏。

第1题（检验：电极反应式书写 + 酸碱性配平） 写出碱性氢氧燃料电池的负极和正极反应式。

第2题（检验：电解池阳极反应 + 膜分离原理） 电解饱和食盐水（氯碱工业）用阳离子交换膜分隔阴阳极室。① 写出阳极反应式；② 说明阳离子交换膜的作用（为何不允许 OH⁻ 进入阳极室）。

第3题（检验：电子守恒 + 质量变化） 用惰性电极电解 $\mathrm{CuSO_4}$ 溶液，若电路中通过 0.4 mol 电子，求：① 阴极析出 Cu 的质量；② 阳极产生 $\mathrm{O_2}$ 的体积（标准状况）。

参考答案

答案与题目分板块呈现，便于"先做后对"。每题给出规范解答 + 易错提醒，做完一题对一题。

▶ 第1题详解（碱性燃料电池电极反应）

碱性环境下用 $\mathrm{OH^-}$ 和 $\mathrm{H_2O}$ 配平电荷：

负极（$\mathrm{H_2}$ 氧化）： $$\mathrm{H_2 - 2e^- + 2OH^- = 2H_2O}$$

正极（$\mathrm{O_2}$ 还原）： $$\mathrm{O_2 + 2H_2O + 4e^- = 4OH^-}$$

验证总反应：$2\mathrm{H_2}+\mathrm{O_2}=2\mathrm{H_2O}$ ✓

易错提醒：碱性环境用 $\mathrm{OH^-}$ 配平电荷；酸性环境用 $\mathrm{H^+}$ 配平电荷；正负极反应中得失电子数必须一致（负极 ×2 与正极 ×1 对应）。

▶ 第2题详解（电解 + 离子交换膜）

① 阳极反应（饱和食盐水，$\mathrm{Cl^-}$ 放电优先于 $\mathrm{OH^-}$）：

$$\mathrm{2Cl^- - 2e^- = Cl_2\uparrow}$$

② 阳离子交换膜的作用：只允许阳离子（$\mathrm{Na^+}$）通过，不允许阴离子（$\mathrm{OH^-}$、$\mathrm{Cl^-}$）通过。

若 $\mathrm{OH^-}$ 进入阳极室，会与 $\mathrm{Cl_2}$ 反应：$\mathrm{Cl_2 + 2OH^- = Cl^- + ClO^- + H_2O}$，消耗产品 $\mathrm{Cl_2}$、降低电流效率。阳离子交换膜阻隔 $\mathrm{OH^-}$，保证 $\mathrm{Cl_2}$ 纯度。

易错提醒：阳离子交换膜只过阳离子、阴离子交换膜只过阴离子、双极膜界面水解离出 $\mathrm{H^+}$ 和 $\mathrm{OH^-}$；膜的作用是"选择性透过"+"防止产物混合反应"。

▶ 第3题详解（电子守恒 + 定量计算）

电解 $\mathrm{CuSO_4}$ 溶液：

阴极：$\mathrm{Cu^{2+} + 2e^- = Cu}$

阳极：$\mathrm{2H_2O - 4e^- = O_2\uparrow + 4H^+}$

① $n(\mathrm{e^-}) = 0.4\ \mathrm{mol}$，$n(\mathrm{Cu}) = \dfrac{0.4}{2} = 0.2\ \mathrm{mol}$

$$m(\mathrm{Cu}) = 0.2\times64 = 12.8\ \mathrm{g}$$

② $n(\mathrm{O_2}) = \dfrac{0.4}{4} = 0.1\ \mathrm{mol}$

$$V(\mathrm{O_2}) = 0.1\times22.4 = 2.24\ \mathrm{L}$$

答：阴极析出 Cu 12.8 g；阳极产生 $\mathrm{O_2}$ 2.24 L（标况）。

易错提醒：电子守恒是串联定量计算的核心；阴极产物 = 阳离子放电（$\mathrm{Cu^{2+}}$ 优先于 $\mathrm{H^+}$），阳极产物 = 阴离子或水放电（此处水放电产生 $\mathrm{O_2}$，因 $\mathrm{SO_4^{2-}}$ 放电顺序极靠后）。
