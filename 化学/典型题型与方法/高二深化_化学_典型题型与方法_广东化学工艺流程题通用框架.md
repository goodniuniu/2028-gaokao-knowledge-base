## 核心内容

### 一、工艺流程题的本质

> **本质**：用化学反应原理解决工业生产中的实际问题。
>
> **核心思想**：**一切反应或操作都是为获得产品而服务。**

---

### 二、通用解题框架（四步通法）

```
Step 1：读题干 → 明确最终产品、原料成分、目标元素
Step 2：析流程 → 每一步"进什么→发生什么→出什么"
Step 3：想原理 → 反应条件控制（速率、平衡、沉淀、氧化还原）
Step 4：答问题 → 规范表述（用化学术语，避免口语化）
```

---

### 三、流程分析核心要点

#### 3.1 常见原料预处理

| 操作 | 目的 | 涉及反应/原理 |
|------|------|--------------|
| **粉碎/研磨** | 增大接触面积，加快反应速率 | 固体反应速率影响因素 |
| **灼烧/煅烧** | 改变结构、除去有机物、氧化还原 | 如菱铁矿煅烧生成Fe₂O₃ |
| **酸浸** | 溶解金属氧化物，除去不溶物 | 金属氧化物 + H⁺ → 盐 + H₂O |
| **碱浸** | 溶解Al、SiO₂、两性氧化物 | 2Al + 2NaOH + 2H₂O → 2NaAlO₂ + 3H₂↑ |
| **水浸** | 溶解可溶性盐 | 物理溶解过程 |

#### 3.2 核心反应类型

| 反应类型 | 常见考法 | 示例 |
|----------|----------|------|
| **氧化还原** | 加入氧化剂/还原剂的目的 | 将Fe²⁺氧化为Fe³⁺，便于沉淀分离 |
| **调节pH** | 控制金属离子沉淀 | Fe³⁺在pH≈3沉淀，Cu²⁺在pH≈5-6沉淀 |
| **沉淀转化** | Ksp小的沉淀更稳定 | AgCl + I⁻ → AgI + Cl⁻ |
| **络合反应** | 溶解难溶物 | AgCl + 2NH₃ → [Ag(NH₃)₂]⁺ + Cl⁻ |
| **电解** | 提纯或提取金属 | 电解精炼铜、电解法制备铝 |

#### 3.3 分离提纯操作

| 操作 | 适用场景 | 注意事项 |
|------|----------|----------|
| **过滤** | 固液分离 | 趁热过滤（防止结晶析出） |
| **蒸发结晶** | 溶解度随温度变化不大的物质 | NaCl：蒸发结晶 |
| **冷却结晶** | 溶解度随温度变化大的物质 | KNO₃：冷却结晶 |
| **萃取分液** | 溶质在不同溶剂中溶解度差异大 | 注意萃取剂选择（不互溶、不反应） |
| **蒸馏** | 沸点差异大的液体分离 | 注意温度计位置、冷凝水流向 |
| **重结晶** | 提纯含少量杂质的固体 | 溶解→蒸发浓缩→冷却结晶→过滤 |

### 四、条件控制原理

#### 4.1 温度控制

| 温度影响 | 答题角度 |
|----------|----------|
| **升高温度** | 加快反应速率、促进溶解、使平衡向吸热方向移动 |
| **降低温度** | 防止物质分解/挥发、使平衡向放热方向移动、减少能耗 |
| **控制温度** | 防止副反应、控制晶体大小、节能 |

#### 4.2 pH控制

| 目的 | 答题角度 | 示例 |
|------|----------|------|
| **促进沉淀** | 使某金属离子完全沉淀（离子浓度<10⁻⁵ mol/L） | Fe³⁺：pH≥3.2 |
| **防止沉淀** | 使目标离子留在溶液中 | Cu²⁺：pH<5 |
| **抑制水解** | 防止金属离子水解 | FeCl₃溶液中加HCl |
| **促进水解** | 制备氢氧化物沉淀 | 加热促进TiCl₄水解 |

#### 4.3 试剂选择

| 试剂类型 | 常见选择 | 选择原则 |
|----------|----------|----------|
| **氧化剂** | H₂O₂、Cl₂、NaClO、KMnO₄、空气 | 不引入新杂质或易除去 |
| **还原剂** | Fe粉、SO₂、H₂S、Na₂SO₃ | 同上 |
| **调节pH** | CuO、Cu(OH)₂、NH₃·H₂O、Na₂CO₃ | 不引入新杂质，消耗H⁺ |
| **沉淀剂** | NaOH、NH₃·H₂O、Na₂CO₃、H₂S | 使目标离子沉淀完全 |

> **绿色化学原则**：优先选择H₂O₂（产物是水）、空气（廉价易得）、不引入新杂质的试剂。

### 五、广东本地产业情境素材

| 产业/地区 | 涉及元素 | 典型流程 | 可能考点 |
|-----------|----------|----------|----------|
| **粤北稀土** | 稀土元素（La、Ce、Nd） | 稀土矿→酸浸→萃取分离→沉淀 | 氧化还原、沉淀pH、Ksp计算 |
| **茂名石化** | C、H、S | 石油裂化→脱硫→催化重整 | 化学反应、催化剂、绿色化学 |
| **珠海盐化工** | Na、Cl、Mg | 海水晒盐→电解→制备镁 | 电解原理、蒸发结晶、萃取 |
| **粤东锂电** | Li、Co、Ni | 废旧电池→酸浸→萃取→电沉积 | 氧化还原、调节pH、电化学 |
| **佛山陶瓷** | Al、Si、Ca | 高岭土→提纯→烧结 | 酸浸、过滤、SiO₂分离 |
| **广东冶炼** | Cu、Fe、Zn、Pb | 多金属矿→焙烧→浸取→电解 | 氧化还原、电解精炼、Ksp |
| **新能源材料** | Li、Co、Ni、Mn | 三元前驱体→共沉淀→烧结 | 沉淀控制、氧化还原、晶体结构 |

### 六、答题规范模板

#### 6.1 "目的/原因"类

> **模板**：为了达到...目的，采取...措施，因为...（原理）。

| 问题类型 | 答题模板 |
|----------|----------|
| 为什么粉碎？ | 增大固体与液体的接触面积，加快反应速率，提高浸取率 |
| 为什么控制温度在X℃？ | 低于X℃反应速率慢；高于X℃XX会分解/挥发/促进副反应 |
| 为什么调节pH到X？ | 使Fe³⁺（或其他杂质）完全沉淀，而目标离子仍留在溶液中 |
| 为什么加H₂O₂？ | 将Fe²⁺氧化为Fe³⁺，便于后续调节pH沉淀除去，且H₂O₂产物为水，不引入新杂质 |
| 为什么用XX调节pH？ | 消耗H⁺，使pH升高，且不引入新杂质（如CuO反应生成Cu²⁺，即目标离子） |

#### 6.2 "方程式书写"类

- 注意：看清是**离子方程式**还是**化学方程式**
- 酸性环境：可补H⁺和H₂O；碱性环境：可补OH⁻和H₂O
- 配平：先电子守恒，再电荷守恒，最后原子守恒

#### 6.3 "计算"类

- Ksp计算：注意离子浓度是否乘以系数幂次
- 产率计算：产率 = (实际产量/理论产量) × 100%
- 纯度计算：纯度 = (纯物质质量/样品总质量) × 100%

> **题目背景**：从多金属精矿中提取Fe、Cu、Ni，涉及"酸浸→高压加热→萃取→电解"流程。

| 小题 | 考查点 | 涉及原理 |
|------|--------|----------|
| (1)提高浸取速率 | 反应速率影响因素 | 温度、浓度、接触面积 |

| (4)绿色化学思想 | 新型冶铁与传统高炉对比 | 环保、节能、原子经济 |

## 自测训练（3道·覆盖流程框架四步通法）

> 先独立完成，再展开卡片末尾「参考答案」核对。每题标注所检验的题型，方便对号查漏。

**第1题**（检验：原料预处理目的 + 试剂选择原则）
某工艺流程中，"酸浸"前先将矿石粉碎，"除杂"时需将 Fe²⁺ 先氧化为 Fe³⁺ 再调 pH 沉淀。请回答：
① 粉碎矿石的目的是什么？
② 除杂时选择 H₂O₂ 而非 Cl₂ 作为氧化剂的好处是什么？

**第2题**（检验：调 pH 除杂原理 + 离子方程式书写）
已知某浸取液含 Fe³⁺、Cu²⁺，$K_{sp}[\mathrm{Fe(OH)_3}]=1.0\times10^{-38}$，$K_{sp}[\mathrm{Cu(OH)_2}]=2.2\times10^{-20}$。若要使 Fe³⁺ 沉淀完全（$c(\mathrm{Fe^{3+}})<10^{-5}\ \mathrm{mol/L}$）而 Cu²⁺ 不沉淀（$c(\mathrm{Cu^{2+}})=0.1\ \mathrm{mol/L}$），pH 应控制在什么范围？简述用 CuO 调 pH 的原因。

**第3题**（检验：产率/纯度计算 + 答题规范）
某工艺流程理论上 100 t 矿石（含 Cu 50%）可制得 CuSO₄·5H₂O 的质量为多少？若实际产出 117.5 t，求产率。（相对原子质量：Cu-64，S-32，O-16，H-1）

## 备注

- **广东卷特色**：工艺流程题是广东化学的"定海神针"，第18题固定位置、固定分值。近年趋向"真实工业流程+绿色化学理念"，如2024题涉及"新型冶铁方法与传统高炉对比"，体现绿色化学思想。
- **易错点**：
  1. "不引入新杂质"是选择试剂的重要原则，如除去Cu²⁺溶液中的Fe³⁺，用CuO或Cu(OH)₂调pH，不能用NaOH（引入Na⁺）
  2. 趁热过滤 vs 冷却过滤：防止目标物质析出或促进杂质析出
  3. Ksp计算时注意离子浓度的系数幂次（如Fe(OH)₃的Ksp = [Fe³⁺][OH⁻]³）
- **等级赋分提示**：工艺流程题是化学的压轴题型，分值高但步骤多。建议训练"分步得分"意识，即使不能完全解出，写出每步的原理和分析也能拿部分分。
- **推荐练习**：2023广东化学第18题、2024广东化学第18题、2024广州一模工艺流程题。

## 参考答案

> 答案与题目分板块呈现，便于"先做后对"。每题给出规范解答 + 易错提醒，做完一题对一题。

<details>
<summary>▶ 第1题详解（原料预处理 + 试剂选择原则）</summary>

① **粉碎矿石的目的**：增大固体与液体的接触面积，加快反应速率，提高浸取率（缩短浸取时间）。

② **选择 H₂O₂ 而非 Cl₂ 的好处**：H₂O₂ 将 Fe²⁺ 氧化为 Fe³⁺ 后，还原产物为 H₂O，**不引入新杂质**；而 Cl₂ 会引入 Cl⁻，可能干扰后续操作或影响产品纯度。此外，H₂O₂ 体现"绿色化学"理念（无有害副产物）。

> **易错提醒**：答题时必须写"不引入新杂质"这一关键词，只写"绿色环保"不够具体。

</details>

<details>
<summary>▶ 第2题详解（调pH除杂 + Ksp定量控制）</summary>

**Fe³⁺ 沉淀完全**（$c(\mathrm{Fe^{3+}})<10^{-5}\ \mathrm{mol/L}$）：

$$K_{sp} = c(\mathrm{Fe^{3+}})\cdot c^3(\mathrm{OH^-}) = 1.0\times10^{-38}$$
$$c(\mathrm{OH^-}) > \sqrt[3]{\frac{1.0\times10^{-38}}{10^{-5}}} = \sqrt[3]{10^{-33}} = 10^{-11}\ \mathrm{mol/L}$$

$\text{pOH} < 11$，$\text{pH} > 3$。

**Cu²⁺ 不沉淀**（$c(\mathrm{Cu^{2+}})=0.1\ \mathrm{mol/L}$）：

$$c(\mathrm{OH^-}) < \sqrt{\frac{K_{sp}}{c(\mathrm{Cu^{2+}})}} = \sqrt{\frac{2.2\times10^{-20}}{0.1}} = \sqrt{2.2\times10^{-19}} \approx 4.7\times10^{-10}\ \mathrm{mol/L}$$

$\text{pOH} > 9.33$，$\text{pH} < 4.67$。

**pH 范围**：$3 < \text{pH} < 4.67$（或写 3.2~4.7 附近均可）。

**用 CuO 调 pH 的原因**：CuO 消耗 H⁺ 使 pH 升高，且反应生成 Cu²⁺ 即目标离子，**不引入新杂质**。若用 NaOH 会引入 Na⁺，污染产品。

> **易错提醒**：Ksp 表达式要按化学式中离子计量数作为幂次——Fe(OH)₃ 中 OH⁻ 是 **3 次方**，Cu(OH)₂ 中 OH⁻ 是 **2 次方**。

</details>

<details>
<summary>▶ 第3题详解（产率计算 + 物质的量桥接）</summary>

$n(\mathrm{Cu}) = \dfrac{100\times10^6\times50\%}{64} = 7.8125\times10^5\ \mathrm{mol}$

由 Cu 守恒（1 Cu → 1 CuSO₄·5H₂O）：

$n(\mathrm{CuSO_4\cdot5H_2O}) = n(\mathrm{Cu}) = 7.8125\times10^5\ \mathrm{mol}$

$M(\mathrm{CuSO_4\cdot5H_2O}) = 64+32+4\times16+5\times18 = 250\ \mathrm{g/mol}$

理论产量 $= 7.8125\times10^5 \times 250 = 1.953\times10^8\ \mathrm{g} = 195.3\ \mathrm{t}$

**产率** $= \dfrac{117.5}{195.3}\times100\% \approx 60.2\%$

> **易错提醒**：产率 = 实际产量/理论产量 ×100%，理论产量由"目标元素物质的量守恒"推算；不要误用纯度公式。

</details>
