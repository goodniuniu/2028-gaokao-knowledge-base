## 核心内容

### 一、题型识别标志

| 题干关键条件 | 识别为 | 首选方法 |
|-------------|--------|----------|
| "已知①②③反应，求目标反应ΔH" | 盖斯定律方程组 | 倒转变号、乘系数、加和消去 |
| "反应历程/能量变化图求总焓变" | 盖斯定律图像法 | 分步焓变相加：ΔH总=Σ各步ΔH |
| "键能数据求ΔH" | 键能法 | ΔH=Σ反应物键能−Σ生成物键能 |
| "正逆反应活化能求ΔH" | 活化能法 | ΔH=Eₐ(正)−Eₐ(逆) |

### 二、核心公式

```
盖斯定律：ΔH只与始态和终态有关，与途径无关
  若 ③ = ① + ②，则 ΔH₃ = ΔH₁ + ΔH₂
  若 ③ = ① − ②，则 ΔH₃ = ΔH₁ − ΔH₂
  若 ③ = n×①，则 ΔH₃ = n×ΔH₁

键能法：ΔH = Σ(反应物键能) − Σ(生成物键能)
图像法：ΔH = E(生成物总能量) − E(反应物总能量) = Eₐ(正) − Eₐ(逆)
```
> 注意事项：① 热化学方程式须标状态(s/l/g/aq)；② ΔH带符号，放热为负；③ 系数变n倍，ΔH变n倍；④ 方程式颠倒，ΔH变号。

### 三、标准化解题路径（方程组四步法）

```
Step 1：写目标 → 写出目标反应的化学方程式（状态标全）
Step 2：选已知 → 从已知反应中找出含目标物质与中间产物的式子
Step 3：调系数 → 颠倒(ΔH变号)/乘n(ΔH等倍)，使中间产物相消
Step 4：加和算 → 方程式相加消去中间物，ΔH对应代数相加
```

> 图像法提示：图像法本质"分段焓变代数和"，按 E(终)−E(始) 取符号；反应物能级在上、生成物在下为放热(ΔH<0)。

### 四、真题母题（2021 广东选择性考试·第19题，节选）

> 广东卷以"CH₄与CO₂重整"反应体系考查盖斯定律代数式书写（碳中和情境）。

**题目**：该重整反应体系主要涉及以下反应：
(a) CH₄(g)+CO₂(g)=2CO(g)+2H₂(g)  ΔH₁
(b) CO₂(g)+H₂(g)=CO(g)+H₂O(g)  ΔH₂
(c) CH₄(g)=C(s)+2H₂(g)  ΔH₃
(d) 2CO(g)=CO₂(g)+C(s)  ΔH₄
(e) CO(g)+H₂(g)=H₂O(g)+C(s)  ΔH₅
(1)根据盖斯定律，反应a的ΔH₁ = ______（写出一个代数式即可）。

**解**：
- 观察：a = b + c − e 的变形，或直接 a = c − d（因 d: 2CO→CO₂+C，则 c−d: CH₄−[2CO→CO₂+C] → CH₄+CO₂→2CO+2H₂ = a）
  → ΔH₁ = ΔH₃ − ΔH₄
- 另一组：a = b + c − e  → ΔH₁ = ΔH₂ + ΔH₃ − ΔH₅
- 官方答案给出两种等价式：**ΔH₁ = ΔH₂ + ΔH₃ − ΔH₅** 或 **ΔH₁ = ΔH₃ − ΔH₄**

**答**：ΔH₂+ΔH₃−ΔH₅（或 ΔH₃−ΔH₄）

> 💡 关键技巧：盖斯定律"拼图法"——把目标反应当作拼图，用已知反应正着加、倒着减，消去所有中间产物(C、CO、H₂O等)即可；不必死记，先消C(s)最稳。

## 自测训练（3道·覆盖盖斯定律三种方法）

> 先独立完成，再展开卡片末尾「参考答案」核对。每题标注所检验的题型，方便对号查漏。

**第1题**（检验：方程组法 + 代数式书写）
已知下列热化学方程式：
- ① $\mathrm{C(s) + O_2(g) = CO_2(g)}\quad \Delta H_1 = -393.5\ \mathrm{kJ/mol}$
- ② $\mathrm{CO(g) + \frac{1}{2}O_2(g) = CO_2(g)}\quad \Delta H_2 = -283.0\ \mathrm{kJ/mol}$

求反应 ③ $\mathrm{C(s) + \frac{1}{2}O_2(g) = CO(g)}$ 的 $\Delta H_3$（用 $\Delta H_1$、$\Delta H_2$ 的代数式表示并计算数值）。

**第2题**（检验：键能法 + 符号判断）
已知键能数据：$E(\mathrm{H-H})=436$，$E(\mathrm{Cl-Cl})=243$，$E(\mathrm{H-Cl})=431$（单位 $\mathrm{kJ/mol}$）。用键能法计算反应 $\mathrm{H_2(g) + Cl_2(g) = 2HCl(g)}$ 的 $\Delta H$。

**第3题**（检验：图像法 + 活化能关系）
某反应的 $E_a(\text{正}) = 120\ \mathrm{kJ/mol}$，$E_a(\text{逆}) = 40\ \mathrm{kJ/mol}$。① 求 $\Delta H$；② 判断正反应是吸热还是放热，并说明依据。

## 参考答案

> 答案与题目分板块呈现，便于"先做后对"。每题给出规范解答 + 易错提醒，做完一题对一题。

<details>
<summary>▶ 第1题详解（方程组法 + 代数式）</summary>

观察：③ = ① − ②（消去 $\mathrm{CO_2(g)}$）

$$\mathrm{C(s) + O_2(g) - [CO(g) + \frac{1}{2}O_2(g)] = CO(g)}$$

整理得：$\mathrm{C(s) + \frac{1}{2}O_2(g) = CO(g)}$ ✓

由盖斯定律：

$$\Delta H_3 = \Delta H_1 - \Delta H_2 = -393.5 - (-283.0) = -110.5\ \mathrm{kJ/mol}$$

**答**：$\Delta H_3 = -110.5\ \mathrm{kJ/mol}$（放热）。

> **易错提醒**：方程式相减时，$\Delta H$ 同步相减（不是变号）；颠倒方程式时 $\Delta H$ 才变号。

</details>

<details>
<summary>▶ 第2题详解（键能法 + 符号）</summary>

键能法：$\Delta H = \sum E(\text{反应物}) - \sum E(\text{生成物})$

$$\Delta H = [E(\mathrm{H-H}) + E(\mathrm{Cl-Cl})] - [2\times E(\mathrm{H-Cl})]$$

$$\Delta H = [436 + 243] - [2\times431] = 679 - 862 = -183\ \mathrm{kJ/mol}$$

**答**：$\Delta H = -183\ \mathrm{kJ/mol}$（放热反应）。

> **易错提醒**：键能法公式为"反应物键能之和 − 生成物键能之和"（记住"吸减放"的方向）；生成物键能大（更稳定）时 $\Delta H < 0$（放热）。

</details>

<details>
<summary>▶ 第3题详解（活化能法 + 吸放热判断）</summary>

① 由活化能关系：

$$\Delta H = E_a(\text{正}) - E_a(\text{逆}) = 120 - 40 = +80\ \mathrm{kJ/mol}$$

② $\Delta H > 0$ ⇒ 正反应为 **吸热反应**。

**依据**：$\Delta H = E_a(\text{正}) - E_a(\text{逆})$。当 $E_a(\text{正}) > E_a(\text{逆})$ 时，正向反应需吸收更多能量（产物能量高于反应物），为吸热反应；反之 $E_a(\text{正}) < E_a(\text{逆})$ 为放热反应。

> **易错提醒**：$\Delta H$ 的符号由 $E_a(\text{正}) - E_a(\text{逆})$ 的正负决定；不要颠倒正逆关系；正值表示吸热、负值表示放热。

</details>
