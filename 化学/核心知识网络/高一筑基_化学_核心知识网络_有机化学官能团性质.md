## 核心内容

### 关键概念
- **官能团**：决定有机化合物特殊性质的原子或原子团
- **同分异构体**：分子式相同，结构不同的化合物
- **同系物**：结构相似，分子组成相差一个或多个CH₂的化合物
- **反应类型**：取代、加成、消去、氧化、还原、聚合、酯化等
- **反应条件**：特定反应需要在特定条件（温度、催化剂、溶剂）下进行

### 核心官能团性质表

#### 1. 烃类官能团
| 类别 | 官能团 | 代表物 | 特征反应 | 反应条件 |
|------|--------|--------|---------|---------|
| 烷烃 | 无（C-C单键） | 甲烷 | 取代反应 | 光照（Cl₂） |
| 烯烃 | C=C | 乙烯 | 加成反应、氧化反应（使KMnO₄褪色）、加聚 | 催化剂/加热 |
| 炔烃 | C≡C | 乙炔 | 加成反应、氧化反应 | 催化剂/加热 |
| 芳香烃 | 苯环 | 苯 | 取代（卤代/硝化/磺化）、加成（H₂） | FeX₃/浓H₂SO₄/催化剂+加热 |

#### 2. 烃的衍生物官能团
| 类别 | 官能团 | 代表物 | 特征反应 | 反应条件 |
|------|--------|--------|---------|---------|
| 卤代烃 | -X | 溴乙烷 | 取代→醇、消去→烯 | NaOH水溶液/醇溶液 |
| 醇 | -OH | 乙醇 | 取代、消去、氧化、酯化 | 浓H₂SO₄/加热/Cu或Ag |
| 酚 | -OH（连苯环） | 苯酚 | 弱酸性、取代、显色（FeCl₃） | 常温/Br₂水 |
| 醛 | -CHO | 乙醛 | 氧化→酸、还原→醇、银镜反应 | 银氨溶液/新制Cu(OH)₂ |
| 酮 | C=O（非端基） | 丙酮 | 还原→醇 | H₂/催化剂 |
| 羧酸 | -COOH | 乙酸 | 酸性、酯化 | 浓H₂SO₄/加热 |
| 酯 | -COO- | 乙酸乙酯 | 水解（酸性/碱性） | H⁺/OH⁻/加热 |
| 醚 | -O- | 乙醚 | 稳定 | — |
| 胺 | -NH₂ | 苯胺 | 碱性、取代 | — |

#### 3. 反应条件与试剂对应表
| 试剂/条件 | 反应类型 | 适用官能团 |
|----------|---------|-----------|
| 浓H₂SO₄/加热 | 消去（醇→烯）、酯化、硝化 | -OH、-COOH、苯环 |
| NaOH水溶液/加热 | 水解（卤代烃→醇、酯→酸+醇） | -X、-COO- |
| NaOH醇溶液/加热 | 消去（卤代烃→烯） | -X |
| Cu/Ag、O₂、加热 | 氧化（醇→醛/酮） | -OH（α位有H） |
| 银氨溶液/水浴加热 | 银镜反应（醛→酸铵） | -CHO |
| 新制Cu(OH)₂/加热 | 氧化（醛→酸，砖红色沉淀） | -CHO |
| H₂/催化剂 | 加成（还原） | C=C、C≡C、-CHO、C=O、苯环 |
| Br₂/CCl₄ | 加成 | C=C、C≡C |
| Br₂/FeBr₃ | 取代（苯环） | 苯环 |
| Br₂水 | 加成（烯炔）、取代（苯酚） | C=C、C≡C、苯酚 |
| KMnO₄/H⁺ | 氧化 | C=C、C≡C、-OH、-CHO、苯环侧链 |

### 方法步骤

#### 有机推断题突破口速查
1. **看反应条件**：
   - NaOH/水 → 卤代烃水解或酯水解
   - NaOH/醇 → 卤代烃消去
   - 浓H₂SO₄/加热 → 醇消去或酯化
   - Cu/O₂/加热 → 醇氧化
   - 银氨溶液/水浴 → 醛基
2. **看特征现象**：
   - 使溴水褪色 → C=C、C≡C、-CHO、苯酚
   - 使KMnO₄褪色 → C=C、C≡C、-OH、-CHO、苯环侧链
   - FeCl₃显紫色 → 酚羟基
   - 银镜反应/砖红色沉淀 → 醛基
   - 与Na反应放H₂ → -OH、-COOH
   - 与NaHCO₃反应放CO₂ → -COOH
3. **看分子量变化**：
   - 加成H₂：M增加2（C=C）或4（C≡C）或6（苯环）
   - 酯化：酸+醇→酯+H₂O，M增加酸+醇-18

#### 同分异构体书写方法
```
① 确定分子式和不饱和度
② 确定官能团类型
③ 按类别异构 → 碳链异构 → 位置异构顺序书写
④ 检查：不重复、不遗漏
```
> 不饱和度Ω = (2C+2-H+N-X)/2；常见：Ω=1→C=C或C=O或环；Ω=2→C≡C或两个C=C或C=O+环；Ω=4→苯环

### 记忆口诀/技巧
> **官能团优先顺序**：羧酸 > 酯 > 醛 > 酮 > 醇 > 胺 > 烯 > 炔 > 醚 > 卤代烃。
> **氧化还原链**：醇 → 醛 → 羧酸（氧化方向）；羧酸 → 醛 → 醇（还原方向）。
> **显色反应口诀**：酚遇三氯化铁，紫色显出来；醛遇银氨溶液，银镜做出来。
> **广东情境提示**：广东卷有机推断常与广东产业结合（如茂名石化、珠海生物医药、深圳新材料），注意题目中的陌生反应信息，往往是解题关键。

> **看到什么条件 → 立刻想到什么方法/模型**

| 题干关键条件 | 识别为 | 首选方法 |
|-------------|--------|----------|
| "关于某有机物说法不正确的是" + 结构图 | 官能团性质判断 | 先标官能团，再逐条对应性质 |
| "能使溴水/溴的四氯化碳褪色" | 含 C=C/C≡C/−CHO/酚 | 加成或氧化，注意苯环不与 Br₂/CCl₄ 反应 |
| "能与 NaHCO₃ 放 CO₂" | 含 −COOH | 酸性强于 H₂CO₃ |
| "与 FeCl₃ 显紫色" | 含酚羟基 | 特征显色反应 |
| "银镜反应/砖红沉淀" | 含 −CHO | 醛基特征检验 |
| "与 Na 放 H₂" | 含 −OH/−COOH | 羟基/羧基活泼氢 |
| "共面/共线、杂化方式" | 空间结构 | sp²(平面)、sp³(四面体，不共面) |

## 解题路径（官能团性质判定三步法）

### 第一步：圈出所有官能团
- 标注 C=C、−COOH、−OH(酚/醇)、−CHO、酯基、醚键等

### 第二步：逐性质对号入座
- 碳碳双键→使溴的 CCl₄ 褪色；羧基→与氨基成酰胺；酚−OH→FeCl₃ 紫色

### 第三步：判空间结构与杂化
- 形成双键的 C 为 sp²(平面)；饱和 C 为 sp³(四面体，不共面)
- 易错：多个环共用 sp³ 碳→环系不可能全共面

## 母题（2024 广东选择性考试·第9题，2分）

> 广东卷以"南海柳珊瑚酸"真实情境考查官能团性质与空间结构。

**题目**：从我国南海的柳珊瑚中分离得到的柳珊瑚酸（图1），具有独特的环系结构。下列关于柳珊瑚酸的说法不正确的是（  ）
A. 能使溴的四氯化碳溶液褪色
B. 能与氨基酸的氨基发生反应
C. 其环系结构中 3 个五元环共平面
D. 其中碳原子的杂化方式有 sp² 和 sp³

**解**：
- A：分子含碳碳双键，能与 Br₂ 发生加成而褪色，**A 正确**
- B：分子含 −COOH，可与氨基酸的 −NH₂ 发生酰胺化反应，**B 正确**
- C：3 个五元环共用的 1 个碳原子及与其相连的 4 个碳原子为 sp³ 杂化(类甲烷四面体)，故 3 个五元环不可能共平面，**C 错**
- D：成双键的 C 为 sp²，其余饱和 C 为 sp³，**D 正确**

**答**：C

> 💡 关键技巧：共面判断题先找 sp³ 碳；只要分子中有 1 个 sp³ 碳参与环系骨架，该局部即不可能全共面。

## 自测训练（3道·覆盖官能团识别与性质判断）

## 备注

- 有机推断是广东卷化学必考大题（通常18-20题），分值15分左右，必须拿下
- 高频陷阱：
  - 酚羟基与醇羟基性质不同：酚有弱酸性（与NaOH反应），醇无
  - 醛基与酮基的区别：醛能发生银镜反应，酮不能
  - 酯在碱性条件下水解生成羧酸盐而非羧酸
  - 消去反应的条件：醇消去需浓H₂SO₄/加热；卤代烃消去需NaOH醇溶液/加热
- 同分异构体是高频难点，注意：
  - 苯环上的取代基位置（邻、间、对）
  - 含氧官能团的位置异构（如C₃H₆O₂可以是酸、酯、羟基醛等）
  - 限制条件的同分异构体书写（如能发生银镜反应、能与NaHCO₃反应等）
- 有机合成路线设计是广东卷创新题方向，关注：
  - 逆合成分析法：从目标产物倒推原料
  - 保护基策略：先保护易被氧化的基团，反应后再脱保护
  - 绿色化学：原子经济性、无溶剂反应、催化剂使用

## 参考答案

> 答案与题目分板块呈现，便于"先做后对"。每题给出规范解答 + 易错提醒，做完一题对一题。

<details>
<summary>▶ 第1题详解（官能团特征反应）</summary>

① **溴的 $\mathrm{CCl_4}$ 溶液**：能与 $\mathrm{C=C}$ 发生 **加成反应**（使溴水/溴的 $\mathrm{CCl_4}$ 褪色）。酚羟基遇溴水发生取代（生成白色沉淀三溴苯酚），但 $\mathrm{Br_2/CCl_4}$ 主要发生加成。**能反应**。

② **$\mathrm{FeCl_3}$ 溶液**：酚羟基与 $\mathrm{Fe^{3+}}$ 发生 **显色反应**（紫色）。**能反应**。

③ **$\mathrm{NaHCO_3}$ 溶液**：$\mathrm{-COOH}$ 酸性强于 $\mathrm{H_2CO_3}$，与 $\mathrm{NaHCO_3}$ 反应放出 $\mathrm{CO_2}$。**能反应**（产生气泡）。

④ **$\mathrm{NaOH}$ 溶液**：$\mathrm{-COOH}$ 发生酸碱中和；酚羟基显弱酸性也与 NaOH 反应（但酸性弱于 $\mathrm{H_2CO_3}$，不与 $\mathrm{NaHCO_3}$ 反应）。**能反应**。

> **易错提醒**：酚羟基有弱酸性（与 NaOH 反应），但酸性弱于 $\mathrm{H_2CO_3}$（不与 $\mathrm{NaHCO_3}$ 反应）；羧基酸性强于 $\mathrm{H_2CO_3}$（与 $\mathrm{NaHCO_3}$ 反应放 $\mathrm{CO_2}$）。

</details>

<details>
<summary>▶ 第2题详解（反应条件与类型）</summary>

① 乙醇 → 乙烯：**消去反应**。条件：**浓 $\mathrm{H_2SO_4}$、170℃**。

$$\mathrm{CH_3CH_2OH \xrightarrow[170℃]{浓H_2SO_4} CH_2=CH_2\uparrow + H_2O}$$

② 乙酸 + 乙醇 → 乙酸乙酯：**酯化反应**（取代）。条件：**浓 $\mathrm{H_2SO_4}$、加热**。

$$\mathrm{CH_3COOH + CH_3CH_2OH \rightleftharpoons \xrightarrow{浓H_2SO_4,\Delta} CH_3COOCH_2CH_3 + H_2O}$$

③ 溴乙烷 → 乙烯：**消去反应**。条件：**NaOH 醇溶液、加热**。

$$\mathrm{CH_3CH_2Br + NaOH \xrightarrow[\Delta]{乙醇} CH_2=CH_2\uparrow + NaBr + H_2O}$$

④ 乙醛 → 乙酸：**氧化反应**。条件：**银氨溶液水浴**（银镜）或 **新制 $\mathrm{Cu(OH)_2}$ 加热**。

$$\mathrm{CH_3CHO + 2Ag(NH_3)_2OH \xrightarrow{\Delta} CH_3COONH_4 + 2Ag\downarrow + 3NH_3 + H_2O}$$

> **易错提醒**：醇消去用"浓 $\mathrm{H_2SO_4}$、170℃"（不是 140℃，那是成醚）；卤代烃消去用"NaOH 醇溶液加热"（不是水溶液，那是取代/水解）；酯化是可逆反应，需标 $\rightleftharpoons$。

</details>

<details>
<summary>▶ 第3题详解（同分异构体 + 限制条件）</summary>

不饱和度 $\Omega = \dfrac{2\times4+2-8}{2} = 1$。

"能发生银镜反应" ⇒ 含 **醛基**（$\mathrm{-CHO}$）；"含羧基"（$\mathrm{-COOH}$）。

同时含醛基和羧基的 $\mathrm{C_4H_8O_2}$（验证：$\mathrm{-CHO}$（1 O）+ $\mathrm{-COOH}$（2 O）= 3 O，但分子式只有 2 O，不能同时含两种）。

重新审视：$\mathrm{C_4H_8O_2}$ 的 $\Omega=1$，"含羧基"已用掉 1 个 $\Omega$ 和 2 个 O。

- $\mathrm{CH_3CH_2CH_2COOH}$（丁酸）：有羧基，**无醛基**，不能银镜；
- $\mathrm{(CH_3)_2CHCOOH}$（异丁酸）：同上；
- 甲酸酯（HCOO−R）：含醛基结构（$\mathrm{H-C(=O)-}$），能发生银镜反应，但无羧基。

**重新解读题意**：$\mathrm{C_4H_8O_2}$ 能发生银镜反应的（含醛基或甲酸酯结构）：

- **甲酸丙酯** $\mathrm{HCOOCH_2CH_2CH_3}$（甲酸正丙酯）；
- **甲酸异丙酯** $\mathrm{HCOOCH(CH_3)_2}$。

"含羧基"与"能银镜"在 $\mathrm{C_4H_8O_2}$ 中**不能同时满足**（O 原子数不足）。

若题目放宽为 $\mathrm{C_4H_6O_3}$（$\Omega = 2$，含 3 个 O），则可同时含醛基和羧基，如 $\mathrm{OHCCH_2CH_2COOH}$（琥珀半醛/4-氧丁酸衍生物）。

**答案调整**：原题 $\mathrm{C_4H_8O_2}$ 条件下：
- **能发生银镜反应**的结构：甲酸丙酯、甲酸异丙酯（2 种，均为甲酸酯类，含类似醛基结构）；
- **含羧基**的结构：丁酸、异丁酸（2 种）。
- 同时满足"银镜 + 羧基"在 $\mathrm{C_4H_8O_2}$ 中不存在。

> **易错提醒**：甲酸酯 $\mathrm{HCOOR}$ 虽无醛基官能团，但因含 $\mathrm{H-C(=O)-O-}$ 结构，能发生银镜反应（类似醛基性质）；同分异构体书写需先算不饱和度，再按"类别异构 → 碳链异构 → 位置异构"穷举。

</details>
