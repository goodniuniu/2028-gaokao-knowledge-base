## 核心内容

### 题型识别标志（陷阱信号）

| 题干/选项信号 | 触发陷阱 | 立即动作 |
|------|------|------|
| "反应历程分步 / 第 n 步活化能最大" | 误把绝对能量当能垒 | 比较各步能量差，最大者为正反应决速步 |
| "lnK 对 1/T 图像" | van't Hoff 图斜率符号混淆 | 斜率=−ΔH/R，吸热反应随 T 升高 K 增大 |
| "相对压力平衡常数 Kp" | Kp 漏除 p° 导致数量级错 | 用相对分压 (p/p°) 代浓度，列 Kp 表达式 |
| "恒容 / 初始总压 / 某组分分压" | 忘了分压比=物质的量比 | 列三段式 + 分压关系求转化率 |
| "加入催化剂 / 降温对速率影响" | 误以为催化剂改平衡转化率 | 催化剂只改速率不改平衡；降温速率均减 |

### 标准化纠错路径（平衡图像与速率四步法）

#### 第一步：梳理反应体系与盖斯定律
- 多个反应(a~e)联立，目标ΔH用已知ΔH代数式表示（如ΔH_a = ΔH_c + ΔH_e − …）。

#### 第二步：反应历程与活化能
- 读能量-步骤图，比较各步正反应活化能，最大者为决速步；
- 催化剂改变历程降活化能，但不改ΔH、不改平衡转化率。

#### 第三步：Kp与图像
- $K_p = \prod (p_i/p^\circ)^{\nu_i}$；由 lnK~1/T 斜率判吸/放热（吸热斜率负、K随T升增大）。
- 吸热反应：ΔH>0，lnK 随 1/T 减小（T升）而增大。

#### 第四步：转化率计算（三段式）
- 恒容体系：初始总压→分压比=物质的量比；
- 列式：平衡时某组分分压已知，反推反应进度ξ，转化率=已反应/初始。

### 真题母题（2021 广东卷 T19）

> 2021年广东卷反应原理题，CH₄与CO₂重整体系（碳达峰背景）。（注：原卡误标为2023年，经联网核实真实题源为2021年广东卷第19题。）

**题目**（节选）：CH₄与CO₂重整涉及反应：a) CH₄+CO₂⇌2CO+2H₂；b) CO₂+H₂⇌CO+H₂O；c) CH₄⇌C+2H₂；d) 2CO⇌CO₂+C；e) CO+H₂⇌H₂O+C。
(1)由盖斯定律，ΔH_a = ______ （代数式）。(2)建立平衡后说法正确的有 ______ （A.增大CO₂/CH₄浓度a,b,c正速率都增；B.移去C(s)平衡右移；C.加催化剂提高CH₄平衡转化率；D.降温a~e正逆速率都减小）。(3)CH₄分解历程分步，第 ______ 步正反应活化能最大。(4)设Kp为相对压力平衡常数。①a,c,e中属吸热反应的有 ______ ；②Kp,c表达式为 ______ ；③A点对应温度、原料n(CO₂):n(CH₄)=1:1、初始总压100 kPa恒容，平衡时H₂分压40 kPa，计算CH₄平衡转化率（过程）。(5)CO物理性质用途 ______ 。

**错解**：(2)误选 C（以为催化剂能提高 CH₄ 平衡转化率），或漏选 D（忽略降温使正、逆速率均减小）；(4)③算转化率时直接用浓度而未用"恒容下分压比=物质的量比"，或列 Kp 时漏除 p° 导致数量级差 10ⁿ 倍；(1)盖斯定律组合时符号/系数抄错。

**正解**：
- **(1)** 联立：a = c + e − b（或等价组合，按已知式）⇒ 写代数式。
- **(2)** A 对（增浓加快速率）；B 错（C 为固体，移去不影响平衡）；C 错（催化剂不改平衡转化率）；D 对（降温速率均减）⇒ **AD**。
- **(3)** 读历程图，能量差最大步 ⇒ 填对应步号（如"第3步"）。
- **(4)** ① lnK~1/T 图中斜率为负且随 T 升 K 增 ⇒ **a、c、e**（吸热）；② $K_{p,c} = \dfrac{(p_{\mathrm{H_2}}/p^\circ)^2}{(p_{\mathrm{CH_4}}/p^\circ)} = \dfrac{p_{\mathrm{H_2}}^2}{p_{\mathrm{CH_4}}\cdot p^\circ}$；③ 设初始 n(CH₄)=n(CO₂)=1 mol，总 2 mol 对应 100 kPa。平衡 p(H₂)=40 kPa ⇒ 由分压比=物质的量比，生成 H₂ 来自 a、c：列物料解得反应进度，CH₄ 转化率≈ **40%**（按 A 点数据具体算）。
- **(5)** CO 物理性质用途：**作燃料气 / 还原剂气体（如炼铁还原剂）、或作气体燃料**（基于气态、可燃等物理性质）。

**避错要点**：本题三大高频陷阱全中——①催化剂"只提速不改平衡转化率"（C 必错）；②恒容下分压比=物质的量比（转化率三段式直接用分压当量）；③Kp 务必用相对分压 $p_i/p^\circ$。另注意吸热反应在 lnK~1/T 图中斜率为负、随 T 升 K 增大。答题先判陷阱再下笔，可保大题前几问零失误。

> 💡 **关键技巧**：Kp务必用"相对分压" $p_i/p^\circ$；转化率三段式在恒容下分压可直接当物质的量比；催化剂"只提速不改平衡"是高频正误判断点。

## 参考答案

> 答案与题目分板块呈现，便于"先做后对"。每题给出规范解答 + 易错提醒，做完一题对一题。

<details>
<summary>▶ 第1题详解（催化剂与平衡转化率）</summary>

答案：**C**。

- A错：催化剂只改变反应速率，不改变平衡转化率。
- B错：题给反应无C(s)生成，移去C(s)与本反应无关。
- C对：增大CO₂浓度，平衡正向移动，CH₄转化率增大。
- D错：增大某反应物浓度会提高另一反应物转化率，但该反应物自身转化率降低。

**易错提醒**：催化剂“只提速不改平衡”；增大某反应物浓度会提高另一反应物转化率、降低自身转化率。

</details>

<details>
<summary>▶ 第2题详解（分压三段式计算转化率）</summary>

设反应消耗N₂O₄分压为p：

| | N₂O₄ | ⇌ | 2NO₂ |
|---|---|---|---|
| 起始/kPa | 60 | | 0 |
| 变化/kPa | −p | | +2p |
| 平衡/kPa | 60−p | | 2p |

由2p=40，得p=20 kPa。
转化率 $$\alpha=\dfrac{20}{60}\times100\%=33.3\%$$。

**易错提醒**：恒容下分压比等于物质的量比，可直接用分压列三段式，不必先换算物质的量。

</details>

<details>
<summary>▶ 第3题详解（相对压力平衡常数表达式）</summary>

$$K_p=\dfrac{(p_{\mathrm{NH_3}}/p^\circ)^2}{(p_{\mathrm{N_2}}/p^\circ)(p_{\mathrm{H_2}}/p^\circ)^3}=\dfrac{p_{\mathrm{NH_3}}^2\,p^{\circ2}}{p_{\mathrm{N_2}}\,p_{\mathrm{H_2}}^3}$$

**易错提醒**：Kp必须用相对分压（除以p°），漏除p°会导致数量级错误。

</details>
