二、入库规则（AI 执行）

当您提供具体学科内容时，AI 将按以下流程执行入库：

入库步骤

  1. 识别科目：从指令中提取目标科目（语/数/英/物/化/生）
  2. 判断维度：根据内容性质归入四个二级维度之一
    • 概念/公式/定理 → 核心知识网络
    • 真题/模拟/题型 → 典型题型与方法
    • 错误/陷阱/辨析 → 易错警示与辨析
    • 素材/拓展/常识 → 素材与拓展
  3. 确定时间标签：根据当前学习阶段或内容深度标注 #高一筑基 / #高二深化 / #高三冲刺
  4. 评估难度：按 ★-★★★★★ 标注难度等级
  5. 标注试卷来源：
    • 语数英：标注 #新高考Ⅰ卷·广东 或 #新高考Ⅰ卷·江苏/山东/福建 等
    • 物化生：标注 #广东选择性考试 或 #广州一模 / #深圳一模 等
    • 教材同步内容标注具体教材章节
  6. 填写广东考情：说明该知识点在广东卷（或新高考Ⅰ卷广东考区）的考查频率、难度、特色
  7. 生成卡片：按 01_知识卡片模板.md 格式编写
  8. 文件命名：按 [时间标签]_[科目]_[维度]_[知识点名称].md 命名
  9. 放置目录：存入对应科目/维度的文件夹中
  10. 更新索引：在对应科目索引和总索引中更新卡片数量和状态统计

支持组合条件检索：

示例：

  • 查物理+易错警示与辨析+高二深化+电磁 — 物理高二电磁易错点

  • 查生物+典型题型与方法+高二深化+广东长句 — 生物高二长句表达类卡片

四、复盘规则（周复盘标准流程 · 2026-08 固化）

周复盘七步流程

  1. 收集材料：本周错题（拍照/文字均可）、感觉模糊的知识点、测验/练习成绩（注明来源：广东卷 / 新高考Ⅰ卷 / 校内练习）。
  2. 错题四分类：每道错题必须归入以下一类，处置动作不同——
错误类型判定标准处置动作
知识性错误概念/公式/定理本身没掌握匹配或新建「核心知识网络」卡片，状态标 ❌未理解
方法性错误知识会，但解题路径/题型通法不对匹配或新建「典型题型与方法」卡片，状态标 ⚠️待强化
审题性错误看错条件、漏隐含条件、答非所问匹配或新建「易错警示与辨析」卡片
计算性错误思路对但算错（符号/运算/抄写）不新建卡片，记入错题本"计算失误高发区"，做限时计算训练
  1. 匹配知识库：用 查[科目]+[关键词] 检索已有卡片；检索不到的错因当场入库（走第二节入库规则），实现"错题即卡片"。
  2. 标记状态：更新卡片元信息表的 状态 字段（✅/⚠️/❌），并同步 复盘追踪/知识掌握状态表.md；批量改状态后可运行 python build_status_table.py 重新生成状态表。
  3. 广东特色检查：重点核对 #广东特色 和 #广东卷 来源卡片的掌握情况；物化生错题额外回答一句："这道题是否符合广东卷命题风格？"
  4. 生成薄弱点清单：让 AI 输出「本周薄弱点清单 + 下周针对性补漏建议 + 推荐变式练习」（用下方模板四）。
  5. 重建与校准：改过任何 md 后运行 python build_site.py（重建 HTML + 断链校验）；统计数字有变时运行 python kb_audit.py 校准总索引。

状态标记规范

  • ✅ 已掌握：能独立、准确、快速完成相关题目，无知识盲区
  • ⚠️ 待强化：基本理解，但做题时偶有失误或速度较慢，需要定期复习
  • ❌ 未理解：概念模糊，无法独立解题，需要重新学习或请教老师

首次复盘启动（当前待办：全库掌握状态尚未破零）

现状：262张卡片全部为 ⚠️/❌，尚无一张 ✅。对 AI 说 「启动首次全库复盘」，按以下方式配合：
1. AI 逐科列出卡片清单（每次一科，避免一次过多）；
2. 自评标记有两条路，任选其一：
- 网页自助（推荐）：直接在卡片页点三键按钮 [❌][⚠️][✅] 标记，手机/电脑进度云同步（见下方"网页端「我的掌握」标记"）；
- 口述代标：你口述自评（能独立做题/偶有失误/不会），AI 负责改卡片状态字段和状态表；
3. 拿不准的卡片，AI 现场出1道快测题，做对了才标 ✅（防止"看懂了"误判为"掌握了"）；
4. 全部过完后 AI 运行 kb_audit.py + build_site.py 校准重建。
目标：2026.9 高二开学前，✅ 已掌握卡片 ≥10 张（650分计划关键成功指标）。

网页端「我的掌握」标记（每用户进度，2026-08 新增）

  • 卡片页三键标记：每张知识卡片顶部有 [❌未理解][⚠️待强化][✅已掌握] 按钮，点击即记录；再点一次当前状态 = 取消标记。
  • 每用户独立：进度存在浏览器本地（localStorage），同一浏览器可建多个用户（右上角 👤 菜单切换）。
  • 云同步（多设备）：右上角 👤 →「注册同步码」获得 6 位同步码；在其它设备的 👤 菜单选「输入同步码恢复」，或打开 Worker 的 /sync 恢复页，即可合并进度。同步码即钥匙，请妥善保存。
  • 进度可视化：索引页已标记卡片显示状态角标；复盘追踪 页顶部有个人仪表盘（六科掌握度、最近 7 天标记动态）。
  • 与静态状态表的关系：知识掌握状态表.md 是内容维护者视角的默认标记（由 md 元信息生成）；网页端三键标记是每个用户自己的进度，两者互不影响。
  • 注意：卡片 md 改名/移动目录会使该卡的进度失联（进度以文件路径为 ID）。

五、维护规则

卡片更新

  • 发现卡片内容有误或需要补充 → 直接修改原文件，保留修改记录
  • 同一知识点不同阶段有不同理解 → 创建新卡片，旧卡片标记为 #历史版本
  • 关联卡片新增 → 在原卡片「关联卡片」部分追加链接
  • 广东卷新真题发布后 → 及时补充 #广东选择性考试 / #新高考Ⅰ卷·广东 来源卡片

定期整理（建议每月）

  • [ ] 检查各科目文件夹是否有未分类的卡片
  • [ ] 检查卡片标签是否完整（科目+维度+时间+难度+试卷来源+广东特色）
  • [ ] 更新各科索引文件中的卡片清单
  • [ ] 清理无效或重复的卡片
  • [ ] 检查物化生卡片是否优先收录了广东卷及省内名校模拟题

六、常见问题

Q1：如何添加新的知识卡片？

A：直接告诉 AI 具体内容，例如：

"请入库：2025广东选择性考试·物理，第12题，关于电磁感应的导轨模型..."

AI 将自动按规则分类、标注试卷来源、填写广东考情、格式化并保存到正确位置。

Q2：如何修改已有卡片？

A：告诉 AI：

"请修改 [卡片标题]，将...改为..."

Q3：如何查看某科所有卡片？

A：使用指令：

"查[科目]+所有" 或 "列出[科目]的全部卡片"

Q4：如何查看广东卷相关的所有卡片？

A：使用指令：

"查所有+广东卷" 或 "查物理+广东特色"

Q5：英语听说考试的内容放哪里？

A：英语听说考试内容统一归入英语科目的「典型题型与方法」或「易错警示与辨析」维度，必须标注 #广东听说 标签。

Q6：复盘提醒如何关闭/调整？

A：告诉 AI 需要调整复盘频率或时间即可。

📌 核心原则：知识库是活的，不是一次性工程。贵在持续积累、定期复盘、动态更新。物化生优先广东卷，语数英兼顾新高考Ⅰ卷教育强省题目，关注广东特色命题风格。

模板四：周复盘（错题四分类）

1. 本周学校讲授的章节/专题：

请按以下步骤执行：
