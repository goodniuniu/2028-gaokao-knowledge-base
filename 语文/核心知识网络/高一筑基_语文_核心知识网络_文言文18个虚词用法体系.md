## 核心内容

### 一、知识网络（18个常见虚词及核心用法）

| 虚词 | 主要用法 | 课内/真题例句 |
|------|----------|---------------|
| **之** | ①代词（他/它）②结构助词"的"③主谓间取独④宾语前置标志 | 2023"不失君臣**之**礼"（助词"的"）；"是以先**之**"（代词） |
| **乎** | ①介词"于"②语气词③形容词词尾 | "生乎吾前"（于） |
| **者** | ①……的人/事②提顿③定语后置标志 | "不余欺**者**" |
| **也** | ①表判断②表语气 | "师**也**者，所以传道受业解惑也" |
| **以** | ①介词（用/凭/把/因）②连词（来/而）③通"已" | 2024"到兰干山南**以**分单于兵"（连，来）；2023"**是以**"（以+是，因此） |
| **于** | ①在②向③被（表被动）④比 | "不拘**于**时"（被） |
| **而** | ①顺承②转折③修饰④并列⑤通"尔" | 2023"骄侮**而**失礼"（转折）；2024"愧苏武**而**为之辞"（顺承） |
| **则** | ①就②那么③却 | "则**是**弃卫" |
| **为** | ①动词"做"②介词"替/被"③语气 | "**为**天下笑"（被） |
| **所** | ①所字结构②与"为"表被动 | "**所**畜积"（所字结构） |
| **其** | ①代词（他/它的）②语气副词 | "**其**莳也若子" |
| **乃** | ①于是②才③竟 | "**乃**以为西河守" |
| **且** | ①况且②暂且③将 | "**且**奈何"（将） |
| **因** | ①于是②趁③依靠 | "**因**归燕赵之兵" |
| **若** | ①像②如果③你 | "**若**甚怜焉" |
| **焉** | ①于此②语气③兼词 | "而卒以祸**焉**" |
| **何** | ①什么②怎么③宾语前置 | "**何**操"（操何） |
| **故** | ①所以②旧的③故意 | "**故**木受绳则直" |

### 二、核心结论
1. **虚词判定先看词性**：在句中作介词还是连词，决定译法（"以"表目的译"来"，表工具译"用"）。
2. **"之/是"为宾语前置标志**："是以"＝"以是"，须调序为"因此"。
3. **"于/为/所"表被动**：见此三标志优先考虑被动句式。
4. **通假优先**："乡"通"向"、"以"通"已"须先注通假。

### 三、易混点
- **而（转折 vs 顺承）**：前后意思相反用转折，先后相承用顺承。
- **以（介词 vs 连词）**：后接名词/代词为介词，连接分句为连词。
- **之（取独 vs 助词"的"）**：取消句子独立性时主谓间无"的"义。

### 四、真题母题印证
- **2023新高考Ⅰ卷·第13题**："是以先之"——"是以"宾语前置（以+是），"之"代词宾语，须"调+换"双得分点。
- **2024新高考Ⅰ卷·第13题**："到兰干山南以分单于兵"——"以"目的连词译"来"；"愧苏武而为之辞也"——"而"顺承连词。

## 参考答案

> 答案与题目分板块呈现，便于"先做后对"。每题给出规范解答 + 易错提醒，做完一题对一题。

<details>
<summary>▶ 第1题详解（"之"的多用）</summary>

**答案：A**

**解析**：
- ① "师道之不传也久矣"："之"位于主谓之间，取消句子独立性，即"取独"。
- ② "六艺经传皆通习之"："之"代指前文"六艺经传"，作宾语，是代词。
- ③ "句读之不知"：即"不知句读"，"之"是宾语前置的标志。
- ④ "古之学者必有师"："之"连接定语"古"与中心语"学者"，是结构助词"的"。

**易错提醒**："之"是虚词中用法最灵活的一个。判定顺序：先看是否在主谓间（取独），再看是否宾前标志，最后看是否代词或助词"的"。

</details>

<details>
<summary>▶ 第2题详解（"以"的连介辨析）</summary>

**答案**：

（1）**连词**，表目的，译为"来"。整句意为"到兰干山南来分散单于的军队"。

（2）第一个"以"是**介词**，译为"把"（"托臣以讨贼兴复之效"即"把讨贼兴复的重任托付给我"）；第二个"以"是**连词**，表目的，译为"来"（"来告慰先帝的在天之灵"）。

**辨析方法**："以"后接名词/代词，多为介词；"以"连接两个分句，多为连词。

**易错提醒**："以"作介词时常见译法：用、把、凭、因；作连词时常见译法：来、而。不要一看到"以"就按"因为"或"用"翻译。

</details>

<details>
<summary>▶ 第3题详解（"于"的被动用法）</summary>

**答案**："不拘于时"中的"于"表被动，译为"被"。整句意为"不被时俗限制"。

**课内例句**：
- "而君幸于赵王"（《廉颇蔺相如列传》）："于"表被动，意为"被赵王宠幸"。
- "则无望民之多于邻国也"（《寡人之于国也》）：此处"于"表比较，译为"比"，注意区分。
- "青，取之于蓝"（《劝学》）：此处"于"译为"从"，亦须注意区分。

**易错提醒**："于"可表"在/向/被/比"等多种意义，被动句中"于"引进动作施事。看到"于"要结合句式整体判断。

</details>
