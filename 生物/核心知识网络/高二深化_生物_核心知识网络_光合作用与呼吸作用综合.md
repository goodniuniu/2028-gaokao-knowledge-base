## 核心内容

### 一、知识网络（两过程关系总图）

```
                         O₂、[H]、ATP
   光反应（类囊体膜） ───────────→ 暗反应（叶绿体基质）
     H₂O → O₂ + [H]                    CO₂ + C₅ → 2C₃ →(还原)→ (CH₂O)
     ADP+Pi → ATP                      消耗[H]、ATP，再生C₅、ADP、Pi
          ↑                                  │
          └──────── ADP、Pi、NADP⁺ ───────────┘

   呼吸作用（细胞质基质+线粒体）：
     葡萄糖 →(有氧)→ CO₂ + H₂O + 能量(ATP)
     场所：第一阶段 细胞质基质；第二、三阶段 线粒体
   光合"产"的O₂可供呼吸；呼吸"产"的CO₂可供光合；二者在细胞内循环利用。
```

### 二、核心过程与结论

| 项目 | 光合作用 | 呼吸作用 |
|------|----------|----------|
| 本质 | 合成有机物、储能 | 分解有机物、放能 |
| 原料/产物 | CO₂+H₂O → (CH₂O)+O₂ | (CH₂O)+O₂ → CO₂+H₂O |
| 能量 | 光能→化学能（贮） | 化学能→ATP/热能（放） |
| [H] | NADPH（水光解） | NADH（糖分解、丙酮酸分解） |
| ATP | 仅供暗反应 | 全细胞通用 |

**关键结论**：
1. **净光合速率 = 总(真正)光合速率 − 呼吸速率**
   - 表观光合（净）= 环境CO₂吸收量 = O₂释放量 = 有机物积累量
   - 真正光合 = 净光合 + 呼吸 = 叶绿体内CO₂固定量 = O₂产生量
2. **光补偿点**：光合吸收CO₂ = 呼吸释放CO₂ 时的光照强度（此时净光合=0）。
3. **光饱和点**：光合速率不再随光强增加而增加的拐点。
4. 密闭容器/自然条件下：白天净光合积累，夜间只呼吸消耗；全天有机物积累 = Σ净光合 − 夜间呼吸。

### 三、易混点辨析（广东卷高频错区）

| 易混点 | 正解 | 典型误判 |
|--------|------|----------|
| "光合作用产生的O₂供全身" | 仅植物自身呼吸可用，释放到大气的O₂才对外 | 以为光合O₂直接供动物 |
| "净光合=总光合" | 净光合已扣除呼吸消耗，二者不等 | 把CO₂吸收量当总光合 |
| "光补偿点时植物不代谢" | 光合=呼吸，仍有旺盛代谢，净积累为0 | 以为此时植物"停止" |
| "遮阴一定减产" | 阴生/下层叶在弱光下净光合可能更高（光补偿点低） | 一概认为弱光不利 |
| "[H]、ATP减少C₃一定减" | 须同时看生成端（CO₂固定）与消耗端（C₃还原） | 只看一端必错 |

### 四、计算模板（四步）

1. **辨"率"**：题目给的是净光合还是总光合（看单位是"吸收/释放"还是"产生/固定"）。
2. **定关系**：总 = 净 + 呼吸。
3. **算昼夜**：全天积累 = 白天净光合总量 − 夜间呼吸总量。
4. **查单位**：统一"mg/h·单位叶面积"，注意"24h"与"光照h"的区别。

### 五、真题母题（广东卷，已核实）

**（2023 广东选择性考试·第18题，13分）** 水稻野生型(WT)与黄绿叶突变体(ygl)在高密度栽培下产量比较……

**第1题**（检验：净光合=总光合−呼吸——三率换算）
某植物在光照强度为 $500\,\mu\text{mol·m}^{-2}\text{·s}^{-1}$ 时，测得叶片从外界吸收CO₂的速率为 $15\,\text{mg CO}_2/\text{h·cm}^2$（净光合速率）；黑暗条件下释放CO₂的速率为 $5\,\text{mg CO}_2/\text{h·cm}^2$（呼吸速率）。求：（1）该光强下总（真正）光合速率；（2）叶绿体固定CO₂的速率。

**第2题**（检验：光补偿点——"光合=呼吸"的应用）
某阳生植物的光补偿点为 $100\,\mu\text{mol·m}^{-2}\text{·s}^{-1}$，光饱和点为 $800\,\mu\text{mol·m}^{-2}\text{·s}^{-1}$。请回答：
（1）在光补偿点时，植物是否生长（有机物是否积累）？为什么？
（2）若将该植物置于 $50\,\mu\text{mol·m}^{-2}\text{·s}^{-1}$ 的弱光下，植物能否长期存活？为什么？

**第3题**（检验：C₃/C₅动态——条件骤变分析）
某植物在适宜光照和CO₂浓度下正常进行光合作用。现突然将CO₂浓度降低到极低水平（光照不变）。请分析短期内（达到新平衡前）：
（1）C₃含量如何变化？原因是什么？
（2）C₅含量如何变化？原因是什么？

## 参考答案（请先独立完成自测训练，再展开核对）

> 答案与题目分板块呈现，便于"先做后对"。每题给出规范解答 + 易错提醒，做完一题对一题。

<details>
<summary>▶ 第1题详解（净光合=总光合−呼吸——三率换算）</summary>

**（1）总光合速率**：
$$\text{总光合} = \text{净光合} + \text{呼吸} = 15 + 5 = 20\,\text{mg CO}_2/\text{h·cm}^2$$

**（2）叶绿体固定CO₂的速率**：
叶绿体固定的CO₂ = 总光合固定的CO₂（包括净吸收+呼吸释放的CO₂被重新固定）：
$$= 15\,(\text{净吸收}) + 5\,(\text{呼吸释放后重新固定}) = 20\,\text{mg CO}_2/\text{h·cm}^2$$

即叶绿体固定CO₂的速率 = 总（真正）光合速率 = $20\,\text{mg CO}_2/\text{h·cm}^2$。

**答**：（1）总光合速率为 $20\,\text{mg CO}_2/\text{h·cm}^2$；（2）叶绿体固定CO₂速率为 $20\,\text{mg CO}_2/\text{h·cm}^2$。

> **易错提醒**：净光合=植物**从外界吸收**的CO₂；总光合=叶绿体**总共固定**的CO₂（=净吸收+自身呼吸释放又被固定的部分）；"总=净+呼吸"用CO₂表示即"总固定=净吸收+呼吸释放"。

</details>

<details>
<summary>▶ 第2题详解（光补偿点——光合=呼吸）</summary>

**（1）** 在光补偿点时，植物**不能生长**（有机物不积累）。
原因：光补偿点是净光合速率=0时的光照强度，即光合作用吸收的CO₂量 = 呼吸作用释放的CO₂量，光合合成的有机物 = 呼吸消耗的有机物，**净积累为0**。植物不能增加干重，不能生长（虽然此时代谢仍旺盛，但无净积累）。

**（2）** 在 $50\,\mu\text{mol·m}^{-2}\text{·s}^{-1}$ 的弱光下（低于光补偿点100），植物**不能长期存活**。
原因：光照低于光补偿点 → 净光合 < 0，即光合合成的有机物 < 呼吸消耗的有机物，有机物净消耗；长期下去植物消耗自身储存的有机物，最终因有机物耗竭而死亡。

> **易错提醒**：光补偿点"净光合=0"≠"植物不代谢"——植物仍旺盛代谢，只是光合=呼吸、净积累为0；长期低于光补偿点 → 净消耗 → 无法存活。

</details>

<details>
<summary>▶ 第3题详解（C₃/C₅动态——CO₂骤降）</summary>

**（1）C₃含量变化**：**下降**。
原因：CO₂浓度降低 → 暗反应中"CO₂+C₅→2C₃"的固定过程减弱 → C₃生成减少；而光照不变，光反应提供的[H]和ATP不变，C₃还原仍在进行（消耗C₃）→ C₃消耗不变、生成减少 → C₃含量下降。

**（2）C₅含量变化**：**上升**。
原因：CO₂浓度降低 → CO₂固定减弱，C₅消耗减少（C₅不再大量转化为C₃）；同时C₃还原仍在进行，C₅再生过程正常（C₃→C₅）→ C₅消耗减少、再生照常 → C₅积累上升。

**口诀验证**：CO₂降 → C₃降 C₅升（与"CO₂增则C₃增C₅减"相反）。

> **易错提醒**：C₃/C₅动态要同时看"生成端"和"消耗端"——CO₂降→C₃生成减少（固定端）、C₃消耗不变（还原端，光未变）→C₃净降；C₅消耗减少（固定端不再用C₅）、C₅再生不变（还原端继续产C₅）→C₅净升。

</details>
