## 核心内容

### 一、知识网络（基因工程操作流程）

```
获取目的基因 → 构建基因表达载体(核心) → 导入受体细胞 → 筛选与检测
   │                │                        │              │
 PCR/文库/合成   启动子+终止子+标记基因   农杆菌/显微注射/  DNA→mRNA→蛋白→
                   +复制原点+目的基因       Ca²⁺感受态       个体水平
```

### 二、核心工具酶

| 工具酶 | 功能 | 易错点 |
|--------|------|--------|
| **限制性内切核酸酶（限制酶）** | 识别特定序列，在特定位点切割DNA，产生黏性/平末端 | 一种酶识别一种特定序列；自身DNA被甲基化保护不被切 |
| **DNA连接酶** | 连接双链DNA片段，恢复磷酸二酯键 | E·coli连接酶连黏性末端；T4连接酶连黏性/平末端 |
| **Taq DNA聚合酶** | PCR中催化DNA延伸 | 热稳定；PCR**不需解旋酶**（高温变性代替） |

> 工具酶选择策略：双酶切（两种不同限制酶）→ 不同黏性末端 → 防自身环化与反向连接；不破坏目的基因与标记基因。

### 三、基因表达载体的核心组件

| 组件 | 功能 | 易错 |
|------|------|------|
| 目的基因 | 需要表达的基因 | — |
| 启动子 | RNA聚合酶识别结合，**驱动转录** | ≠起始密码子（后者在mRNA上） |
| 终止子 | 终止转录 | 使转录在需要处停止 |
| 标记基因 | 筛选含质粒的受体细胞（如抗生素抗性） | 还用于维持筛选压力、抑制杂菌 |
| 复制原点 | 质粒在宿主中自我复制 | 必备，否则不能稳定遗传 |

### 四、四步操作流程与要点

1. **获取目的基因**：PCR（需设计一对引物，从3'端延伸）、从基因文库获取、人工合成。
2. **构建表达载体（核心）**：目的基因+启动子+终止子+标记基因+复制原点 → 重组质粒。
3. **导入受体细胞**：植物→农杆菌转化法（最常用）；动物→显微注射（受精卵）；微生物→Ca²⁺感受态。
4. **筛选与检测**：DNA水平（是否导入）→ mRNA（是否转录）→ 蛋白质（是否翻译）→ 个体（是否发挥功能）。

### 五、PCR技术速记

| 步骤 | 温度 | 作用 |
|------|------|------|
| 变性 | 90~95℃ | 双链解开（无需解旋酶） |
| 复性(退火) | 55~60℃ | 引物与单链结合 |
| 延伸 | 70~75℃ | Taq酶催化延伸 |

### 六、真题母题（广东卷，已核实）

**（2022 广东选择性考试·第22题，选考，约14分）** 研究者以工业废气（含CO₂等）为原料，通过厌氧发酵（梭菌）生产丙酮。
- **(1)** 针对每个需要扩增的酶基因设计一对______，利用PCR技术扩增得到目标酶基因。（答：引物）
- **(2)** 表达载体pMTL80k包含启动子、终止子及抗生素抗性基因等，其中**抗生素抗性基因的作用是______**，**终止子的作用是______**。（答：作为标记基因筛选含表达载体的受体细胞；终止转录，使转录在需要的地方停下来）

**分析与答案要点**：本题精准覆盖"工具酶(PCR引物)+表达载体组件功能(启动子/终止子/标记基因)"两大核心，是基因工程基本操作的典型母题。

## 参考答案（请先独立完成自测训练，再展开核对）

> 答案与题目分板块呈现，便于"先做后对"。每题给出规范解答 + 易错提醒，做完一题对一题。

<details>
<summary>▶ 第1题详解（工具酶——双酶切策略）</summary>

**双酶切（用两种不同限制酶）的原因**：

- **防止自身环化**：若用同一种限制酶切目的基因和质粒，二者两端黏性末端相同，质粒切开后两端可重新连接（自身环化），形成不含目的基因的空质粒，降低重组效率。双酶切使质粒两端为不同黏性末端，无法自身环化。
- **保证定向连接**：双酶切使目的基因两端为不同的黏性末端，质粒两端也是对应的不同的黏性末端；目的基因只能以特定方向插入质粒（A端连A端、B端连B端），确保目的基因在启动子下游的正确方向插入，保证后续转录的正确性。
- **保护目的基因**：选择不在目的基因内部有识别位点的酶，避免切断目的基因。

> **易错提醒**：双酶切的核心理由是"防自身环化 + 定向连接"，不是"提高酶切效率"；还要注意不能破坏标记基因和目的基因。

</details>

<details>
<summary>▶ 第2题详解（四步流程——导入与筛选检测）</summary>

**（1）导入大肠杆菌的方法**：用**Ca²⁺（CaCl₂溶液）** 处理大肠杆菌，使其成为**感受态细胞**（细胞膜通透性增大），再将重组质粒加入，通过短暂热激（如42℃）使质粒进入细胞。

**（2）筛选原理**：利用质粒上的**标记基因**（如抗生素抗性基因）。将转化后的细菌涂布到含相应抗生素的固体培养基上，只有成功导入重组质粒（含抗性基因）的细菌才能存活形成菌落；未导入质粒的细菌被抗生素杀死。即"抗生素抗性筛选含重组质粒的受体细胞"。

**（3）分子水平检测转录**：用目的基因的DNA（或RNA）做探针，与提取的mRNA进行**分子杂交（DNA-RNA杂交）**——若有杂交带出现，说明目的基因已成功转录为mRNA。

> **易错提醒**：Ca²⁺处理大肠杆菌为感受态，是微生物转化专用；植物最常用农杆菌转化法，动物用显微注射法。检测转录用DNA-RNA杂交，检测翻译用抗原-抗体杂交（免疫印记），两者不要混淆。

</details>

<details>
<summary>▶ 第3题详解（PCR——温度步骤与引物）</summary>

**（1）PCR不需解旋酶的原因**：PCR利用**高温（90~95℃）** 使DNA双链变性解开为单链，高温代替了生物体内解旋酶的作用；且使用的Taq DNA聚合酶耐高温，在变性温度下仍保持活性，因此无需添加解旋酶。

**（2）引物**：
- **作用**：提供3′-OH端，使Taq DNA聚合酶能从3′端开始延伸合成新链（DNA聚合酶不能从头起始，必须依赖引物）。
- **数量**：需设计**一对（2条）特异性引物**，分别与模板两条链的3′端互补。
- **延伸方向**：从引物的**3′端**向5′端方向延伸（新链合成方向为5′→3′）。

**（3）PCR三个基本温度步骤**：
- **变性**（90~95℃）：双链解开为单链。
- **复性/退火**（55~60℃）：引物与单链模板结合。
- **延伸**（70~75℃）：Taq DNA聚合酶催化引物沿模板延伸。

> **易错提醒**：引物必答"一对"而非"一种"；延伸方向"从3′端"是细节得分点；"高温变性代替解旋酶"是不需解旋酶的核心理由，也是PCR区别于体内复制的最大特点。

</details>
