## 核心内容

### 一、模型总览与决策树

```
力学压轴题 → 多物体+多过程 → 识别模型
  ├── 两物体叠放/相对滑动 → 板块模型
  ├── 物体在运动的带上运动 → 传送带模型
  └── 涉及弹簧连接/弹性势能 → 弹簧模型（类碰撞）
```

> **核心思想**：三大模型本质都是**牛顿定律 + 运动学 + 能量/动量**的综合。解题关键是**分段分析**、**找临界点**、**画v-t图**。

---

### 二、板块模型（滑块-木板）

#### 2.1 核心问题
两物体叠放，外力作用于其中一个，判断是否相对滑动、求相对位移/摩擦生热/分离时间。

#### 2.2 解题通法

**第一步：求临界力 F₀（判断是否相对滑动）**

假设相对静止，整体法求加速度：$a_{整体} = F/(M+m)$

对上方物块用隔离法：$f = ma_{整体}$

若 $f ≤ f_{max} = μmg$ → 相对静止，用整体法

若 $f > f_{max}$ → 相对滑动，分别隔离列方程

**第二步：相对滑动时的动力学方程**

| 对象 | 受力分析 | 方程 |
|------|----------|------|
| 小物块 m | 滑动摩擦力 $f = μmg$（方向与相对运动相反） | $a_m = μg$ |
| 木板 M | 外力 F + 地面摩擦力 + 物块给的摩擦力 | $a_M = (F ± μmg ± f_{地})/M$ |

**第三步：运动学关系**

- 相对位移：$Δx = x_{木板} - x_{物块}$（或反之，看参考系）
- 摩擦生热：$Q = f_{滑} · |Δx|$
- 共速条件：$v_m = v_M$ 时，判断是否还能相对滑动（若外力仍作用，需重新判断）

#### 2.3 易错点
- 摩擦力方向：**与相对运动方向相反**，不是与运动方向相反
- 地面光滑 vs 地面粗糙：地面有摩擦时木板加速度不同
- 共速后若外力 F 仍存在，可能再次相对滑动，需重新判断

### 三、传送带模型

#### 3.1 分类
| 类型 | 特点 | 关键分析点 |
|------|------|----------|
| **水平传送带** | 带匀速转动，物体初速v₀ | 判断共速前是否滑出 |
| **倾斜传送带** | 带有倾角θ | 比较 $μ$ 与 $tanθ$ 判断能否静止 |
| **平斜交接** | 水平段→倾斜段 | 交接处速度衔接，重新判断摩擦力方向 |

#### 3.2 水平传送带通法

**情景一：物体初速 v₀，带速 v，同向**

| 条件 | 运动过程 | 痕迹长度 |
|------|----------|----------|
| v₀ < v，带足够长 | 先加速 $a=μg$，再共速匀速 | $Δx = v·t - x_{物} = v²/(2μg) - v₀²/(2μg)$ |
| v₀ > v，带足够长 | 先减速 $a=μg$，再共速匀速 | 类似 |
| 带长 L < 加速距离 | 一直加速，末速 $v' = √(v₀²+2μgL)$ | 全程滑动 |

**情景二：物体初速 v₀，带速 v，反向**

- 先减速到0，再反向加速
- 若 $v₀ ≥ v$：返回速度 = v（与带共速后匀速）
- 若 $v₀ < v$：返回速度 = v₀（对称性）

#### 3.3 能量与摩擦生热

- 摩擦生热：$Q = f_{滑} · Δx_{相对}$（**注意是相对位移，不是对地位移**）
- 多消耗的电能 = 物块动能变化 + 摩擦生热（能量守恒）

#### 3.4 广东情境示例
- 2023广东模拟：地铁安检行李传送带（水平+倾斜交接）
- 2024广东模拟：工厂流水线工件传输（多物体依次放上传送带）

### 四、弹簧模型（连接体/类碰撞）

#### 4.1 两类问题

| 类型 | 特征 | 核心方法 |
|------|------|----------|
| **弹簧连接体** | 弹簧连接两物体，受外力作用 | 整体法 + 隔离法，注意弹簧弹力不可突变 |
| **弹簧类碰撞** | 弹簧作为相互作用媒介，求最大压缩/分离 | 动量守恒 + 能量守恒（弹性势能参与） |

#### 4.2 弹簧连接体通法

- 弹簧弹力：$F = kx$（x 为形变量，注意原长位置）
- 平衡时：对连接体整体分析，求共同加速度，再隔离求弹簧形变量
- **关键**：弹簧弹力不可突变，但形变量可以渐变

#### 4.3 弹簧类碰撞（滑块-弹簧-滑块）

- **系统动量守恒**：$m₁v₁ + m₂v₂ = m₁v₁' + m₂v₂'$
- **系统能量守恒**：$rac{1}{2}m₁v₁² + rac{1}{2}m₂v₂² = rac{1}{2}m₁v₁'² + rac{1}{2}m₂v₂'² + E_p$

**临界条件**：两滑块速度相等时，弹簧压缩/伸长最大，弹性势能最大。

**求解方法**：
1. 动量守恒求共同速度：$m₁v₁ + m₂v₂ = (m₁+m₂)v_{共}$
2. 能量守恒求最大弹性势能：$E_{p,max} = E_{k初} - E_{k共}$

### 五、三大模型通用解题步骤

```
① 审题画情境图 → 标出已知量、未知量、各物体初速度
② 分段分析 → 按"速度变化点"分段（摩擦突变点、共速点、分离点）
③ 选对象列方程 → 整体法/隔离法交替使用
④ 运动学联立 → v-t图辅助分析，避免代数错误
⑤ 验证结果 → 检查物理意义（速度方向、位移正负、能量是否守恒）
```

## 自测训练（3道·覆盖板块·传送带·弹簧三大模型）

> 先独立完成，再展开卡片末尾「参考答案」核对。每题标注所检验的题型，方便对号查漏。

**第1题**（检验：板块模型——临界力判断 + 整体隔离法）
质量 $m=2\,\mathrm{kg}$ 的小物块放在质量 $M=4\,\mathrm{kg}$ 的长木板上，地面光滑，物块与木板间动摩擦因数 $\mu=0.3$。现对木板施加水平向右的拉力 $F$，$g$ 取 $10\,\mathrm{m/s^2}$，最大静摩擦力等于滑动摩擦力。求：
(1) 物块与木板恰好不发生相对滑动时，拉力 $F_0$ 的大小；
(2) 若 $F=30\,\mathrm{N}$，求物块和木板的加速度分别为多大。

**第2题**（检验：水平传送带模型——共速分析与摩擦生热）
一个工件（可视为质点）质量 $m=1\,\mathrm{kg}$，以初速度 $v_0=2\,\mathrm{m/s}$ 水平滑上足够长的水平传送带，传送带以 $v=6\,\mathrm{m/s}$ 匀速顺时针转动，工件与传送带间动摩擦因数 $\mu=0.2$，$g$ 取 $10\,\mathrm{m/s^2}$。求：
(1) 工件达到与传送带共速所用的时间；
(2) 全过程摩擦产生的热量 $Q$。

**第3题**（检验：弹簧类碰撞——动量守恒 + 能量守恒求最大弹性势能）
光滑水平面上，质量 $m_1=2\,\mathrm{kg}$ 的滑块以 $v_0=4\,\mathrm{m/s}$ 水平向右运动，与前方通过一轻质弹簧相连的质量 $m_2=2\,\mathrm{kg}$ 的静止滑块发生相互作用（弹簧处于原长，另一端固定在 $m_2$ 左侧），求：
(1) 弹簧被压缩至最短时两滑块的共同速度 $v_{共}$；
(2) 弹簧的最大弹性势能 $E_{p,\max}$。

## 参考答案（请先独立完成自测训练，再展开核对）

> 答案与题目分板块呈现，便于"先做后对"。每题给出规范解答 + 易错提醒，做完一题对一题。

<details>
<summary>▶ 第1题详解（板块模型——临界力判断 + 整体隔离法）</summary>

**(1) 临界力判断（假设相对静止，整体法求加速度）**

假设物块与木板相对静止，共同加速度：
$$a=\frac{F_0}{m+M}=\frac{F_0}{2+4}=\frac{F_0}{6}$$

隔离物块，其所受摩擦力恰好等于最大静摩擦力：
$$f_{\max}=\mu mg=0.3\times2\times10=6\,\mathrm{N}$$
$$f=ma=2\times\frac{F_0}{6}\le f_{\max}=6$$
$$\Rightarrow F_0\le18\,\mathrm{N}$$

**临界拉力 $F_0=18\,\mathrm{N}$**。

**(2) $F=30\,\mathrm{N}>18\,\mathrm{N}$，发生相对滑动，分别隔离**

对物块（受滑动摩擦力 $f=\mu mg=6\,\mathrm{N}$，方向向右）：
$$a_m=\frac{f}{m}=\frac{6}{2}=3\,\mathrm{m/s^2}$$

对木板（受拉力 $F$ 与物块给木板的摩擦力 $f'=6\,\mathrm{N}$ 反向，地面光滑无摩擦）：
$$a_M=\frac{F-f'}{M}=\frac{30-6}{4}=6\,\mathrm{m/s^2}$$

**答**：(1) $F_0=18\,\mathrm{N}$；(2) $a_m=3\,\mathrm{m/s^2}$，$a_M=6\,\mathrm{m/s^2}$。

> **易错提醒**：判断临界力的关键是"假设相对静止→整体法求 $a$→隔离上方物块→$ma\le\mu mg$"；$F>F_0$ 后必须分别隔离列方程，摩擦力对木板是反作用力，方向与物块所受摩擦力相反。

</details>

<details>
<summary>▶ 第2题详解（水平传送带模型——共速与摩擦生热）</summary>

**(1) 共速时间**

工件初速 $v_0=2\,\mathrm{m/s}<v=6\,\mathrm{m/s}$，受向右滑动摩擦力加速：
$$a=\mu g=0.2\times10=2\,\mathrm{m/s^2}$$

达到共速 $v=6\,\mathrm{m/s}$ 所需时间：
$$t=\frac{v-v_0}{a}=\frac{6-2}{2}=2\,\mathrm{s}$$

**(2) 摩擦生热 $Q=f\cdot|\Delta x_{相对}|$**

工件对地位移：
$$x_{物}=v_0t+\frac12at^2=2\times2+\frac12\times2\times2^2=8\,\mathrm{m}$$

传送带对地位移：
$$x_{带}=vt=6\times2=12\,\mathrm{m}$$

相对位移（传送带比工件多走的距离）：
$$|\Delta x|=x_{带}-x_{物}=12-8=4\,\mathrm{m}$$

摩擦生热：
$$Q=f\cdot|\Delta x|=\mu mg\cdot|\Delta x|=0.2\times1\times10\times4=8\,\mathrm{J}$$

**答**：(1) $t=2\,\mathrm{s}$；(2) $Q=8\,\mathrm{J}$。

> **易错提醒**：摩擦生热务必用**相对位移**计算，不能用对地位移；工件共速后匀速，摩擦力突变为零，不再生热。

</details>

<details>
<summary>▶ 第3题详解（弹簧类碰撞——动量守恒 + 能量守恒）</summary>

**(1) 弹簧压缩至最短时两滑块共速**

弹簧压缩至最短时两滑块速度相等（临界条件），水平方向动量守恒：
$$m_1v_0=(m_1+m_2)v_{共}$$
$$2\times4=(2+2)v_{共}\Rightarrow v_{共}=2\,\mathrm{m/s}$$

**(2) 最大弹性势能**

能量守恒（初动能 − 共速时动能 = 最大弹性势能）：
$$E_{p,\max}=\frac12m_1v_0^2-\frac12(m_1+m_2)v_{共}^2$$
$$=\frac12\times2\times4^2-\frac12\times4\times2^2=16-8=8\,\mathrm{J}$$

**答**：(1) $v_{共}=2\,\mathrm{m/s}$；(2) $E_{p,\max}=8\,\mathrm{J}$。

> **易错提醒**：弹簧问题中"压缩至最短/伸长至最长"对应"两物体共速"是核心临界条件；动量守恒要求系统水平方向合外力为零（光滑水平面）。

</details>
