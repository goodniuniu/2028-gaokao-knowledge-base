## 核心内容

### 错题1：斜面往返动能问题（单选）

**题目**：物体以100J的初动能从斜面底端沿斜面向上运动，当它向上通过斜面上某一点M时，其动能减少了80J，克服摩擦力做功32J，则物体返回到斜面底端时的动能为（　　）

A. 20J　　B. 48J　　C. 60J　　D. 68J

**错因分析**：
- 误把"动能减少80J"直接等同于"重力势能增加80J"，忽略了摩擦力也在消耗能量
- 没有建立**动能减少量 = 重力势能增加量 + 摩擦生热**的能量分配关系
- 对往返过程中摩擦力做功的特点不清晰

**正确解法**：

从底端 → M点：
- 动能减少 $\Delta E_k = 80\text{J}$，即 $W_{合} = -80\text{J}$
- 克服摩擦力做功 $W_{f1} = 32\text{J}$（摩擦力做负功 $-32\text{J}$）
- 由动能定理：$W_G + W_f = \Delta E_k$
- 即 $-mgh_M + (-32) = -80$
- 解得：**重力势能增加** $mgh_M = 80 - 32 = 48\text{J}$

**关键比例发现**：
- 在上升过程中，每减少80J动能，48J转化为重力势能，32J转化为摩擦热
- 势能增量 : 摩擦损耗 = $48 : 32 = 3 : 2$

从底端 → 最高点（设总动能减少100J）：
- 按 $3:2$ 比例分配：势能增量 = $100 \times \frac{3}{5} = 60\text{J}$，摩擦损耗 = $100 \times \frac{2}{5} = 40\text{J}$
- 即上升过程克服摩擦力做功 **40J**

往返全过程：
- 上升克服摩擦力做功 40J，下降克服摩擦力做功 40J（路程相同）
- 总摩擦损耗 = $40 + 40 = 80\text{J}$
- 返回底端时动能：$E_k = 100 - 80 = \boxed{20\text{J}}$，选 **A**

**方法提炼**：
> **比例法**：当斜面倾角不变、摩擦系数不变时，上升过程中**重力做功与摩擦力做功的比例恒定**。利用某一点的能量分配比例，可推算全程。

### 错题2：斜轨道+圆弧轨道模型（单选）

**题目**：斜轨道ab的下端与半径为 $r = 40\text{cm}$ 的圆轨道平滑连接。现在使质量为 $m = 100\text{g}$ 的小球从斜轨道上端距地面 $h = 2\text{m}$ 的a点由静止滑下，运动到圆形轨道的最高点c处时，对轨道的压力大小等于小球的重力大小，$g$ 取 $10\text{m/s}^2$，则小球从a运动到c的过程中克服摩擦力所做的功为（　　）

A. 0.2J　　B. 0.4J　　C. 0.6J　　D. 0.8J

**错因分析**：
- 对"最高点c处压力等于重力"的向心力分析不熟练，列错方程
- 忘记或错误计算c点相对于a点的高度差（$h - 2r$ 而非 $h$）
- 动能定理方程中功和动能的符号混乱

**正确解法**：

**第一步：分析最高点c的受力与速度**

小球在圆轨道最高点c，对轨道压力等于重力，即 $N = mg$。
由牛顿第三定律，轨道对小球支持力 $N' = mg$（方向向下，与重力同向）。

向心力方程（指向圆心向下）：
$$mg + N' = \frac{mv_c^2}{r}$$
$$mg + mg = \frac{mv_c^2}{r}$$
$$v_c^2 = 2gr = 2 \times 10 \times 0.4 = 8\text{ m}^2/\text{s}^2$$

**第二步：从a到c列动能定理**

初态（a点）：$v_a = 0$，$E_{ka} = 0$
末态（c点）：$E_{kc} = \frac{1}{2}mv_c^2 = \frac{1}{2} \times 0.1 \times 8 = 0.4\text{J}$

重力做功：小球下降高度为 $h - 2r = 2 - 0.8 = 1.2\text{m}$
$$W_G = mg(h - 2r) = 0.1 \times 10 \times 1.2 = 1.2\text{J}$$

设摩擦力做功为 $W_f$（负值），动能定理：
$$W_G + W_f = E_{kc} - E_{ka}$$
$$1.2 + W_f = 0.4 - 0$$
$$W_f = 0.4 - 1.2 = -0.8\text{J}$$

**克服摩擦力所做的功** = $|W_f| = \boxed{0.8\text{J}}$，选 **D**

**方法提炼**：
> **"先找临界速度，再算能量损失"**：涉及圆周轨道最高点的题目，通常先通过**向心力方程**求出临界速度，再通过**动能定理**或**机械能守恒**（含摩擦）计算能量损失。

### 共性知识点总结

| 考点 | 要点 |
|------|------|
| **动能定理的灵活选取** | 可以全程用，也可以分段用；优先全程 |
| **摩擦力做功** | 与路径有关，往返运动要乘2；$W_f = -f \cdot s_{路程}$ |
| **圆周运动最高点** | 先写 $F_{向} = \frac{mv^2}{r}$，再确定各力方向 |
| **能量分配** | 动能减少 = 势能增加 + 内能增加（摩擦热） |

### 高考真题变式训练

> **命题趋势**：动能定理是高考**5年4考**的高频考点。2024广东卷考查多过程动能定理应用（选择题），2024新课标卷/辽宁卷以计算题形式考查，2025广东卷第2道计算题明确要求"用动能定理求解外力做功和初末速度"。以下变式题均来自近年高考真题同类型。

**变式1（2024广东卷同类型 · 多过程+图像）**：

一物体从固定斜面底端以一定初速度沿斜面向上滑动，然后返回底端。以底端为原点，沿斜面向上为正方向建立 $x$ 轴。物体动能 $E_k$ 随位移 $x$ 变化的图像如图所示（上升过程为斜向下的直线，下降过程为斜向上的直线，两直线斜率不同）。已知上升最大位移为 $x_0$，上升过程末动能为0，返回底端时动能为 $\frac{1}{5}E_{k0}$。则（　　）

A. 上升过程摩擦力做功为 $\frac{2}{5}E_{k0}$  
B. 斜面倾角 $\theta$ 满足 $\sin\theta = \frac{3E_{k0}}{5mgx_0}$  
C. 物体与斜面间的动摩擦因数 $\mu = \frac{2}{3}\tan\theta$  
D. 上升与下降过程所用时间之比为 $1:2$

**解题思路**：
- 上升过程：$E_k$ 从 $E_{k0}$ 减到0，$W_{合} = -E_{k0} = -(mg\sin\theta + \mu mg\cos\theta)x_0$
- 下降过程：$E_k$ 从0增到 $\frac{1}{5}E_{k0}$，$W_{合} = \frac{1}{5}E_{k0} = (mg\sin\theta - \mu mg\cos\theta)x_0$
- 联立解得：$mg\sin\theta \cdot x_0 = \frac{3}{5}E_{k0}$，$\mu mg\cos\theta \cdot x_0 = \frac{2}{5}E_{k0}$
- 故 $\mu = \frac{2}{3}\tan\theta$，选 **C**

**变式2（2022福建卷同类型 · 斜面往返）**：

一物块以初速度 $v_0$ 自固定斜面底端沿斜面向上运动，一段时间后回到斜面底端。已知斜面倾角为 $\theta$，物块与斜面间的动摩擦因数为 $\mu$（$\mu < \tan\theta$），重力加速度为 $g$。则物块（　　）

A. 上升过程中加速度大小为 $g(\sin\theta + \mu\cos\theta)$  
B. 上升的最大高度为 $\frac{v_0^2}{2g(1 + \mu\cot\theta)}$  
C. 返回底端时的速度大小为 $v_0\sqrt{\frac{\sin\theta - \mu\cos\theta}{\sin\theta + \mu\cos\theta}}$  
D. 整个过程中摩擦生热为 $\frac{\mu mv_0^2\cos\theta}{2(\sin\theta + \mu\cos\theta)}$

**解题思路**：
- 上升：$a_{上} = g(\sin\theta + \mu\cos\theta)$，**A正确**
- 最大位移：$x = \frac{v_0^2}{2a_{上}} = \frac{v_0^2}{2g(\sin\theta + \mu\cos\theta)}$
- 最大高度：$h = x\sin\theta = \frac{v_0^2\sin\theta}{2g(\sin\theta + \mu\cos\theta)} = \frac{v_0^2}{2g(1 + \mu\cot\theta)}$，**B正确**
- 全程动能定理：$-2\mu mg\cos\theta \cdot x = \frac{1}{2}mv^2 - \frac{1}{2}mv_0^2$
- 解得 $v = v_0\sqrt{\frac{\sin\theta - \mu\cos\theta}{\sin\theta + \mu\cos\theta}}$，**C正确**
- 摩擦生热：$Q = 2\mu mg\cos\theta \cdot x = \frac{\mu mv_0^2\cos\theta}{\sin\theta + \mu\cos\theta}$，**D错误**（系数应为1不是1/2）

**变式3（2025广东卷计算题同类型 · 动能定理+功率）**：

一质量为 $m = 2\text{kg}$ 的物体在水平拉力 $F$ 作用下沿粗糙水平面从静止开始做匀加速直线运动，运动 $t = 4\text{s}$ 后撤去拉力，物体又滑行 $x = 8\text{m}$ 后停止。已知水平面动摩擦因数 $\mu = 0.2$，$g = 10\text{m/s}^2$。求：

（1）撤去拉力时物体的速度大小；  
（2）拉力 $F$ 的大小；  
（3）拉力 $F$ 的平均功率。

**解题思路**：
- （1）撤去拉力后：$-\mu mgx = 0 - \frac{1}{2}mv^2$，$v = \sqrt{2\mu gx} = \sqrt{32} = 4\sqrt{2}\text{m/s}$
- （2）全过程：$Fs_1 - \mu mg(s_1 + x) = 0$，其中 $s_1 = \frac{v}{2}t = 2\sqrt{2} \times 4 = 8\sqrt{2}\text{m}$... 或用牛顿定律：$F - \mu mg = ma$，$v = at$，$a = \sqrt{2}\text{m/s}^2$，$F = 2\sqrt{2} + 4 = (2\sqrt{2} + 4)\text{N}$
- （3）$P = F \cdot \bar{v} = F \cdot \frac{v}{2} = ...$（略）

> **方法归纳**：近年高考动能定理考查三大模式：
> 1. **斜面往返模式**：全程优先，注意摩擦力往返做功与单程的关系
> 2. **圆弧临界模式**：先向心力方程求速度，再动能定理求能量损失
> 3. **多过程+功率模式**：分阶段列动能定理，结合功率公式 $P = Fv$ 或 $P = W/t$

### 题型识别标志（陷阱信号）

| 题干/选项信号 | 触发陷阱 | 立即动作 |
|------|------|------|
| "物体以某初动能上滑，动能减少ΔE，克服摩擦做功Wf" | 把"动能减少"直接当"势能增加"（漏算摩擦生热） | 列 ΔE_k = ΔEp + Q，先求能量分配比例再推全程 |
| "斜面往返 / 上升后下降回到底端" | 往返摩擦做功只算单程 | 摩擦力与路径有关，全程 W_f = −f·(2s_单程)，必须乘 2 |
| "圆弧轨道最高点/末端，对轨道压力 = mg" | 向心力方程列错（力方向判反、漏重力或漏支持力） | 先写 F_向 = mv²/r，再判各力方向（绳/轨道向内、杆可向外、末端支持力向上） |
| "高度差取 h 还是 h−2r" | 圆轨道末态高度取错 | 圆轨道最高点相对起点高 h−2r；1/4 圆弧末端（切线水平）相对起点高 h−R |
| "多过程：先加速后撤力滑行" | 分段/全程动能定理不会选 | 优先全程 W_合 = ΔE_k；含摩擦多段可分段列式 |
| "给 E_k−x / v−t 图像求功" | 斜率/面积意义混淆 | E_k−x 图斜率 = 合外力；动能变化 = 各段功的代数和 |

### 标准化纠错路径（能量分配 + 临界速度分流）

**一、斜面往返 / 多过程能量分配**
1. **定基准**：明确初末状态动能，列 ΔE_k = W_合。
2. **拆做功**：重力做功 ±mgh、摩擦力做功 −f·s_路程（往返乘 2）、其他力做功单列。
3. **找比例**：同一斜面倾角、同 μ 时，上升段 ΔE_k = ΔEp + Q 的比例恒定，用一点推全程（如错题1）。

**二、圆弧轨道临界问题**
1. **先求速度**：在轨道最高点/末端列向心力方程 F_向 = mv²/r，由各力方向定 v（如 N+mg=mv²/r，或 F_N−mg=mv²/R）。
2. **再算能量损失**：从起点到该点列动能定理 W_G + W_f = E_k末 − E_k初，解克服摩擦功或末动能。
3. **验高度**：确认末态相对起点的竖直高度（圆轨道顶 h−2r，1/4 圆弧末端 h−R）。

### 真题母题（2023 广东卷 T8）

**题**：人们用滑道从高处向低处运送货物。可看作质点的货物从 1/4 圆弧滑道顶端 P 点静止释放，沿滑道运动到圆弧末端 Q 点时速度大小为 6 m/s。已知货物质量为 20 kg，滑道高度 h 为 4 m，且过 Q 点的切线水平，重力加速度取 10 m/s²。关于货物从 P 点运动到 Q 点的过程，下列说法正确的有（　　）
A. 重力做的功为 360 J
B. 克服阻力做的功为 440 J
C. 经过 Q 点时向心加速度大小为 9 m/s²
D. 经过 Q 点时对轨道的压力大小为 380 N

**错解**：A 误把末动能当重力功，算成 360 J（漏算阻力、忘 W_G=mgh=800 J）；C 错代半径，以为 a=v²/h 无依据；D 列错向心力方程（漏重力或把支持力方向搞反），得 200 N 或 580 N。
**正解**：
- A：重力做功 W_G = mgh = 20×10×4 = 800 J，A 错。
- B：由动能定理 W_G − W_f = ½mv² ⇒ 800 − W_f = ½×20×36 = 360 ⇒ **克服阻力 W_f = 440 J**，B 对。
- C：1/4 圆弧滑道半径 R = h = 4 m，Q 点向心加速度 a = v²/R = 36/4 = **9 m/s²**，C 对。
- D：Q 点向心方程 F_N − mg = mv²/R ⇒ F_N = 200 + 180 = **380 N**，由牛顿第三定律对轨道压力 380 N，D 对。
⇒ 答案选 **BCD**。
**避错要点**：本题同时命中本卡错题2的"先向心力求速度、再动能定理算能量损失"套路与"圆周运动先写 F_向 = mv²/r、判各力方向"。B 是动能定理标准应用（重力功减阻力功等于动能增量）；C、D 是 1/4 圆弧末端临界——注意 Q 点切线水平、半径 R = h，向心力由"支持力 − 重力"提供。这正是广东卷把"圆弧轨道 + 动能定理 + 向心力"融于一题的命题偏好（同见 2023 广东 T15 药品传送）。

<summary>▶ 第1题详解（斜面往返能量分配）</summary>

由 $M$ 点信息：动能减少 $\Delta E_k=60\,\text{J}$，克服摩擦力做功 $W_{f1}=24\,\text{J}$，故重力势能增加量为

上升段能量分配比例：$\Delta E_p:Q=36:24=3:2$。

从底端到最高点，动能共减少 $120\,\text{J}$，按 $3:2$ 分配得：
- 重力势能增量 $=120\times\dfrac{3}{5}=72\,\text{J}$，
- 摩擦生热 $=120\times\dfrac{2}{5}=48\,\text{J}$。

即上升过程克服摩擦力做功 $48\,\text{J}$；往返路程相同，下降过程克服摩擦力做功也为 $48\,\text{J}$。总摩擦损耗 $96\,\text{J}$，返回底端时动能为
$$E_k=120-96=\boxed{24\,\text{J}}.$$

**答**：选 **B**。

**易错提醒**：不能直接把“动能减少量”当作“重力势能增加量”，必须先扣除摩擦生热；往返运动摩擦力做功要乘 2。

</details>

<details>
<summary>▶ 第2题详解（圆弧轨道临界 + 动能定理）</summary>

在最高点 $c$，轨道对小球支持力 $N'=2mg$（向下，与重力同向），故
$$mg+N'=\frac{mv_c^2}{r}\Rightarrow 3mg=\frac{mv_c^2}{r}.$$
解得 $v_c^2=3gr=3\times10\times0.5=15\,\text{m}^2/\text{s}^2$，$E_{kc}=\dfrac12mv_c^2=\dfrac12\times0.2\times15=1.5\,\text{J}$。

从 $a$ 到 $c$，重力做功 $W_G=mg\Delta h=0.2\times10\times2.0=4.0\,\text{J}$。设摩擦力做功为 $W_f$，由动能定理：
$$W_G+W_f=E_{kc}-0\Rightarrow 4.0+W_f=1.5,$$
得 $W_f=-2.5\,\text{J}$，故克服摩擦力做功为 $\boxed{2.5\,\text{J}}$。

**答**：选 **D**。

**易错提醒**：注意最高点压力方向向下，向心力方程不要漏掉重力；高度差是 $h_{ac}=2.0\,\text{m}$，不是 $r$ 或 $2r$。

</details>

<details>
<summary>▶ 第3题详解（动能定理适用条件）</summary>

- **A 正确**：动能定理只需初末动能和总功，对变力做功特别有效。
- **B 正确**：摩擦力做功 $W_f=-f\cdot s_{路程}$，往返时 $s_{路程}$ 是单程的两倍。
- **C 正确**：$W_{合}=\Delta E_k$ 只关心初末状态，不依赖中间过程。
- **D 错误**：动能定理是标量方程，不能分解到某一方向单独使用。

**答**：选 **ABC**。

**易错提醒**：动能定理的“总功”是所有外力做功的代数和，且功是标量；动能本身也没有方向，不能按分量列式。

</details>
