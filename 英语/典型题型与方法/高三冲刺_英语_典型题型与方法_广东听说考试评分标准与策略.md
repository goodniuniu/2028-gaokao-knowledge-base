## 核心内容

### 题型识别标志
> **看到什么环节 → 立刻想到什么抢分路径**

| 考试环节 | 识别为 | 首选策略 |
|---------|--------|----------|
| Part A 观看片段+模仿朗读 | 模仿朗读（20分） | 第一遍静听抓生词/重音/连读；影子跟读；正式录不回读 |
| Part B 中文提示提3问+听答5问 | 角色扮演（16分） | 三问：疑词前置+核心动词提句首；五答：前两答出自首遍对话，后三答出自计算机回答 |
| Part C 听2遍独白+复述 | 故事复述（24分） | 第一遍记核心动词链，第二遍补名词/adj；用五大基本句型串，勿背原文 |

### 解题路径（三题型评分拆解+策略）

#### 第一步：Part A 模仿朗读（20分）
**评分维度**（已核验）：
- 语音语调：A 8-12（清晰准确、自然连贯）/ B 4-7 / C 0-3
- 语速与内容：A 6-8（原速、漏≤3词）/ B 3-5 / C 0-2
**策略**：首遍播放**不跟读**，专听生词重音+连读失爆+语调；1分钟自主练攻克难点句；正式录重音明确、按意群停顿、轻微口误不回溯。

#### 第二步：Part B 角色扮演（16分）
**评分维度**（已核验）：提问（3问）语言 1.5/1/0 + 信息 0.5/0；回答（5答）语言+信息分层计分。
**策略**：
- 三问黄金模板：一般疑问"核心动词+主+谓"（Can you…?）；特殊疑问"5W1H+核心动词+主+谓"（Why are you…?）；用"陈述句变形术"兜底。
- 五答：前2答出自首遍对话（抓时间/数字/地名），后3答出自计算机回答（播2遍，抓 and/but/because 后信息）；速记用符号不写全词。

#### 第三步：Part C 故事复述（24分）
**评分维度**（已核验）：内容 8-12/4-7/0-3 + 语言 3-4/2/0-1 + 流利 4-5/2-3/0-1 + 语音 3/2/1。
**策略**：听前看关键词预判；第一遍记3个核心情节节点（动词链），第二遍补细节；1分钟用五大基本句型串成完整故事；尽量用自己的话，不硬背原文。

### 母题（广东听说考试评分标准，官方档位已核验）

> **Part A 档位示例**：考生发音清晰、语调自然、按原速且内容完整（漏≤3词）→ 语音语调A(8-12)+语速内容A(6-8)=**满分20**。
> **Part C 档位示例**：涵盖大多信息点+语言规范+流利+语音不影响理解 → 内容A(8-12)+语言A(3-4)+流利A(4-5)+语音A(3)=**满分24**。

> 💡 **关键技巧**：听说"准+齐"两准则——单词读准（不吞音）、信息读齐（不漏词）；回读/卡顿扣分远多于单个词轻错，保持语流连贯最划算。

## 自测训练（3道·覆盖Part A朗读策略·Part B三问五答评分·Part C内容完整度）

> 先独立完成，再展开卡片末尾「参考答案」核对。每题标注所检验的题型，方便对号查漏。

**第1题**（检验：Part A 朗读评分维度 —— 语音语调/语速内容）

判断以下考生的 Part A 表现属于哪个档位（A/B/C），并说明理由。

```
考生表现：发音基本清晰，但有3个词的尾音吞掉（如 likes 读成 like）；语速
与原音基本一致，完整朗读全文未漏词；偶有1处不自然停顿。
```

Q: 该考生的"语速与内容"维度最可能属于哪个档位？
A. A档（6-8分）　　B. B档（3-5分）　　C. C档（0-2分）

**第2题**（检验：Part B 三问评分 —— 语言+信息分层）

以下是某考生的三问翻译，请判断是否有语言错误并改正。

```
中文提示：你通常怎样去上学？
考生翻译：How you usually go to school?
```

**第3题**（检验：Part C 内容完整度 —— 信息点覆盖）

阅读以下故事梗概，列出 Part C 复述必须覆盖的5个核心信息点。

```
故事梗概：Tom 想给妈妈买生日礼物，但钱不够。店长帮他打折，他买下了花瓶。
回家路上花瓶摔碎了，他很伤心。妈妈说心意最重要，Tom 露出了笑容。
关键词：Tom, birthday gift, not enough money, manager discount, vase broke,
moved, smile
```

## 参考答案（请先独立完成自测训练，再展开核对）

> 答案与题目分板块呈现，便于"先做后对"。每题给出规范解答 + 易错提醒，做完一题对一题。

<details>
<summary>▶ 第1题详解（Part A 评分维度判断）</summary>

**答案：A. A档（6-8分）**

分析：语速与内容维度看"是否原速+漏词情况"。该考生"语速与原音一致 + 完整朗读未漏词"→ 符合 A 档标准（原速、漏≤3词）。尾音吞音与1处停顿影响的是"语音语调"维度（可能判B），但"语速与内容"维度仍为A。

> **易错提醒**：三维度分开评分——语音语调、语速内容各自独立定档；尾音吞音扣的是"语音语调"分，不是"内容"分。

</details>

<details>
<summary>▶ 第2题详解（Part B 三问语言错误改正）</summary>

**错误**：疑问句语序错误（陈述语序）。

```
原句：How you usually go to school?（× 缺助动词 do）
改正：How do you usually go to school?（√ 疑问词+助动词+主语+动词原形）
```

> **易错提醒**：特殊疑问句 = 疑问词 + 助动词（do/does/did）+ 主语 + 动词原形；助动词后动词回原形；usually 不能漏译（是采分点）。

</details>

<details>
<summary>▶ 第3题详解（Part C 核心信息点）</summary>

5个核心信息点：

```
① 人物+动机：Tom 想给妈妈买生日礼物（birthday gift for mother）
② 困难：钱不够（not enough money）
③ 转机：店长打折，买下花瓶（manager discount, bought vase）
④ 挫折：回家路上花瓶摔碎，Tom 伤心（vase broke, sad）
⑤ 结局/升华：妈妈说心意最重要，Tom 笑了（thought matters, smiled）
```

> **易错提醒**：Part C 内容分权重最高（8-12分），5个核心信息点缺一扣分严重；按"动机→困难→转机→挫折→结局"顺序梳理，确保主线完整。

</details>
