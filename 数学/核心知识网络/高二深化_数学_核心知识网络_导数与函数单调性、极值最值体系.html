导数与函数单调性、极值最值体系

⚠️待强化★★★★☆#高二深化#新高考Ⅰ卷·广东来源：人教A版选择性必修二 / 2024新课标Ⅰ卷第10题（极值判定）
广东考情：考查频率：高频（导数压轴必用）· 中档至压轴 · 单调性⇔导函数符号、极值⇔导函数零点变号、最值⇔极值+端点，是导数大题的"操作系统" · 真题锚定：2024新高考Ⅰ卷T10（f(x)=(x-1)²(x-4)极值）

核心内容

本质理解：导数是"函数变化的显微镜"。$f'(x)>0$ 增、$f'(x)<0$ 减；极值发生在 $f'(x)=0$ 且变号处；最值是极值与端点比较的胜者。

一、知识网络

导数工具
 ├─ 求导：公式+四则+复合（链）
 ├─ 单调性：f'(x)>0 ⇔ 增区间；<0 ⇔ 减区间
 ├─ 极值：f'(x)=0 且左右变号（极大：+→−；极小：−→+）
 ├─ 最值：区间内极值 + 端点值 比较取最大/最小
 └─ 含参讨论：按 f'(x)=0 的根与区间位置分类

二、核心公式/结论

结论内容注意
单调判定$f'(x)>0\Rightarrow$ 增；$<0\Rightarrow$ 减等号仅在孤立点可取
极值第一充分条件$f'(x)$ 在 $x_0$ 左正右负→极大；左负右正→极小须变号
极值第二充分条件$f'(x_0)=0,\ f''(x_0)<0$→极大仅当 $f''$ 存在且非0
最值$\max/\min\{$ 各极值, 端点值 $\}$闭区间必有最值
含参分类按 $f'(x)=0$ 根与定义域/区间关系画数轴标根

三、易混点

易混点正解错法
$f'(x_0)=0$未必极值（如 $y=x^3$ 在0）见导数为0即判极值
极值 vs 最值局部 / 全局混淆两者
单调增区间端点可含使 $f'=0$ 的孤立点误开区间丢点
含参讨论根可能落在区间外漏讨论根的位置

真题母题（2024 新课标Ⅰ卷·第10题，6分）

题目：设函数 $f(x)=(x-1)^2(x-4)$，则（ ） A. $x=3$ 是 $f(x)$ 的极小值点 B. 当 $0f(x)$

解析： $f'(x)=2(x-1)(x-4)+(x-1)^2=3(x-1)(x-3)$。 单调表：$(-\infty,1)$ 增、$(1,3)$ 减、$(3,+\infty)$ 增。 A：$x=3$ 左减右增→极小值点，对。 B：$0f(x^2)$，B错。 C：$10$，D对。 答案：ACD。

关键提炼：本题是"求导→单调表→判极值/比大小"的范式，导数是分析一切的源头。

参考答案

答案与题目分板块呈现，便于"先做后对"。每题给出规范解答 + 易错提醒，做完一题对一题。

▶ 第1题详解（求导定单调性 + 极值判定）

求导：$f'(x) = 3x^2 - 6x = 3x(x-2)$。

令 $f'(x) = 0$：$x_1 = 0$，$x_2 = 2$。

列表分析 $f'(x)$ 符号：

$x$$(-\infty, 0)$$0$$(0, 2)$$2$$(2, +\infty)$
$f'(x)$$+$$0$$-$$0$$+$
$f(x)$递增极大值递减极小值递增
  • 在 $(-\infty, 0)$ 和 $(2, +\infty)$ 上单调递增，在 $(0, 2)$ 上单调递减。
  • 极大值：$f(0) = 0 - 0 + 2 = 2$；极小值：$f(2) = 8 - 12 + 2 = -2$。

易错提醒：$f'(x_0)=0$ 只是极值必要条件，必须看 $f'(x)$ 在 $x_0$ 左右是否变号。如 $y=x^3$ 在 $x=0$ 处 $f'(0)=0$ 但左右同号，不是极值。

▶ 第2题详解（闭区间最值：极值 + 端点比较）

求导：$f'(x) = 3x^2 - 12x + 9 = 3(x-1)(x-3)$。

令 $f'(x) = 0$：$x_1 = 1$，$x_2 = 3$，均在 $[0, 4]$ 内。

计算极值和端点值：

  • $f(0) = -3$
  • $f(1) = 1 - 6 + 9 - 3 = 1$（极大值）
  • $f(3) = 27 - 54 + 27 - 3 = -3$（极小值）
  • $f(4) = 64 - 96 + 36 - 3 = 1$

比较：$\max = 1$（在 $x=1$ 和 $x=4$ 处），$\min = -3$（在 $x=0$ 和 $x=3$ 处）。

答：最大值 $1$，最小值 $-3$。

易错提醒：闭区间上最值 = 极值 + 端点值 比较。必须逐一计算所有驻点和端点的函数值，不能只比较驻点。本题端点 $x=4$ 恰取最大值，漏算必错。

▶ 第3题详解（含参讨论：根的位置分类）

求导：$f'(x) = x^2 - ax + 1$，判别式 $\Delta = a^2 - 4$。

情形1：$a^2 \le 4$（$-2 \le a \le 2$），$\Delta \le 0$，$f'(x) \ge 0$ 恒成立，$f(x)$ 在 $\mathbb{R}$ 上单调递增。（$a = \pm 2$ 时仅在孤立点 $f'=0$，不影响单调性。）

情形2：$a^2 > 4$（$a > 2$ 或 $a < -2$），$\Delta > 0$，$f'(x)=0$ 有两根 $x_1 = \dfrac{a-\sqrt{a^2-4}}{2} < x_2 = \dfrac{a+\sqrt{a^2-4}}{2}$。

$f'(x)$ 符号：$(-\infty, x_1)$ 正、$(x_1, x_2)$ 负、$(x_2, +\infty)$ 正。

故 $f(x)$ 在 $(-\infty, x_1)$ 和 $(x_2, +\infty)$ 上递增，在 $(x_1, x_2)$ 上递减。

答：当 $-2 \le a \le 2$ 时，$f(x)$ 在 $\mathbb{R}$ 上单调递增；当 $a > 2$ 或 $a < -2$ 时，$f(x)$ 在 $\left(-\infty, \dfrac{a-\sqrt{a^2-4}}{2}\right)$ 和 $\left(\dfrac{a+\sqrt{a^2-4}}{2}, +\infty\right)$ 上递增，在 $\left(\dfrac{a-\sqrt{a^2-4}}{2}, \dfrac{a+\sqrt{a^2-4}}{2}\right)$ 上递减。

易错提醒：含参讨论关键是看 $f'(x)=0$ 的根是否存在、是否在定义域内。以 $\Delta = 0$ 为分界点分类，不遗漏 $\Delta = 0$（仅一个重根，不改变单调性）和 $\Delta < 0$（无根，$f'$ 恒正或恒负）两种情形。
