## 核心内容

### 一、直线的交点坐标与距离公式
- **两直线交点**：联立 $A_1 x + B_1 y + C_1 = 0$ 与 $A_2 x + B_2 y + C_2 = 0$ 求解
- **两点间距离**：$|P_1 P_2| = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$
- **点到直线距离**：点 $P(x_0, y_0)$ 到直线 $Ax + By + C = 0$ 的距离 $d = \frac{|Ax_0 + By_0 + C|}{\sqrt{A^2 + B^2}}$
- **两平行线距离**：$Ax + By + C_1 = 0$ 与 $Ax + By + C_2 = 0$ 的距离 $d = \frac{|C_1 - C_2|}{\sqrt{A^2 + B^2}}$（$C_1 \neq C_2$）

### 二、圆的方程
- **标准方程**：$(x - a)^2 + (y - b)^2 = r^2$（$r > 0$），圆心 $(a, b)$，半径 $r$
- **一般方程**：$x^2 + y^2 + Dx + Ey + F = 0$（$D^2 + E^2 - 4F > 0$）
  - 圆心：$(-\frac{D}{2}, -\frac{E}{2})$，半径：$r = \frac{\sqrt{D^2 + E^2 - 4F}}{2}$

### 三、点与圆的位置关系
点 $M(x_0, y_0)$ 与圆 $C: (x - a)^2 + (y - b)^2 = r^2$：
- 点在圆内：$(x_0 - a)^2 + (y_0 - b)^2 < r^2$
- 点在圆上：$(x_0 - a)^2 + (y_0 - b)^2 = r^2$
- 点在圆外：$(x_0 - a)^2 + (y_0 - b)^2 > r^2$

### 四、直线与圆的位置关系
设圆心到直线距离为 $d$，半径为 $r$：
- $d < r$：相交（弦长 $= 2\sqrt{r^2 - d^2}$）
- $d = r$：相切
- $d > r$：相离

### 五、圆与圆的位置关系
设两圆圆心距为 $d$，半径分别为 $r_1, r_2$：
- $d > r_1 + r_2$：外离
- $d = r_1 + r_2$：外切
- $|r_1 - r_2| < d < r_1 + r_2$：相交
- $d = |r_1 - r_2|$：内切
- $d < |r_1 - r_2|$：内含

## 解题路径（圆上点与直线·数形结合五步）

### 第一步：写圆与直线方程
写出圆心 $M$、半径 $r$；直线化为一般式 $Ax+By+C=0$。

### 第二步：求圆心到直线距离
$$d=\frac{|Ax_0+By_0+C|}{\sqrt{A^2+B^2}}.$$

### 第三步：定距离范围
圆上点到该直线的距离 $\in[d-r,\ d+r]$，据此判断最值选项。

### 第四步：角的极值
过定点 $B$ 作圆的切线，切点处 $\angle PBA$ 取得最小或最大。

### 第五步：勾股定理求切线长
$$|PB|=\sqrt{|BM|^2-r^2}.$$

> **易错提醒**：把圆心到直线距离当成了点到直线距离的最值；忘记切线长公式而直接猜；未判断选项是否"一定成立"。

## 母题（2021 新课标Ⅰ卷·第11题，5分）

**题目**：已知点 $P$ 在圆 $(x-5)^2+(y-5)^2=16$ 上，点 $A(4,0)$，$B(0,2)$，则（　）
A. 点 $P$ 到直线 $AB$ 的距离小于 $10$
B. 点 $P$ 到直线 $AB$ 的距离大于 $2$
C. 当 $\angle PBA$ 最小时，$|PB|=3\sqrt2$
D. 当 $\angle PBA$ 最大时，$|PB|=3\sqrt2$

**解答**：
直线 $AB$：$\frac{x}{4}+\frac{y}{2}=1$，即 $x+2y-4=0$。
圆心 $M(5,5)$，半径 $r=4$，圆心到直线距离
$$d=\frac{|5+10-4|}{\sqrt{1^2+2^2}}=\frac{11}{\sqrt5}>4.$$
故圆上点到 $AB$ 的距离范围为 $\left[\frac{11}{\sqrt5}-4,\ \frac{11}{\sqrt5}+4\right]$。
因 $\frac{11}{\sqrt5}<5$，所以 $\frac{11}{\sqrt5}-4<1$，$\frac{11}{\sqrt5}+4<10$，故 A 正确、B 错误。

当 $PB$ 与圆相切时，$\angle PBA$ 取得最小或最大。此时
$$|BM|=\sqrt{(5-0)^2+(5-2)^2}=\sqrt{34},\quad |PB|=\sqrt{|BM|^2-r^2}=\sqrt{34-16}=3\sqrt2,$$
故 C、D 正确。

综上选 **ACD**。

> 答案与题目分板块呈现，便于"先做后对"。每题给出规范解答 + 易错提醒，做完一题对一题。

<details>
<summary>▶ 第1题详解（距离公式应用）</summary>

**(1)** 点 $P(1, -2)$ 到直线 $3x + 4y - 5 = 0$ 的距离：
$$d = \dfrac{|3\cdot 1 + 4\cdot(-2) - 5|}{\sqrt{3^2+4^2}} = \dfrac{|3 - 8 - 5|}{5} = \dfrac{|-10|}{5} = 2$$

**(2)** 两平行线 $2x - y + 1 = 0$ 与 $2x - y - 5 = 0$（$A, B$ 系数已相同），距离：
$$d = \dfrac{|C_1 - C_2|}{\sqrt{A^2+B^2}} = \dfrac{|1-(-5)|}{\sqrt{4+1}} = \dfrac{6}{\sqrt{5}} = \dfrac{6\sqrt{5}}{5}$$

**答**：(1) $d = 2$；(2) $d = \dfrac{6\sqrt{5}}{5}$。

> **易错提醒**：点到直线距离公式中分子带**绝对值**。两平行线距离公式要求两方程的 $A, B$ 系数相同（若不同先化为相同）。

</details>

<details>
<summary>▶ 第2题详解（圆的一般方程与位置关系判定）</summary>

**(1)** 配方法化一般方程为标准方程：
$$x^2 + y^2 - 4x + 2y + 1 = 0$$
$$(x^2 - 4x + 4) + (y^2 + 2y + 1) = -1 + 4 + 1$$
$$(x-2)^2 + (y+1)^2 = 4$$

圆心 $C(2, -1)$，半径 $r = 2$。

**(2)** 圆心 $C(2, -1)$ 到直线 $3x + 4y - 5 = 0$ 的距离：
$$d = \dfrac{|3\cdot 2 + 4\cdot(-1) - 5|}{\sqrt{9+16}} = \dfrac{|6 - 4 - 5|}{5} = \dfrac{3}{5}$$

因 $d = \dfrac{3}{5} < 2 = r$，直线与圆**相交**。

**答**：(1) 圆心 $(2, -1)$，半径 $2$；(2) 相交。

> **易错提醒**：一般方程配方法要"两边同时加常数"。位置关系判定用"圆心到直线距离 $d$" 与半径 $r$ 比较：$d < r$ 相交、$d = r$ 相切、$d > r$ 相离。

</details>

<details>
<summary>▶ 第3题详解（点与圆位置 + 过外点切线）</summary>

**(1)** 圆 $C: x^2 + y^2 = 4$，圆心 $O(0,0)$，半径 $r = 2$。

$|OP| = \sqrt{3^2 + 4^2} = \sqrt{25} = 5 > 2 = r$，故点 $P$ 在圆外。

**(2)** 设切线方程为 $y - 4 = k(x - 3)$，即 $kx - y + (4 - 3k) = 0$。

圆心 $O(0,0)$ 到切线距离等于半径：
$$\dfrac{|0 - 0 + 4 - 3k|}{\sqrt{k^2 + 1}} = 2$$
$$|4 - 3k| = 2\sqrt{k^2+1}$$
$$(4-3k)^2 = 4(k^2+1)$$
$$16 - 24k + 9k^2 = 4k^2 + 4$$
$$5k^2 - 24k + 12 = 0$$
$$k = \dfrac{24 \pm \sqrt{576 - 240}}{10} = \dfrac{24 \pm \sqrt{336}}{10} = \dfrac{24 \pm 4\sqrt{21}}{10} = \dfrac{12 \pm 2\sqrt{21}}{5}$$

需检验斜率不存在（$x = 3$）是否为切线：$O$ 到 $x = 3$ 距离为 $3 \ne 2$，不是切线。

**答**：(1) 点 $P$ 在圆外；(2) 切线方程为 $y - 4 = \dfrac{12 \pm 2\sqrt{21}}{5}(x-3)$。

> **易错提醒**：过圆外一点有**两条**切线。用待定系数法设斜率 $k$ 时，需**单独验证斜率不存在**（即 $x = x_0$ 形式）是否为切线，否则可能漏解。

</details>
