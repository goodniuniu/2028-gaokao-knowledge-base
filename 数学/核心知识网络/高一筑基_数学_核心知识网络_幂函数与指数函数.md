## 核心内容

### 一、幂函数 $y = x^\alpha$
- **定义**：$x$ 是自变量，$\alpha$ 是常数
- **图象过定点**：$(1, 1)$
- **单调性**：
  - $\alpha > 0$：在 $(0, +\infty)$ 上单调递增
  - $\alpha < 0$：在 $(0, +\infty)$ 上单调递减
- **常见幂函数**：$y = x, y = x^2, y = x^3, y = x^{\frac{1}{2}}, y = x^{-1}$

### 二、指数
- **$n$ 次方根**：若 $x^n = a$，则 $x = \sqrt[n]{a}$
- **分数指数幂**：$a^{\frac{m}{n}} = \sqrt[n]{a^m}$，$a^{-\frac{m}{n}} = \frac{1}{\sqrt[n]{a^m}}$（$a > 0, m, n \in \mathbb{N}^*, n > 1$）
- **运算性质**（$a > 0, r, s \in \mathbb{R}$）：
  - $a^r \cdot a^s = a^{r+s}$
  - $(a^r)^s = a^{rs}$
  - $(ab)^r = a^r b^r$

### 三、指数函数 $y = a^x$（$a > 0$ 且 $a \neq 1$）
| 性质 | $a > 1$ | $0 < a < 1$ |
|------|---------|-------------|
| 图象 | 上升，过 $(0, 1)$ | 下降，过 $(0, 1)$ |
| 定义域 | $\mathbb{R}$ | $\mathbb{R}$ |
| 值域 | $(0, +\infty)$ | $(0, +\infty)$ |
| 单调性 | 在 $\mathbb{R}$ 上递增 | 在 $\mathbb{R}$ 上递减 |
| 函数值 | $x > 0$ 时 $y > 1$；$x < 0$ 时 $0 < y < 1$ | $x > 0$ 时 $0 < y < 1$；$x < 0$ 时 $y > 1$ |

- **底数对图象的影响**：在第一象限，底数越大图象越靠上（$0 < a_1 < a_2 < 1 < a_3 < a_4$ 时，$y = a_4^x$ 在最上方）

### 四、指数方程与不等式
- 解指数方程：化为同底 $a^{f(x)} = a^{g(x)} \Rightarrow f(x) = g(x)$
- 解指数不等式：利用单调性去底
  - $a > 1$：$a^{f(x)} > a^{g(x)} \Rightarrow f(x) > g(x)$
  - $0 < a < 1$：$a^{f(x)} > a^{g(x)} \Rightarrow f(x) < g(x)$

## 题型识别标志

> **看到什么条件 → 立刻想到什么方法**

| 题干关键条件 | 识别为 | 首选方法 |
|------|------|------|
| 形如 $a^x$ 与 $b^y$ 比较大小 | 指数型比大小 | 化同底/同指，或取中间值 $0,1$ |
| 含 $e^x$ 与多项式混合 | 指数放缩 | 构造函数 $f(x)=e^x-1-x\ge0$ 或切线放缩 |
| 含 $\ln$ 的比较 | 对数放缩 | 用 $\ln(1+x)<x\ (x>0)$、$\ln(1+x)>x-\frac{x^2}{2}$ |
| 指数式与分数比较 | 估值夹逼 | 两边取对数或双向夹逼定位 |
| $a^{f(x)}=a^{g(x)}$ 方程/不等式 | 同底指数幂 | 利用单调性化为 $f(x)=g(x)$ 或比大小 |
| 幂指函数 $x^\alpha$ 比大小 | 幂函数性质 | 看 $\alpha>0$ 或 $<0$ 及单调性 |

## 解题路径（指幂大小比较四步法）

### 第一步：统一结构
尽量化为同底（用 $a^m=e^{m\ln a}$）或同指数；无法统一时寻找中间值 $0,1$。

### 第二步：构造函数放缩
常用不等式：$e^x\ge 1+x$（$x=0$ 取等）；$\ln(1+x)<x\ (x>0)$；$\ln(1+x)>x-\frac{x^2}{2}\ (x>0)$。

### 第三步：双向夹逼定位
分别证明 $c<\text{某值}<a$ 与 $a<\text{某值}<b$，或直接比大小，把每个数夹在可比较的区间里。

### 第四步：下结论
按大小排序，回扣选项。

> **易错提醒**：放缩方向搞反（$e^x\ge 1+x$ 不能写成 $\le$）；中间值选错导致无法比较；估算 $e\approx2.718$ 时误差过大。

## 母题（2022 新课标Ⅰ卷·第7题，5分）

**题目**：设 $a=0.1e^{0.1},\ b=\frac{1}{9},\ c=-\ln 0.9$，则（　）
A. $a<b<c$　B. $c<b<a$　C. $c<a<b$　D. $a<c<b$

**解答**：
- 比较 $a$ 与 $b$：由 $e^{0.1}<1.1111\ldots=\frac{10}{9}$，得
  $$a=0.1e^{0.1}<\frac{1}{10}\cdot\frac{10}{9}=\frac19=b.$$
- 比较 $c$ 与 $a$：由 $e^{0.1}>1.1$ 得 $a=0.1e^{0.1}>0.11$；又 $c=-\ln 0.9=\ln\frac{10}{9}$，因为 $e^{0.11}>1.116>\frac{10}{9}$，故 $\ln\frac{10}{9}<0.11$，即 $c<0.11<a$。
- 综上 $c<a<b$。

故选 **C**。

## 参考答案

> 答案与题目分板块呈现，便于"先做后对"。每题给出规范解答 + 易错提醒，做完一题对一题。

<details>
<summary>▶ 第1题详解（幂函数与指数函数单调性比大小）</summary>

**(1)** 考虑 $y = x^{-2}$ 在 $(0, +\infty)$ 上单调递减（$\alpha = -2 < 0$）。

取绝对值后：$2.1 < 2.5 \Rightarrow 2.1^{-2} > 2.5^{-2}$，即 $(-2.1)^{-2} = 2.1^{-2} > 2.5^{-2} = (-2.5)^{-2}$。

**答**：$(-2.1)^{-2} > (-2.5)^{-2}$。

**(2)** 考虑 $y = \left(\dfrac{4}{3}\right)^x$，底数 $a = \dfrac{4}{3} > 1$，在 $\mathbb{R}$ 上单调递增。

$-0.5 < 0.5 \Rightarrow \left(\dfrac{4}{3}\right)^{-0.5} < \left(\dfrac{4}{3}\right)^{0.5}$。

**答**：$\left(\dfrac{4}{3}\right)^{-0.5} < \left(\dfrac{4}{3}\right)^{0.5}$。

> **易错提醒**：(1) 中负数的偶数次幂结果为正，可直接比较绝对值大小；(2) 底数 $>1$ 时指数越大值越大，底数 $0<a<1$ 时恰好相反。

</details>

<details>
<summary>▶ 第2题详解（指数运算性质综合）</summary>

$$\frac{\left(2^{1/3}\cdot 2^{2/3}\right)^6}{2^4} - (0.027)^{-2/3}$$

**第一项**：$2^{1/3}\cdot 2^{2/3} = 2^{1/3+2/3} = 2^1 = 2$，$(2)^6 = 64$，$\dfrac{64}{2^4} = \dfrac{64}{16} = 4$。

**第二项**：$0.027 = 0.3^3 = \left(\dfrac{3}{10}\right)^3$。
$$\left(\dfrac{3}{10}\right)^{-2} = \left(\dfrac{10}{3}\right)^2 = \dfrac{100}{9}$$

所以原式 $= 4 - \dfrac{100}{9} = \dfrac{36 - 100}{9} = -\dfrac{64}{9}$。

**答**：$-\dfrac{64}{9}$。

> **易错提醒**：运算性质 $a^r\cdot a^s = a^{r+s}$（同底幂相乘，指数相加），$(a^r)^s = a^{rs}$（幂的幂，指数相乘）。$(0.027)^{-2/3} = \left[(0.3)^3\right]^{-2/3} = (0.3)^{-2} = \dfrac{100}{9}$。

</details>

<details>
<summary>▶ 第3题详解（指数函数单调性 + 分类讨论）</summary>

$a^{3/2} > a^{5/3}$ 是指数型不等式。注意指数函数 $y = a^x$ 要求 $a > 0$ 且 $a \ne 1$，分两种情况：

**情形1**：$a > 1$ 时，$y = a^x$ 单调递增，$a^{3/2} > a^{5/3} \Leftrightarrow \dfrac{3}{2} > \dfrac{5}{3}$，但 $\dfrac{3}{2} = \dfrac{9}{6} < \dfrac{10}{6} = \dfrac{5}{3}$，矛盾，无解。

**情形2**：$0 < a < 1$ 时，$y = a^x$ 单调递减，$a^{3/2} > a^{5/3} \Leftrightarrow \dfrac{3}{2} < \dfrac{5}{3}$，即 $\dfrac{9}{6} < \dfrac{10}{6}$，恒成立。

**答**：$a \in (0, 1)$。

> **易错提醒**：解指数不等式时，务必先判断底数 $a$ 的范围。$a>1$ 时单调递增、不等号方向不变；$0<a<1$ 时单调递减、不等号要反向。本题 $\dfrac{3}{2} < \dfrac{5}{3}$ 是关键事实。

</details>
