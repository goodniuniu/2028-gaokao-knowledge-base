集合与常用逻辑用语

⚠️待强化★★☆☆☆#高一筑基#新高考Ⅰ卷·广东来源：53科学备考《高中知识清单》数学知识图谱 / 人教A版必修第一册第一章
广东考情：考查频率：中频（选填基础题）；难度：基础；常以集合运算与不等式解集结合命题

核心内容

一、集合的概念与表示

  • 定义：研究对象称为元素，元素组成的总体叫做集合
  • 元素特性：确定性、互异性、无序性
  • 表示法：
    • 列举法：$\{a_1, a_2, a_3, \dots\}$
    • 描述法：$\{x \in A \mid P(x)\}$
    • 图示法：Venn图
  • 常用数集：$\mathbb{N}^*$（正整数）$\subset \mathbb{N}$（自然数）$\subset \mathbb{Z}$（整数）$\subset \mathbb{Q}$（有理数）$\subset \mathbb{R}$（实数）$\subset \mathbb{C}$（复数）

二、集合间的基本关系

  • 子集：$A \subseteq B$（$\forall x \in A, x \in B$）
  • 真子集：$A \subsetneqq B$（$A \subseteq B$ 且 $A \neq B$）
  • 集合相等：$A = B \Leftrightarrow A \subseteq B$ 且 $B \subseteq A$
  • 空集：$\varnothing$ 是任何集合的子集；是任何非空集合的真子集
  • 含 $n$ 个元素的集合：子集个数 $2^n$，真子集个数 $2^n-1$，非空真子集 $2^n-2$

三、集合的基本运算

运算定义Venn图特征
并集 $A \cup B$$\{x \mid x \in A$ 或 $x \in B\}$两圆覆盖的全部区域
交集 $A \cap B$$\{x \mid x \in A$ 且 $x \in B\}$两圆重叠区域
补集 $\complement_U A$$\{x \mid x \in U$ 且 $x \notin A\}$全集中圆外区域

运算律：

  • $A \cup B = B \cup A$；$A \cap B = B \cap A$
  • $(A \cup B) \cup C = A \cup (B \cup C)$
  • $A \cup (B \cap C) = (A \cup B) \cap (A \cup C)$
  • $\complement_U(A \cup B) = \complement_U A \cap \complement_U B$（德摩根律）
  • $\complement_U(A \cap B) = \complement_U A \cup \complement_U B$

四、充分条件与必要条件

设 $A = \{x \mid p(x)\}$，$B = \{x \mid q(x)\}$：

条件关系集合关系口诀
$p$ 是 $q$ 的充分不必要条件$A \subsetneqq B$小推大
$p$ 是 $q$ 的必要不充分条件$B \subsetneqq A$大推小
$p$ 是 $q$ 的充要条件$A = B$等价
$p$ 是 $q$ 的既不充分也不必要条件$A \not\subseteq B$ 且 $B \not\subseteq A$无关

五、全称量词与存在量词

  • 全称量词命题：$\forall x \in M, p(x)$，否定为 $\exists x \in M, \neg p(x)$
  • 存在量词命题：$\exists x \in M, p(x)$，否定为 $\forall x \in M, \neg p(x)$
  • 规律：全称 $\leftrightarrow$ 存在互换，结论取反

解题路径（集合运算三步）

第一步：化简集合

解不等式、写出区间或列举元素；含参数时先分类讨论。

第二步：数形结合

在数轴上标出各集合：交集取重叠、并集取覆盖、补集取外部。

第三步：核对端点

开闭区间端点是否取到；元素是否属于要逐点验证（尤其整数集）。

易错提醒：忽略区间开闭导致端点误判；混淆 $\in$ 与 $\subseteq$；含参集合漏掉空集情形。

母题（2021 新课标Ⅰ卷·第1题，5分）

题目：设集合 $A=\{x\mid -2

解答： $A=(-2,4)$ 为开区间，$B=\{2,3,4,5\}$。 逐一检验：$2\in A$，$3\in A$，$4\notin A$（开区间不含 $4$），$5\notin A$。 故 $A\cap B=\{2,3\}$。

故选 B。

自测训练（3道·覆盖集合运算、充分必要条件、量词否定）

先独立完成，再展开卡片末尾「参考答案」核对。每题标注所检验的知识点，方便对号查漏。

第1题（检验 集合的交并运算）

设集合 $A=\{x\mid x^2-3x+2\le0\}$，$B=\{x\mid x>1\}$，求 $A\cap B$ 和 $A\cup B$。

第2题（检验 充分必要条件）

判断：$p:x>2$ 是 $q:x>1$ 的什么条件？（填"充分不必要""必要不充分""充要"或"既不充分也不必要"）

第3题（检验 全称量词命题的否定）

写出命题"$\forall x\in\mathbb{R}$，$x^2+x+1>0$"的否定。

关联卡片

  • 函数的定义与三要素 — 集合是函数定义域、值域的基础
  • 一元二次函数方程与不等式 — 集合运算常与不等式解集结合

备注

  • 易错点：空集是任何集合的子集，但 $\varnothing \subseteq \varnothing$ 成立，$\varnothing \in \varnothing$ 不成立
  • 广东卷常考：集合与不等式解集的综合运算，注意端点检验
  • 充分必要条件判断优先用集合法，直观不易错

参考答案

答案与题目分板块呈现，便于"先做后对"。每题给出规范解答 + 易错提醒，做完一题对一题。

▶ 第1题详解（集合运算）

解不等式 $x^2-3x+2\le0$ 得 $(x-1)(x-2)\le0$，所以 $A=[1,2]$。

$B=(1,+\infty)$。

因此 $$A\cap B=(1,2],\quad A\cup B=[1,+\infty).$$

答：$A\cap B=(1,2]$，$A\cup B=[1,+\infty)$。

易错提醒：集合运算前先化简集合；注意区间端点开闭，$B$ 中 $x>1$ 不含 $1$，所以 $A\cap B$ 不含 $1$。

▶ 第2题详解（充分必要条件）

若 $x>2$，则必有 $x>1$，所以 $p\Rightarrow q$，$p$ 是 $q$ 的充分条件。

但 $x>1$ 时不一定有 $x>2$（如 $x=1.5$），所以 $q\nRightarrow p$。

故 $p$ 是 $q$ 的充分不必要条件。

答：充分不必要条件。

易错提醒：判断充分必要条件可用集合法：$p$ 对应集合 $A$，$q$ 对应集合 $B$，$A\subsetneqq B$ 则 $p$ 是 $q$ 的充分不必要条件。

▶ 第3题详解（量词否定）

全称量词命题的否定规则：$\forall$ 变 $\exists$，结论取反。

所以否定为 $$\exists x\in\mathbb{R},\ x^2+x+1\le0.$$

答：$\exists x\in\mathbb{R}$，$x^2+x+1\le0$。

易错提醒：量词否定时，"$\forall$"与"$\exists$"互换，同时结论中的不等号也要取反（$>$ 变 $\le$）。
