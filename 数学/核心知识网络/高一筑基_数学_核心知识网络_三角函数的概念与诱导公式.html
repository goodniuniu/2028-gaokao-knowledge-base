三角函数的概念与诱导公式

⚠️待强化★★★☆☆#高一筑基#新高考Ⅰ卷·广东来源：53科学备考《高中知识清单》数学知识图谱 / 人教A版必修第一册第五章
广东考情：考查频率：高频；难度：基础~中档；诱导公式与三角函数定义是三角大题的第一问基础，必须熟练

核心内容

一、任意角与弧度制

  • 终边相同角：$S = \{\beta \mid \beta = \alpha + k \cdot 360°\}$ 或 $\beta = \alpha + 2k\pi$（$k \in \mathbb{Z}$）
  • 弧度制：$|\alpha| = \frac{l}{r}$，$1 \text{ rad} \approx 57.3°$
  • 换算：$\pi = 180°$，$1° = \frac{\pi}{180} \text{ rad}$

二、三角函数定义

单位圆定义：设角 $\alpha$ 终边与单位圆交于点 $P(x, y)$，则

  • $\sin\alpha = y$，$\cos\alpha = x$，$\tan\alpha = \frac{y}{x}$（$x \neq 0$）

一般定义：终边上一点 $P(x, y)$，$r = \sqrt{x^2 + y^2}$，则

  • $\sin\alpha = \frac{y}{r}$，$\cos\alpha = \frac{x}{r}$，$\tan\alpha = \frac{y}{x}$

三、三角函数值在各象限的符号

口诀：一全正，二正弦，三正切，四余弦

四、同角三角函数的基本关系式

$$\sin^2\alpha + \cos^2\alpha = 1, \quad \tan\alpha = \frac{\sin\alpha}{\cos\alpha}\quad(\alpha \neq k\pi + \frac{\pi}{2})$$

  • 应用：求值、化简、证明（知一求二）

五、诱导公式

公式正弦余弦正切记忆口诀
公式一：$2k\pi + \alpha$$\sin\alpha$$\cos\alpha$$\tan\alpha$周期不变
公式二：$\pi + \alpha$$-\sin\alpha$$-\cos\alpha$$\tan\alpha$同名
公式三：$-\alpha$$-\sin\alpha$$\cos\alpha$$-\tan\alpha$同名
公式四：$\pi - \alpha$$\sin\alpha$$-\cos\alpha$$-\tan\alpha$同名
公式五：$\frac{\pi}{2} - \alpha$$\cos\alpha$$\sin\alpha$$\cot\alpha$互余互换
公式六：$\frac{\pi}{2} + \alpha$$\cos\alpha$$-\sin\alpha$$-\cot\alpha$互余互换

统一口诀：奇变偶不变，符号看象限

  • "奇偶"：指 $\frac{\pi}{2}$ 的奇数倍或偶数倍
  • "变"：函数名改变（正弦 $\leftrightarrow$ 余弦，正切 $\leftrightarrow$ 余切）
  • "符号"：把 $\alpha$ 看成锐角，判断原函数在相应象限的符号

终边对称关系：

  • $\pi - \alpha$ 与 $\alpha$：终边关于 $y$ 轴对称
  • $\pi + \alpha$ 与 $\alpha$：终边关于原点对称
  • $2\pi - \alpha$ 与 $\alpha$：终边关于 $x$ 轴对称

题型识别标志

看到什么条件 → 立刻想到什么方法

题干关键条件识别为首选方法
"已知 $\tan\theta=k$，求关于 $\sin\theta,\cos\theta$ 的式子"同角关系切化弦 $\tan\theta=\frac{\sin\theta}{\cos\theta}$，或构 $1=\sin^2\theta+\cos^2\theta$
"出现 $\sin2\theta,\cos2\theta$"倍角用 $\sin2\theta=2\sin\theta\cos\theta$ 等降次
"求 $\sin(\alpha\pm\beta),\cos(\alpha\pm\beta)$"和差角展开后正余弦互化
"给角求值含非特殊角"诱导/配角奇变偶不变、符号看象限；或配成特殊角
"分子分母同次齐次式"齐次式同除以 $\cos\theta$ 化为 $\tan\theta$
"已知终边/单位圆上点坐标"定义$\sin\alpha=y,\cos\alpha=x,\;r=1$

解题路径（同角+倍角求值三步法）

650分导向：三角求值是广东卷三角大题第一问的标配，目标是"化为同名、可代入"。

第一步：统一名称

优先"切化弦"或"弦化切"，把不同名函数化为同名，便于约分。

第二步：降次配角

用倍角公式、平方和公式把式子化为可代入的形式（如分子配成 $(\sin\theta+\cos\theta)^2$）。

第三步：代入约分

代入已知值（如 $\tan\theta=-2$），注意符号与分母不为零。

母题（2021 新课标Ⅰ卷·第6题，5分）

广东考生真题。典型"切化弦+齐次式"求值，属于三角概念与恒等变换的基础应用。

题目：若 $\tan\theta=-2$，则 $\dfrac{\sin\theta(1+\sin2\theta)}{\sin\theta+\cos\theta}=$（ ）

A. $-\dfrac{6}{5}$　B. $-\dfrac{2}{5}$　C. $\dfrac{2}{5}$　D. $\dfrac{6}{5}$

解： $$\begin{aligned} \text{原式}&=\frac{\sin\theta(\sin^2\theta+\cos^2\theta+2\sin\theta\cos\theta)}{\sin\theta+\cos\theta}\\ &=\frac{\sin\theta(\sin\theta+\cos\theta)^2}{\sin\theta+\cos\theta} =\sin\theta(\sin\theta+\cos\theta)\\ &=\frac{\sin^2\theta+\sin\theta\cos\theta}{\sin^2\theta+\cos^2\theta} \end{aligned}$$

上下同除以 $\cos^2\theta$ 得 $$\frac{\tan^2\theta+\tan\theta}{\tan^2\theta+1}=\frac{4-2}{4+1}=\frac{2}{5}$$

答：选 C。

自测训练（3道·覆盖三角函数定义、同角关系、诱导公式）

先独立完成，再展开卡片末尾「参考答案」核对。每题标注所检验的知识点，方便对号查漏。

第1题（检验 三角函数定义与同角关系）

已知 $\sin\alpha=\dfrac{3}{5}$，且 $\alpha$ 是第二象限角，求 $\cos\alpha$ 与 $\tan\alpha$。

第2题（检验 诱导公式化简）

化简：$\dfrac{\sin(\pi+\alpha)\cos(2\pi-\alpha)}{\cos\left(\dfrac{\pi}{2}+\alpha\right)\sin(-\alpha)}$。

第3题（检验 齐次式求值）

已知 $\tan\theta=-2$，求 $\dfrac{\sin\theta+\cos\theta}{\sin\theta-\cos\theta}$ 的值。

  • 易错点：诱导公式使用时"符号看象限"容易记错，建议用单位圆辅助判断

参考答案

答案与题目分板块呈现，便于"先做后对"。每题给出规范解答 + 易错提醒，做完一题对一题。

▶ 第1题详解（三角函数定义与同角关系）

由 $\sin^2\alpha+\cos^2\alpha=1$，得 $$\cos^2\alpha=1-\left(\dfrac{3}{5}\right)^2=\dfrac{16}{25}.$$ 因为 $\alpha$ 在第二象限，$\cos\alpha<0$，所以 $\cos\alpha=-\dfrac{4}{5}$。

于是 $$\tan\alpha=\dfrac{\sin\alpha}{\cos\alpha}=\dfrac{\frac{3}{5}}{-\frac{4}{5}}=-\dfrac{3}{4}.$$

答：$\cos\alpha=-\dfrac{4}{5}$，$\tan\alpha=-\dfrac{3}{4}$。

易错提醒：由 $\sin\alpha$ 求 $\cos\alpha$ 时，必须根据象限定正负；第二象限余弦为负，易漏负号。

▶ 第2题详解（诱导公式）

逐项化简：

  • $\sin(\pi+\alpha)=-\sin\alpha$；
  • $\cos(2\pi-\alpha)=\cos\alpha$；
  • $\cos\left(\dfrac{\pi}{2}+\alpha\right)=-\sin\alpha$；
  • $\sin(-\alpha)=-\sin\alpha$。

代入得 $$\text{原式}=\dfrac{(-\sin\alpha)\cos\alpha}{(-\sin\alpha)(-\sin\alpha)}=-\dfrac{\cos\alpha}{\sin\alpha}=-\cot\alpha.$$

答：$-\cot\alpha$。

易错提醒："奇变偶不变，符号看象限"中，"符号"是把 $\alpha$ 看成锐角后判断原函数值的符号；$\cos\left(\dfrac{\pi}{2}+\alpha\right)$ 变名为 $-\sin\alpha$。

▶ 第3题详解（齐次式求值）

分子分母同除以 $\cos\theta$（$\cos\theta\ne0$，因 $\tan\theta$ 存在）： $$\dfrac{\sin\theta+\cos\theta}{\sin\theta-\cos\theta}=\dfrac{\tan\theta+1}{\tan\theta-1}.$$

代入 $\tan\theta=-2$： $$\dfrac{-2+1}{-2-1}=\dfrac{-1}{-3}=\dfrac{1}{3}.$$

答：$\dfrac{1}{3}$。

易错提醒：齐次式化切时，分子分母必须同次；本题分子分母都是一次，可直接同除 $\cos\theta$。
