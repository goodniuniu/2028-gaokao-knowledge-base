条件概率与离散型随机变量

⚠️待强化★★★★☆#高二深化#新高考Ⅰ卷·广东来源：53科学备考《高中知识清单》数学知识图谱 / 人教A版选择性必修第三册第七章
广东考情：考查频率：高频；难度：中档~中高档；概率统计大题是广东卷必考题型，条件概率和全概率公式近年考查力度加大

核心内容

一、条件概率与全概率公式

  • 条件概率：$P(B|A) = \frac{P(AB)}{P(A)}$（$P(A) > 0$）
  • 乘法公式：$P(AB) = P(A)P(B|A)$
  • 全概率公式：$P(B) = \sum_{i=1}^n P(A_i)P(B|A_i)$（$A_1, A_2, \dots, A_n$ 为样本空间的一个划分）
  • 贝叶斯公式：$P(A_i|B) = \frac{P(A_i)P(B|A_i)}{P(B)} = \frac{P(A_i)P(B|A_i)}{\sum_{k=1}^n P(A_k)P(B|A_k)}$

二、离散型随机变量

  • 定义：可能取值为有限个或可以一一列举的随机变量
  • 分布列：$P(X = x_i) = p_i$（$i = 1, 2, \dots, n$），满足 $p_i \geq 0$ 且 $\sum p_i = 1$

1. 均值（数学期望）

$$E(X) = x_1 p_1 + x_2 p_2 + \cdots + x_n p_n = \sum_{i=1}^n x_i p_i$$

  • 线性性质：$E(aX + b) = aE(X) + b$

2. 方差

$$D(X) = \sum_{i=1}^n (x_i - E(X))^2 p_i$$

  • 线性性质：$D(aX + b) = a^2 D(X)$

三、两点分布（0-1分布）

$X$$0$$1$
$P$$1-p$$p$
  • $E(X) = p$，$D(X) = p(1-p)$

题型识别标志

看到什么条件 → 立刻想到什么方法

题干关键条件识别为首选方法
"命中则继续，未命中换人"状态递推设 $a_i$ 建一阶线性递推
求第 $i$ 次某状态概率递推数列$a_i=qa_{i-1}+p$ 构造等比
多原因导致事件 $B$全概率公式$P(B)=\sum P(A_i)P(B|A_i)$
分布列 + 期望数字特征$E(X)=\sum x_ip_i$，线性 $E(aX+b)=aE(X)+b$
前 $n$ 次中某类出现次数 $Y$两点分布和$E(Y)=\sum q_i$
"有放回/无放回"分布选型有放回→二项，无放回→超几何

解题路径（递推概率五步）

第一步：定义状态概率

设 $a_i=P(\text{第}i\text{次是甲})$，明确初值 $a_1$（如抽签得 $0.5$）。

第二步：建立递推

由全概率：$a_i=P(\text{上一轮甲且命中})+P(\text{上一轮乙且未命中})$。

第三步：解递推数列

化为 $a_i-\lambda=q(a_{i-1}-\lambda)$，求通项 $a_i=\lambda+(a_1-\lambda)q^{i-1}$。

第四步：转化为随机变量

$Y=\sum_{i=1}^n X_i$，$X_i\sim$ 两点分布，$P(X_i=1)=a_i$。

第五步：求期望

$$E(Y)=\sum_{i=1}^n a_i,$$ 用等比求和公式得出结果。

易错提醒：递推关系式写反（把"命中继续"写成换人）；构造等比数列时 $\lambda$ 算错；期望漏加首项。

母题（2023 新课标Ⅰ卷·第21题，12分）

题目：甲、乙两人投篮，每次由其中一人投篮，规则如下：若命中则此人继续投篮，若未命中则换为对方投篮。无论之前投篮情况如何，甲每次命中率均为 $0.6$，乙每次命中率均为 $0.8$，由抽签确定第 $1$ 次投篮的人选，第 $1$ 次是甲、乙的概率各为 $0.5$。 (1) 求第 $2$ 次投篮的人是乙的概率； (2) 求第 $i$ 次投篮的人是甲的概率； (3) 记前 $n$ 次中甲投篮的次数为 $Y$，求 $E(Y)$。

解答： (1) 第 $2$ 次是乙有两种互斥情形：第 $1$ 次甲且未中，或第 $1$ 次乙且命中： $$P=0.5\times(1-0.6)+0.5\times0.8=0.6.$$

(2) 记 $a_i=P(\text{第}i\text{次是甲})$，则 $a_1=0.5$，且 $$a_i=0.6a_{i-1}+0.2(1-a_{i-1})=0.4a_{i-1}+0.2.$$ 令 $a_i-\frac13=0.4\left(a_{i-1}-\frac13\right)$，得 $$a_i=\frac13+\frac16\left(\frac25\right)^{i-1}.$$

(3) 设 $X_i$ 表示第 $i$ 次是否为甲投篮（$1$ 是，$0$ 否），则 $P(X_i=1)=a_i$，$Y=\sum_{i=1}^n X_i$， $$E(Y)=\sum_{i=1}^n a_i=\sum_{i=1}^n\left[\frac13+\frac16\left(\frac25\right)^{i-1}\right] =\frac n3+\frac16\cdot\frac{1-(2/5)^n}{1-2/5} =\frac n3+\frac{5}{18}\left[1-\left(\frac25\right)^n\right].$$

袋中有 3 个红球、2 个白球，除颜色外完全相同。从中不放回地依次取出 2 个球。 (1) 求第 1 次取到红球的概率； (2) 求在第 1 次取到红球的条件下，第 2 次也取到红球的概率； (3) 求两次都取到红球的概率。

第2题（检验 离散型随机变量分布列与期望）

已知随机变量 $X$ 的分布列为 $P(X=0) = 0.2$，$P(X=1) = 0.5$，$P(X=2) = 0.3$。 (1) 求 $E(X)$ 和 $D(X)$； (2) 若 $Y = 2X - 1$，求 $E(Y)$ 和 $D(Y)$。

第3题（检验 全概率公式）

甲袋有 2 个红球、3 个白球，乙袋有 4 个红球、1 个白球。随机选一袋（每袋被选中的概率为 $\frac{1}{2}$），再从该袋中任取 1 球。求取到红球的概率。

参考答案

答案与题目分板块呈现，便于"先做后对"。每题给出规范解答 + 易错提醒，做完一题对一题。

▶ 第1题详解（条件概率与乘法公式）

(1) 第 1 次取球时共 5 个球（3 红 2 白），取到红球的概率： $$P(A) = \dfrac{3}{5}$$

(2) 在第 1 次取到红球后，袋中剩 2 红 2 白共 4 个球。第 2 次取到红球的概率： $$P(B|A) = \dfrac{2}{4} = \dfrac{1}{2}$$

(3) 由乘法公式 $P(AB) = P(A)\cdot P(B|A)$： $$P(AB) = \dfrac{3}{5}\times\dfrac{1}{2} = \dfrac{3}{10}$$

答：(1) $\dfrac{3}{5}$；(2) $\dfrac{1}{2}$；(3) $\dfrac{3}{10}$。

易错提醒：条件概率 $P(B|A)$ 中，样本空间已缩小为 $A$ 发生后的情况（袋中球少了一个）。不放回抽样前后概率不同，不能用 $\dfrac{3}{5}$ 硬套。

▶ 第2题详解（分布列、期望与方差性质）

(1) $E(X) = \sum x_i p_i = 0\times 0.2 + 1\times 0.5 + 2\times 0.3 = 0 + 0.5 + 0.6 = 1.1$。

$D(X) = \sum (x_i - E(X))^2 p_i$： $$D(X) = (0-1.1)^2\times 0.2 + (1-1.1)^2\times 0.5 + (2-1.1)^2\times 0.3 = 1.21\times 0.2 + 0.01\times 0.5 + 0.81\times 0.3 = 0.242 + 0.005 + 0.243 = 0.49$$

(2) 由线性性质： $$E(Y) = E(2X-1) = 2E(X) - 1 = 2\times 1.1 - 1 = 1.2$$ $$D(Y) = D(2X-1) = 2^2 D(X) = 4\times 0.49 = 1.96$$

答：(1) $E(X) = 1.1$，$D(X) = 0.49$；(2) $E(Y) = 1.2$，$D(Y) = 1.96$。

易错提醒：期望的线性性质 $E(aX+b) = aE(X)+b$；但方差 $D(aX+b) = a^2 D(X)$——注意平方、且常数不影响方差。$E(X)$ 是加权平均（值 $\times$ 概率之和），$D(X)$ 用定义 $(x_i-E(X))^2 p_i$ 直接算最稳。

▶ 第3题详解（全概率公式·两袋选一）

设 $A_1$ = "选中甲袋"，$A_2$ = "选中乙袋"，$B$ = "取到红球"。

$A_1, A_2$ 是样本空间的一个划分，$P(A_1) = P(A_2) = \dfrac{1}{2}$。

条件概率：

  • $P(B|A_1) = \dfrac{2}{2+3} = \dfrac{2}{5}$
  • $P(B|A_2) = \dfrac{4}{4+1} = \dfrac{4}{5}$

由全概率公式： $$P(B) = P(A_1)P(B|A_1) + P(A_2)P(B|A_2) = \dfrac{1}{2}\times\dfrac{2}{5} + \dfrac{1}{2}\times\dfrac{4}{5} = \dfrac{1}{5} + \dfrac{2}{5} = \dfrac{3}{5}$$

答：取到红球的概率为 $\dfrac{3}{5}$。

易错提醒：全概率公式的适用场景——事件 $B$ 的发生有多个互斥原因 $A_i$，且 $\{A_i\}$ 是样本空间的划分（完备且互斥）。常见错误是把 $P(B|A_i)$ 当作 $P(A_i B)$ 直接相加。
