## 核心内容

### 一、解题思路速查卡（"看到什么→想什么→用什么"）

> 先看"长什么样"，再决定"走哪条路"。这是变形题型的最高效决策框架。

| 看到什么 | 想什么 | 用什么 |
|---------|--------|--------|
| $a\sin x + b\cos x$ | 提斜凑正弦 | **辅助角公式** $\sqrt{a^2+b^2}\sin(x+\varphi)$ |
| $\sin^2 x,\ \sin x\cos x$（齐次式） | 弦化切 | 同除 $\cos^2 x$ |
| 已知 $\alpha+\beta$ 和 $\alpha$，求 $\beta$ | 配角 | $\beta = (\alpha+\beta) - \alpha$ |
| $\sin x + \cos x = k$ | 化单一名称 | **辅助角公式**化同名同角 |
| 有 $\cos^2 x$ 或 $\sin^2 x$ | 降次 | **二倍角公式**（升幂/降幂） |

### 二、五大题型通法与母题

#### 题型一：辅助角公式（提斜凑正弦）

**通法**：$a\sin x + b\cos x = \sqrt{a^2+b^2}\sin(x+\varphi)$，其中 $\tan\varphi = b/a$（注意 $a,b$ 符号共同决定 $\varphi$ 所在象限，不只看比值）。

**变形后的标准动作**：化简成 $A\sin(\omega x+\varphi)+B$ → 直接读出周期 $T=2\pi/\omega$、最大值 $A+B$、单调递增区间 $[\!-\pi/2-\varphi,\ \pi/2-\varphi\!]$。

**常见快速形式**：
- $\sin x \pm \cos x = \sqrt{2}\sin\!\left(x \pm \dfrac{\pi}{4}\right)$
- $\sqrt{3}\sin x \pm \cos x = 2\sin\!\left(x \pm \dfrac{\pi}{6}\right)$
- $\sin x \pm \sqrt{3}\cos x = 2\sin\!\left(x \pm \dfrac{\pi}{3}\right)$

**母题【例1】**：已知 $f(x) = \sin x + \sqrt{3}\cos x$。
(1) 求 $f(x)$ 的最大值及取最大值时 $x$ 的取值集合；
(2) 求 $f(x)$ 的最小正周期和单调递增区间。

**规范解答**：
$$\sqrt{1^2+(\sqrt{3})^2} = \sqrt{1+3}=2$$
$$f(x) = 2\!\left(\dfrac{1}{2}\sin x + \dfrac{\sqrt{3}}{2}\cos x\right) = 2\sin\!\left(x + \dfrac{\pi}{3}\right)$$

(1) 当 $\sin\!\left(x+\dfrac{\pi}{3}\right)=1$ 时 $f(x)$ 取最大值 $2$，此时 $x+\dfrac{\pi}{3}=\dfrac{\pi}{2}+2k\pi$，解得 $x=\dfrac{\pi}{6}+2k\pi\ (k\in\mathbb{Z})$，取值集合为 $\left\{x \mid x=\dfrac{\pi}{6}+2k\pi,\ k\in\mathbb{Z}\right\}$。

(2) 最小正周期 $T = \dfrac{2\pi}{1} = 2\pi$；令 $-\dfrac{\pi}{2}+2k\pi \le x+\dfrac{\pi}{3} \le \dfrac{\pi}{2}+2k\pi$，解得 $-\dfrac{5\pi}{6}+2k\pi \le x \le \dfrac{\pi}{6}+2k\pi$，单调递增区间为 $\left[-\dfrac{5\pi}{6}+2k\pi,\ \dfrac{\pi}{6}+2k\pi\right],\ k\in\mathbb{Z}$。

#### 题型二：配角法（统一角——差角公式反用）

**通法**：当目标角不是已知角时，把目标角拆成"已知角的和/差"——本质是差角公式 $\cos(A-B)=\cos A\cos B+\sin A\sin B$ 的逆用。

**决策三问**：
1. 已知谁？（如 $\alpha$ 与 $\alpha+\beta$）
2. 求谁？（$\beta$）
3. 怎么配？（$\beta = (\alpha+\beta) - \alpha$）

**注意**：先判断角的范围（特别是 $\alpha+\beta$ 落在第几象限），再决定 $\sin/\cos$ 的符号。

**母题【例2】**：已知 $\alpha,\beta$ 均为锐角，$\cos\alpha=\dfrac{1}{7}$，$\cos(\alpha+\beta)=-\dfrac{11}{14}$，求 $\cos\beta$ 的值。

**规范解答**：
$\alpha$ 为锐角，$\cos\alpha=\dfrac{1}{7}$，故
$$\sin\alpha = \sqrt{1-\left(\dfrac{1}{7}\right)^2} = \sqrt{\dfrac{48}{49}} = \dfrac{4\sqrt{3}}{7}$$

$\alpha,\beta$ 均为锐角，故 $0<\alpha+\beta<\pi$；又 $\cos(\alpha+\beta)=-\dfrac{11}{14}<0$，故 $\dfrac{\pi}{2}<\alpha+\beta<\pi$，于是
$$\sin(\alpha+\beta) = \sqrt{1-\left(-\dfrac{11}{14}\right)^2} = \sqrt{\dfrac{75}{196}} = \dfrac{5\sqrt{3}}{14}$$

由配角：$\beta = (\alpha+\beta)-\alpha$，
$$\begin{aligned}
\cos\beta &= \cos[(\alpha+\beta)-\alpha] \\
&= \cos(\alpha+\beta)\cos\alpha + \sin(\alpha+\beta)\sin\alpha \\
&= \left(-\dfrac{11}{14}\right)\!\cdot\!\dfrac{1}{7} + \dfrac{5\sqrt{3}}{14}\!\cdot\!\dfrac{4\sqrt{3}}{7} \\
&= -\dfrac{11}{98} + \dfrac{60}{98} = \dfrac{49}{98} = \dfrac{1}{2}
\end{aligned}$$

#### 题型三：齐次化（"1"的代换与弦化切）

**通法**：看到 $\sin^2 x + \sin x\cos x - 3\cos^2 x$ 这类 sin、cos 的**齐次多项式**，想到 $\sin^2+\cos^2=1$——把"1"代换成 $\sin^2+\cos^2$，分子分母同除以 $\cos^2 x$（或 $\sin^2 x$），化为关于 $\tan x$（或 $\cot x$）的有理式。

**两种情形**：
- 已知 $\tan x$ 的值 → 除以 $\cos^2 x$；
- 已知 $\cot x$ 的值 → 除以 $\sin^2 x$。

**注意**：$\sin x=0$ 或 $\cos x=0$ 时该法失效，须先验证。

**母题【例3】**：已知 $\tan\alpha=2$，求 $\sin^2\alpha + \sin\alpha\cos\alpha - 3\cos^2\alpha$ 的值。

**规范解答**：
原式是关于 $\sin\alpha,\cos\alpha$ 的二次齐次式，分子分母同除以 $\cos^2\alpha$：
$$\begin{aligned}
&\sin^2\alpha + \sin\alpha\cos\alpha - 3\cos^2\alpha \\
&= \dfrac{\sin^2\alpha + \sin\alpha\cos\alpha - 3\cos^2\alpha}{\sin^2\alpha + \cos^2\alpha} \\
&= \dfrac{\tan^2\alpha + \tan\alpha - 3}{\tan^2\alpha + 1}
\end{aligned}$$

代入 $\tan\alpha=2$：
$$= \dfrac{2^2 + 2 - 3}{2^2 + 1} = \dfrac{4+2-3}{5} = \dfrac{3}{5}$$

#### 题型四：三角方程求解

**通法**：左边是一次式（如 $\sin x+\cos x=k$）→ 先用辅助角公式化为单一名称；左边是二次式（如 $\sin^2 x + \sin x - 1 = 0$）→ 换元或因式分解。最后回到基本三角方程 $\sin\theta=a/\cos\theta=a/\tan\theta=a$ 求解，注意**通解 + 区间筛选**两步缺一不可。

**母题【例4】**：解方程 $\sin x + \cos x = 1$，其中 $x\in[0,2\pi]$。

**规范解答**：
提取 $\sqrt{2}$，用辅助角公式：
$$\sqrt{2}\!\left(\dfrac{1}{\sqrt{2}}\sin x + \dfrac{1}{\sqrt{2}}\cos x\right) = \sqrt{2}\sin\!\left(x + \dfrac{\pi}{4}\right) = 1$$

即 $\sin\!\left(x+\dfrac{\pi}{4}\right) = \dfrac{\sqrt{2}}{2}$。

令 $\theta = x+\dfrac{\pi}{4}$，则 $\sin\theta = \dfrac{\sqrt{2}}{2}$，
$$\theta = \dfrac{\pi}{4} + 2k\pi \quad\text{或}\quad \theta = \dfrac{3\pi}{4} + 2k\pi \quad(k\in\mathbb{Z})$$

- 情况①：$x+\dfrac{\pi}{4}=\dfrac{\pi}{4}+2k\pi$，得 $x=2k\pi$；在 $[0,2\pi]$ 内 $x=0$ 或 $x=2\pi$。
- 情况②：$x+\dfrac{\pi}{4}=\dfrac{3\pi}{4}+2k\pi$，得 $x=\dfrac{\pi}{2}+2k\pi$；在 $[0,2\pi]$ 内 $x=\dfrac{\pi}{2}$。

**答**：$x\in\left\{0,\ \dfrac{\pi}{2},\ 2\pi\right\}$。

---

#### 题型五：综合——降次 + 辅助角 + 性质

**通法（流水线）**：含 $\cos^2 x$ / $\sin^2 x$ → 先**二倍角降幂**统一次数；含 $\sin 2x$ / $\cos 2x$ → 直接进入**辅助角公式**化为标准型 $A\sin(\omega x+\varphi)+B$；最后代入 $\omega,\varphi,B$ 读**周期 / 最值 / 单调区间**。

**母题【例5】**：已知 $f(x) = 2\cos^2 x + \sin 2x$。
(1) 求 $f(x)$ 的最大值和最小正周期；
(2) 求 $f(x)$ 在 $\left[0,\dfrac{\pi}{2}\right]$ 上的单调递增区间。

**规范解答**：
(1) 用二倍角降次：$2\cos^2 x = 1+\cos 2x$，故
$$f(x) = 1 + \cos 2x + \sin 2x = \sin 2x + \cos 2x + 1$$

对 $\sin 2x + \cos 2x$ 用辅助角公式：
$$f(x) = \sqrt{2}\sin\!\left(2x + \dfrac{\pi}{4}\right) + 1$$

当 $\sin\!\left(2x+\dfrac{\pi}{4}\right)=1$ 时 $f(x)$ 取最大值 $\sqrt{2}+1$；
最小正周期 $T = \dfrac{2\pi}{2} = \pi$。

(2) 由 $-\dfrac{\pi}{2}+2k\pi \le 2x+\dfrac{\pi}{4} \le \dfrac{\pi}{2}+2k\pi$ 得
$$-\dfrac{3\pi}{8}+k\pi \le x \le \dfrac{\pi}{8}+k\pi$$

取 $k=0$，区间 $\left[-\dfrac{3\pi}{8},\ \dfrac{\pi}{8}\right]$ 与 $\left[0,\dfrac{\pi}{2}\right]$ 取交集得 $\left[0,\dfrac{\pi}{8}\right]$；
取 $k=1$，区间 $\left[\dfrac{5\pi}{8},\dfrac{9\pi}{8}\right]$ 与 $\left[0,\dfrac{\pi}{2}\right]$ 无交集。

**答**：单调递增区间为 $\left[0,\dfrac{\pi}{8}\right]$。

### 三、核心原则（原文总结·贯穿五大通法）

> 以下 4 条是专项配题原文给出的核心原则，是五大通法的"操作总纲"。

1. **辅助角公式**：$a\sin x + b\cos x = \sqrt{a^2+b^2}\sin(x+\varphi)$，其中 $\tan\varphi = b/a$。
2. **配角法核心**：$\alpha = (\alpha+\beta) - \beta$；$\ 2\alpha = (\alpha+\beta) + (\alpha-\beta)$。
3. **齐次式弦化切**：分子分母同除以 $\cos^2 x$（或 $\cos x$）。
4. **三角方程通法**：化简 $\rightarrow$ 解基本方程 $\rightarrow$ 回代求 $x$ $\rightarrow$ 结合定义域筛选。

> **变形策略补充（"目标"视角）**：统一名称（化同名同角）、统一角（配角凑已知角）、统一次数（二倍角升降幂）、"1"的代换（$\sin^2 x+\cos^2 x=1$）。前 4 条是"怎么操作"，这 4 条是"朝什么方向变形"，二者互为表里。

## 备注

- **三角大题化简的标准流水线**：诱导公式 → 和差/倍角展开 → 降幂 → 辅助角公式 → $A\sin(\omega x+\varphi)$ 标准型 → 读性质。
- **易错点**：
  - 辅助角公式 $\tan\varphi = b/a$，$\varphi$ 的象限由 $a,b$ **共同**决定，不能只看比值。
  - 配角前**必须**判断角的范围（如 $\alpha+\beta$ 是否落在第几象限），否则符号会错。
  - 弦化切前**先验证** $\cos x \neq 0$（或 $\sin x \neq 0$）。
  - 三角方程求解别忘**通解 + 区间筛选**两步，缺一不可。
- **广东卷考法**：三角大题第一问常考"化简→求周期/单调区间/最值"（题型一/题型五），第二问接解三角形；填空/选择里则可能单独考配角（题型二）或齐次化（题型三）。
- **训练建议**：把"速查卡"那张表打印贴在书桌前，做题时强迫自己先过一遍"看到什么→想什么→用什么"再动手。

<summary>▶ 第1题详解（辅助角公式 + 综合降次）</summary>

$f(x) = \sin^2 x - \dfrac{\sqrt{3}}{2}\sin 2x$。

降幂：$\sin^2 x = \dfrac{1-\cos 2x}{2}$，故
$$f(x) = \dfrac{1-\cos 2x}{2} - \dfrac{\sqrt{3}}{2}\sin 2x = \dfrac{1}{2} - \left(\dfrac{1}{2}\cos 2x + \dfrac{\sqrt{3}}{2}\sin 2x\right)$$

对括号内用辅助角公式（$\sqrt{(1/2)^2+(\sqrt{3}/2)^2}=1$）：
$$\dfrac{1}{2}\cos 2x + \dfrac{\sqrt{3}}{2}\sin 2x = \sin\!\left(2x + \dfrac{\pi}{6}\right)$$

故 $f(x) = \dfrac{1}{2} - \sin\!\left(2x + \dfrac{\pi}{6}\right)$。

(1) 当 $\sin\!\left(2x+\dfrac{\pi}{6}\right) = -1$ 时 $f(x)$ 取最大值 $\dfrac{1}{2}-(-1) = \dfrac{3}{2}$；最小正周期 $T = \dfrac{2\pi}{2} = \pi$。

(2) $f(x)$ 递增 $\Leftrightarrow \sin\!\left(2x+\dfrac{\pi}{6}\right)$ 递减 $\Leftrightarrow \dfrac{\pi}{2}+2k\pi \le 2x+\dfrac{\pi}{6} \le \dfrac{3\pi}{2}+2k\pi$，解得 $\dfrac{\pi}{6}+k\pi \le 2x \le \dfrac{4\pi}{3}+k\pi$，即 $\dfrac{\pi}{12}+k\pi \le x \le \dfrac{2\pi}{3}+k\pi,\ k\in\mathbb{Z}$。

**答**：(1) 最大值 $\dfrac{3}{2}$，最小正周期 $\pi$；(2) 单调递增区间 $\left[\dfrac{\pi}{12}+k\pi,\ \dfrac{2\pi}{3}+k\pi\right],\ k\in\mathbb{Z}$。

> **易错提醒**：$f(x)=\dfrac{1}{2}-\sin(\cdot)$ 是**减**复合，递增区间对应 $\sin$ 的递减区间，符号方向别搞反——这是本题最大陷阱。

</details>

<details>
<summary>▶ 第2题详解（配角法）</summary>

$\alpha$ 锐角，$\cos\alpha = \dfrac{3}{5}$，故 $\sin\alpha = \sqrt{1-\left(\dfrac{3}{5}\right)^2} = \dfrac{4}{5}$。

$\alpha,\beta$ 均锐角 $\Rightarrow 0 < \alpha+\beta < \pi$；又 $\cos(\alpha+\beta) = -\dfrac{5}{13} < 0$，故 $\dfrac{\pi}{2} < \alpha+\beta < \pi$，于是 $\sin(\alpha+\beta) = \sqrt{1-\left(-\dfrac{5}{13}\right)^2} = \dfrac{12}{13}$。

配角：$\beta = (\alpha+\beta) - \alpha$，
$$\begin{aligned}
\cos\beta &= \cos[(\alpha+\beta)-\alpha] \\
&= \cos(\alpha+\beta)\cos\alpha + \sin(\alpha+\beta)\sin\alpha \\
&= \left(-\dfrac{5}{13}\right)\!\cdot\!\dfrac{3}{5} + \dfrac{12}{13}\!\cdot\!\dfrac{4}{5} \\
&= -\dfrac{15}{65} + \dfrac{48}{65} = \dfrac{33}{65}
\end{aligned}$$

**答**：$\cos\beta = \dfrac{33}{65}$。

> **易错提醒**：必须先由 $\cos(\alpha+\beta)<0$ 判定 $\alpha+\beta \in (\pi/2, \pi)$，$\sin(\alpha+\beta)$ 取正；不判范围直接开方，符号会错。

</details>

<details>
<summary>▶ 第3题详解（齐次化 + 三角方程）</summary>

**(1)** 分子分母同除以 $\cos x$（$\tan x = 2$ 已隐含 $\cos x \ne 0$）：
$$\dfrac{\sin x + \cos x}{\sin x - \cos x} = \dfrac{\tan x + 1}{\tan x - 1} = \dfrac{2+1}{2-1} = 3$$

**答**：值为 $3$。

> **易错提醒**：弦化切前要确认 $\cos x \ne 0$；本题 $\tan x = 2$ 有定义已隐含此条件，可直接除。

**(2)** 用辅助角公式：$\sin x + \cos x = \sqrt{2}\sin\!\left(x+\dfrac{\pi}{4}\right) = \sqrt{2}$，即 $\sin\!\left(x+\dfrac{\pi}{4}\right) = 1$。

令 $\theta = x+\dfrac{\pi}{4}$，则 $\theta = \dfrac{\pi}{2}+2k\pi$，即 $x = \dfrac{\pi}{4}+2k\pi\ (k\in\mathbb{Z})$。

在 $[0, 2\pi]$ 内：$k=0 \Rightarrow x=\dfrac{\pi}{4}$（在区间内）；$k=-1 \Rightarrow x=-\dfrac{7\pi}{4}$（不在）；$k=1 \Rightarrow x=\dfrac{9\pi}{4}$（不在）。

**答**：$x = \dfrac{\pi}{4}$。

> **易错提醒**：三角方程务必**通解 + 区间筛选**两步齐走；只写 $x=\pi/4$ 而不验证 $k=\pm1$ 是否落入区间，是常见扣分点。

</details>
