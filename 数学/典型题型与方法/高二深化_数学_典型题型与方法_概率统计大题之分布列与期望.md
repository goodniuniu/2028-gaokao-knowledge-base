## 核心内容

### 题型识别标志
> **看到什么条件 → 立刻想到什么方法**

| 题干关键条件 | 识别为 | 首选方法 |
|-------------|--------|----------|
| "每次由其中一人投篮/抽奖，命中则继续、不中则换人" | 马尔可夫链 | 设 aₙ=P(第n次状态)，建递推 |
| "第n次处于某状态的概率" | 递推数列 | aₙ = p·aₙ₋₁ + q·(1-aₙ₋₁) 构造等比 |
| "已知 Xi 两点分布，E(ΣXi)=Σqi" | 期望线性性 | 直接求和 Σaᵢ |
| 随机变量取值为 0/1（是否发生） | 两点分布 | 用指示变量把计数转化为 ΣXi |
| 多个互斥状态转移 | 全概率公式 | 按上一状态分类 |

### 解题路径（概率递推大题四步法）
#### 第一步：建模设变量
设 aₙ = "第 n 次处于目标状态"的概率，写出 a₁（初始概率）。
#### 第二步：建递推
用全概率：aₙ = P(本状态命中留)+P(他状态未中换)，化为 aₙ = p·aₙ₋₁ + q（一阶线性递推）。
#### 第三步：求通项
构造常数列 aₙ + c = k(aₙ₋₁ + c) 化为等比，得 aₙ = A·k^(n-1) + B。
#### 第四步：算期望
利用两点分布期望线性性 E(Y) = Σaᵢ，分组（等比求和+常数求和）得结果。

### 母题（2023 新课标Ⅰ卷·第21题，12分）
**题目**：甲、乙两人投篮，每次由其中一人投篮，规则：若命中则此人继续，若未命中则换对方。甲命中率0.6，乙命中率0.8，第一次由抽签决定，甲、乙各0.5。
(1) 求第2次投篮的人是乙的概率；
(2) 求第 i 次投篮的人是甲的概率；
(3) 记前 n 次中甲投篮次数为 Y（Xi 为两点分布、P(Xi=1)=aᵢ），求 E(Y)。

**解析**：
(1) P(第2次是乙) = P(甲先投且未中) + P(乙先投且命中) = 0.5×0.4 + 0.5×0.8 = 0.6 = **3/5**。
(2) 设 aᵢ = P(第i次甲投)，则 aᵢ = 0.6·aᵢ₋₁ + 0.2·(1-aᵢ₋₁) = (2/5)aᵢ₋₁ + 1/5（i≥2），a₁=1/2。
构造：aᵢ - 1/3 = (2/5)(aᵢ₋₁ - 1/3)，故 {aᵢ-1/3} 是首项 1/6、公比 2/5 的等比，
得 **aᵢ = (1/6)(2/5)^(i-1) + 1/3**。
(3) 由两点分布期望线性性，E(Y) = Σ₁ⁿ aᵢ = Σ₁ⁿ[(1/6)(2/5)^(i-1) + 1/3]
= (1/6)·[1-(2/5)ⁿ]/(1-2/5) + n/3 = **n/3 + 5/18 - (1/9)(2/5)^(n-1)**。

**关键提炼**：马尔可夫链本质是一阶线性递推数列；期望用"指示变量+线性性"一步到位，避免逐一列分布列。

**第1题**（检验 第一步·建递推 + 第三步·构造等比求通项）

甲、乙两人传球，第 1 次球在甲手中。每次持球者以概率 $\dfrac{1}{3}$ 将球传给对方，以概率 $\dfrac{2}{3}$ 自己保留。设 $a_n$ 为第 $n$ 次球在甲手中的概率（$n\ge1$）。
(1) 求 $a_1$、$a_2$ 的值；
(2) 写出 $\{a_n\}$ 的递推关系，并求 $a_n$ 的通项公式。

**第2题**（检验 第四步·两点分布 + 期望线性性）

一个袋子中有 3 个红球、2 个白球，每次从中不放回地取一个球，取到红球记 $X_i=1$，取到白球记 $X_i=0$，共取 3 次。设 $Y=X_1+X_2+X_3$ 为取出的红球总数，用期望线性性求 $E(Y)$。

**第3题**（检验 马尔可夫链全流程：建递推→求通项→算期望）

甲、乙两人投篮，每次由其中一人投篮，规则：若命中则此人继续投，若未命中则换对方。甲命中率 $\dfrac{3}{4}$，乙命中率 $\dfrac{1}{2}$，第一次由甲投篮。设 $a_i$ 为第 $i$ 次由甲投篮的概率（$i=1,2,\ldots$），记前 $n$ 次中甲投篮次数为 $Y=\sum_{i=1}^{n}X_i$（$X_i$ 服从两点分布，$P(X_i=1)=a_i$）。
(1) 求 $a_i$ 的通项公式；
(2) 求 $E(Y)$。

## 参考答案（请先独立完成自测训练，再展开核对）

> 答案与题目分板块呈现，便于"先做后对"。每题给出规范解答 + 易错提醒，做完一题对一题。

<details>
<summary>▶ 第1题详解（建递推 + 构造等比求通项）</summary>

**(1)** 第 1 次球在甲手中：$a_1=1$。

第 2 次球在甲手中 $\Leftrightarrow$ 第 1 次甲持球且甲保留（概率 $\dfrac{2}{3}$），故 $a_2=\dfrac{2}{3}$。

$$\boxed{a_1=1,\quad a_2=\frac{2}{3}}$$

**(2)** 第 $n$ 次球在甲手中 $\Leftrightarrow$ 第 $n-1$ 次甲持球且保留，或第 $n-1$ 次乙持球且传给甲：
$$a_n = \frac{2}{3}\,a_{n-1}+\frac{1}{3}(1-a_{n-1})=\frac{1}{3}\,a_{n-1}+\frac{1}{3}\quad(n\ge2)$$

设 $a_n+c=\dfrac{1}{3}(a_{n-1}+c)$，解 $c=\dfrac{1/3}{1-1/3}=\dfrac{1}{2}$，即 $\left\{a_n-\dfrac{1}{2}\right\}$ 是首项 $a_1-\dfrac{1}{2}=\dfrac{1}{2}$、公比 $\dfrac{1}{3}$ 的等比数列：
$$a_n-\frac{1}{2}=\frac{1}{2}\!\left(\frac{1}{3}\right)^{\!n-1}\implies\boxed{a_n=\frac{1}{2}+\frac{1}{2}\!\left(\frac{1}{3}\right)^{n-1}=\frac{1}{2}\!\left[1+\left(\frac{1}{3}\right)^{n-1}\right]}$$

验证：$n=1$ 时 $a_1=\dfrac{1}{2}(1+1)=1$ ✓；$n=2$ 时 $a_2=\dfrac{1}{2}\!\left(1+\dfrac{1}{3}\right)=\dfrac{2}{3}$ ✓。

> **易错提醒**：构造辅助数列时 $c=\dfrac{q}{1-p}$（$p=1/3$，$q=1/3$），公式别记反成 $\dfrac{q}{p-1}$。

</details>

<details>
<summary>▶ 第2题详解（两点分布 + 期望线性性）</summary>

每次取球时，第 $i$ 次取到红球记 $X_i=1$。虽然不放回导致各 $X_i$ 不独立，但期望线性性不要求独立：$E(Y)=E(X_1)+E(X_2)+E(X_3)$。

第 1 次取到红球概率：$P(X_1=1)=\dfrac{3}{5}$。

第 2 次取到红球概率（对称性，5 球排列中每个位置等可能出现红球）：
$$P(X_2=1)=\frac{3}{5}$$

第 3 次同理：$P(X_3=1)=\dfrac{3}{5}$。

因此
$$E(Y)=\sum_{i=1}^{3}E(X_i)=\frac{3}{5}+\frac{3}{5}+\frac{3}{5}=\boxed{\frac{9}{5}}$$

> **易错提醒**：不放回抽样时各 $X_i$ 不独立，但**期望线性性无需独立性**，$E(\sum X_i)=\sum E(X_i)$ 恒成立。逐次算 $P(X_i=1)$ 用对称性最方便。

</details>

<details>
<summary>▶ 第3题详解（马尔可夫链全流程：建递推→求通项→算期望）</summary>

**(1)** 第 $i$ 次甲投篮 $\Leftrightarrow$ 第 $i-1$ 次甲投且甲命中（留），或第 $i-1$ 次乙投且乙未命中（换甲）：
$$a_i=\frac{3}{4}\,a_{i-1}+\frac{1}{2}(1-a_{i-1})=\frac{1}{4}\,a_{i-1}+\frac{1}{2}\quad(i\ge2),\qquad a_1=1$$

构造：设 $a_i+c=\dfrac{1}{4}(a_{i-1}+c)$，解 $c=\dfrac{1/2}{1-1/4}=\dfrac{2}{3}$，即 $\left\{a_i-\dfrac{2}{3}\right\}$ 是首项 $a_1-\dfrac{2}{3}=\dfrac{1}{3}$、公比 $\dfrac{1}{4}$ 的等比数列：
$$\boxed{a_i=\frac{2}{3}+\frac{1}{3}\!\left(\frac{1}{4}\right)^{i-1}}$$

**(2)** 由期望线性性：
$$\begin{aligned}
E(Y)&=\sum_{i=1}^{n}a_i=\sum_{i=1}^{n}\!\left[\frac{2}{3}+\frac{1}{3}\!\left(\frac{1}{4}\right)^{i-1}\right] \\
&=\frac{2n}{3}+\frac{1}{3}\cdot\frac{1-\left(\frac{1}{4}\right)^{n}}{1-\frac{1}{4}} \\
&=\frac{2n}{3}+\frac{1}{3}\cdot\frac{4}{3}\!\left[1-\left(\frac{1}{4}\right)^{n}\right]
\end{aligned}$$
$$\boxed{E(Y)=\frac{2n}{3}+\frac{4}{9}\!\left[1-\left(\frac{1}{4}\right)^{n}\right]}$$

> **易错提醒**：求和时把常数项 $\dfrac{2}{3}$ 和等比项 $\dfrac{1}{3}\!\left(\frac{1}{4}\right)^{i-1}$ 分别求和，等比求和公式别漏除以 $1-\dfrac{1}{4}$。

</details>
