【卡片标题】数列放缩与不等式证明

⚠️待强化★★★★☆#高二深化#新高考Ⅰ卷·广东来源：专题归纳 / 2022新课标Ⅰ卷·第17题
广东考情：高频（新高考Ⅰ卷数列题常考）· 基础 · 累乘法求通项+裂项相消+末项正数放缩 · 真题锚定：2022新高考Ⅰ卷T17（数列放缩/裂项）

核心内容

题型识别标志

看到什么条件 → 立刻想到什么方法

题干关键条件识别为首选方法
"证明 1/a₁+1/a₂+…+1/aₙ < C（C为整数）"放缩证明裂项相消后整体放缩
"{Sₙ/aₙ} 是等差数列" / "{naₙ}等差"累乘法求通项用 Sₙ-Sₙ₋₁ 构造 aₙ/aₙ₋₁ 比，累乘
通项为 n(n+1)/2、n² 等二次型1/aₙ 可裂项1/aₙ = 常数·(1/f(n)-1/f(n+1))
出现 1/[n(n+1)]、1/[n(n+k)]标准裂项1/[n(n+k)] = (1/k)(1/n - 1/(n+k))
要证 Σ < C 但逐项求和发散放缩后再裂项先放缩通项再求和

解题路径（数列放缩证明四步法）

第一步：求通项

由题干递推/和项关系，用累乘法、构造常数列或待定系数求出 aₙ 的显式。广东卷第17题几乎必考"和项关系→累乘法"。

第二步：裂项变形

将 1/aₙ 写成常数×(1/f(n) - 1/f(n+1)) 的形式。关键是配出"后项减前项"的分母结构。

第三步：求和并放缩

Σ1/aₙ = 常数×(首项 - 末项)。因末项 >0，故 Σ < 常数×首项 = 目标上界 C。

第四步：验证严格不等

说明等号无法取到（n 有限时末项 >0），即得严格小于。若问"≤"则补 n→∞ 极限情形。

母题（2022 新课标Ⅰ卷·第17题，10分）

题目：记 Sₙ 为数列 {aₙ} 的前 n 项和，已知 a₁=1，{Sₙ/aₙ} 是公差为 1/3 的等差数列。 (1) 求 {aₙ} 的通项公式； (2) 证明：1/a₁ + 1/a₂ + … + 1/aₙ < 2。

解析： (1) 由题 Sₙ/aₙ = 1 + (n-1)·(1/3) = (n+2)/3，故 Sₙ = (n+2)aₙ/3。 当 n≥2 时 Sₙ₋₁ = (n+1)aₙ₋₁/3，两式相减得 aₙ = (n+2)aₙ/3 - (n+1)aₙ₋₁/3， 整理：(n-1)aₙ = (n+1)aₙ₋₁，即 aₙ/aₙ₋₁ = (n+1)/(n-1)。 累乘：aₙ/a₁ = [(n+1)/(n-1)]·[n/(n-2)]·…·(3/1) = n(n+1)/2，又 a₁=1，故 aₙ = n(n+1)/2（首项也满足）。 (2) 1/aₙ = 2/[n(n+1)] = 2(1/n - 1/(n+1))， Σ₁ⁿ 1/aₖ = 2[(1-1/2)+(1/2-1/3)+…+(1/n-1/(n+1))] = 2(1 - 1/(n+1)) < 2。证毕。

关键提炼：和项关系→累乘法求通项是广东卷数列第一问的固定套路；第二问"裂项相消+末项正数放缩"是放缩证明题的标准模板。

自测训练（3道·覆盖累乘法求通项 + 裂项放缩证明）

先独立完成，再展开卡片末尾「参考答案」核对。每题标注所检验的题型，方便对号查漏。

第1题（检验 第一步·累乘法求通项 + 第二步·标准裂项）

已知数列 $\{a_n\}$ 的前 $n$ 项和为 $S_n$，$a_1=1$，且 $\dfrac{S_n}{a_n} = \dfrac{n+2}{3}$（$n\ge1$）。 (1) 求 $\{a_n\}$ 的通项公式； (2) 设 $b_n = \dfrac{1}{a_n}$，求 $T_n = b_1 + b_2 + \cdots + b_n$ 的表达式。

第2题（检验 第三步·求和并放缩 + 第四步·验证严格不等）

已知数列 $\{a_n\}$ 满足 $a_n = n(n+1)$，$n\ge1$。 (1) 求 $\dfrac{1}{a_1} + \dfrac{1}{a_2} + \cdots + \dfrac{1}{a_n}$ 的表达式； (2) 证明：$\dfrac{1}{a_1} + \dfrac{1}{a_2} + \cdots + \dfrac{1}{a_n} < 1$。

第3题（检验 先放缩通项再裂项）

已知数列 $\{a_n\}$ 满足 $a_n = n^2$（$n\ge1$），证明： $$\frac{1}{a_1} + \frac{1}{a_2} + \cdots + \frac{1}{a_n} < 2 - \frac{1}{n}, \quad n\ge2.$$

备注

  • 广东卷数列放缩常考「分母二次型通项」，裂项后必剩一项正数，故严格 < 上界。
  • 易错：累乘时漏掉 a₁ 验证首项；裂项系数配错（2/[n(n+1)] 的 2 易丢）。
  • 提速：直接背熟 Σ1/[k(k+1)] = 1 - 1/(n+1)。

参考答案（请先独立完成自测训练，再展开核对）

答案与题目分板块呈现，便于"先做后对"。每题给出规范解答 + 易错提醒，做完一题对一题。

▶ 第1题详解（累乘法求通项 + 标准裂项）

(1) 由 $\dfrac{S_n}{a_n} = \dfrac{n+2}{3}$，得 $S_n = \dfrac{(n+2)\,a_n}{3}$。

当 $n\ge2$ 时，$S_{n-1} = \dfrac{(n+1)\,a_{n-1}}{3}$，两式相减： $$a_n = \frac{(n+2)\,a_n}{3} - \frac{(n+1)\,a_{n-1}}{3}$$ $$3\,a_n = (n+2)\,a_n - (n+1)\,a_{n-1} \implies (n-1)\,a_n = (n+1)\,a_{n-1}$$ $$\therefore\ \frac{a_n}{a_{n-1}} = \frac{n+1}{n-1} \quad (n\ge2)$$

累乘： $$\frac{a_n}{a_1} = \frac{3}{1}\cdot\frac{4}{2}\cdot\frac{5}{3}\cdots\frac{n+1}{n-1} = \frac{n(n+1)}{2}$$

又 $a_1=1$ 满足，故 $\boxed{a_n = \dfrac{n(n+1)}{2}}$。

(2) $b_n = \dfrac{1}{a_n} = \dfrac{2}{n(n+1)} = 2\!\left(\dfrac{1}{n}-\dfrac{1}{n+1}\right)$，

$$T_n = 2\!\left[\left(1-\dfrac{1}{2}\right)+\left(\dfrac{1}{2}-\dfrac{1}{3}\right)+\cdots+\left(\dfrac{1}{n}-\dfrac{1}{n+1}\right)\right] = 2\!\left(1-\dfrac{1}{n+1}\right) = \boxed{\dfrac{2n}{n+1}}$$

易错提醒：累乘后务必把 $n=1$ 代入验证首项是否满足；若不满足需写成分段形式。

▶ 第2题详解（裂项相消 + 末项正数放缩）

(1) $\dfrac{1}{a_k} = \dfrac{1}{k(k+1)} = \dfrac{1}{k}-\dfrac{1}{k+1}$，

$$\sum_{k=1}^{n}\frac{1}{a_k} = \left(1-\frac{1}{2}\right)+\left(\frac{1}{2}-\frac{1}{3}\right)+\cdots+\left(\frac{1}{n}-\frac{1}{n+1}\right) = 1-\frac{1}{n+1} = \boxed{\frac{n}{n+1}}$$

(2) 由(1)已得 $\dfrac{1}{a_1}+\cdots+\dfrac{1}{a_n} = \dfrac{n}{n+1}$。

因 $\dfrac{1}{n+1}>0$，故 $\dfrac{n}{n+1} = 1-\dfrac{1}{n+1} < 1$。$\boxed{\text{证毕}}$

易错提醒：第(2)问的本质是"裂项后剩下一项正数"，由此保证严格不等。若问 $\le$ 则取极限 $n\to\infty$ 时等号成立。

▶ 第3题详解（先放缩通项再裂项求和）

关键放缩：当 $n\ge2$ 时，$n^2 > n(n-1)$，故 $$\frac{1}{n^2} < \frac{1}{n(n-1)} = \frac{1}{n-1}-\frac{1}{n}$$

而 $\dfrac{1}{a_1} = \dfrac{1}{1^2} = 1$，直接保留。

因此 $$\sum_{k=1}^{n}\frac{1}{k^2} = 1+\sum_{k=2}^{n}\frac{1}{k^2} < 1+\sum_{k=2}^{n}\left(\frac{1}{k-1}-\frac{1}{k}\right) = 1+\left(1-\frac{1}{n}\right) = 2-\frac{1}{n}$$

$\boxed{\text{证毕}}$

易错提醒：放缩方向是"分母变小、分数变大"，即 $\dfrac{1}{n^2}<\dfrac{1}{n(n-1)}$；方向搞反会得到 $>$。另外首项 $k=1$ 时 $n(n-1)=0$ 无意义，必须单独处理。
