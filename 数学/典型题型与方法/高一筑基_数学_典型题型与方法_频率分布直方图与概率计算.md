## 核心内容

> **本质理解**：频率分布直方图是"用样本的频率分布估计总体的概率分布"的可视化工具。核心操作：读图→算频率→估概率→求复合事件概率。

---

### 一、大题标准解题模板（五步式）

#### 第1步：求直方图参数（如$a$的值）

**原理**：所有矩形面积之和 = 1

**标准写法**：
```
由频率分布直方图可知，各组频率/组距分别为 [列出已知值]，
组距为 [值]。

∵ 所有矩形面积之和为1
∴ (a_1 + a_2 + ... + a_n) × 组距 = 1
即 [方程]
解得：a = [值]
```

> **广东卷评分要点**：必须写"所有矩形面积之和为1"的理由，不能凭空列方程。

---

#### 第2步：计算频率、频数

**标准写法**：
```
[某组]的频率 = [该组纵坐标] × 组距 = [值]
[某组]的频数 = 频率 × 样本容量 = [值] × [样本容量] = [值]
```

---

#### 第3步：计算中位数（高频！）

**标准写法**：
```
设中位数为x。

∵ 中位数左右两侧面积各为0.5
左侧累加面积：[计算过程]
可知中位数落在[第k组]内。

列方程：前(k-1)组面积 + (x - 下限) × 该组纵坐标 = 0.5
即 [方程]
解得：x = [值]

∴ 中位数为 [值]
```

> **关键**：中位数不是最高矩形中点！而是使左右面积各为0.5的横坐标。

---

#### 第4步：计算平均数（或估计总体平均数）

**标准写法**：
```
样本平均数 = Σ(各组中点 × 该组频率)
           = [组1中点]×[组1频率] + [组2中点]×[组2频率] + ...
           = [计算过程]
           = [值]

∴ 估计总体平均数为 [值]
```

> **注意**：用样本平均数估计总体平均数时，必须写"估计"二字。

---

#### 第5步：概率计算（大题第2问核心！）

**标准写法**：
```
由（1）可知，[某事件A]的频率为 [值]。
用频率估计概率，得 P(A) ≈ [值]。

[根据题意，分情况计算]

情况1：...
P(情况1) = ...

情况2：...
P(情况2) = ...

∴ 所求概率 P = P(情况1) + P(情况2) = [值]
```

> **广东卷必写语句**："用频率估计概率"——不写扣1分！

---

### 二、高频概率计算类型

#### 类型1：古典概型（列举法）

**适用**：样本空间小（基本事件数≤20）

**标准步骤**：
1. 设事件："设事件A为..."
2. 列举所有基本事件：用坐标、编号或树状图列出$n(\Omega)$
3. 找出事件A包含的基本事件：列出$n(A)$
4. 计算概率：$P(A) = \frac{n(A)}{n(\Omega)} = \frac{[值]}{[值]}$

> **示例**：从分层抽样的5人中选2人，求恰有1男1女的概率。
> - 设5人为$M_1, M_2, F_1, F_2, F_3$
> - 所有基本事件：$C_5^2 = 10$种
> - 事件A（1男1女）：$2 \times 3 = 6$种
> - $P(A) = \frac{6}{10} = \frac{3}{5}$

---

#### 类型2：独立事件的复合概率

**适用**：多次试验，各次结果互不影响

**公式**：
- $P(A \cap B) = P(A) \cdot P(B)$（A、B独立）
- $P(A \cup B) = P(A) + P(B) - P(A)P(B)$（A、B独立）
- $P(\text{至少一个发生}) = 1 - P(\text{都不发生}) = 1 - P(\bar{A})P(\bar{B})$

> **广东卷高频**："至少有一人合格""至少有一次成功"——用对立事件$1 - P(\text{全不合格})$。

---

#### 类型3：条件概率（高一拓展）

**公式**：$P(B|A) = \frac{P(A \cap B)}{P(A)}$（$P(A) > 0$）

**缩小样本空间法**：$P(B|A) = \frac{n(A \cap B)}{n(A)}$

> **适用场景**：已知某条件发生，求另一事件的概率。如"已知选中的男生，求是优秀生的概率"。

### 三、大题答题规范（广东卷评分细则）

| 项目 | 要求 | 分值 | 常见错误 |
|------|------|------|----------|
| **设事件** | 必须设"设事件A为..." | 1分 | 不设事件，直接写$P = ...$ |
| **列总数** | 写明样本空间总数$n(\Omega) = ...$ | 1分 | 不写总数，直接写概率 |
| **列事件数** | 写明事件包含的基本事件数$n(A) = ...$ | 1分 | 不写事件数 |
| **写公式** | $P(A) = \frac{n(A)}{n(\Omega)}$ | 1分 | 直接写结果 |
| **计算结果** | 分数或小数（保留要求） | 1分 | 计算错误 |
| **统计语句** | "用频率估计概率" | 1分 | 不写此句 |

> **广东卷评分要点**：统计大题共12-14分，概率计算部分通常占6-8分。按上述规范书写，可确保不丢步骤分。

---

### 四、高频易错点速查

| 易错点 | 正确做法 | 错误示例 |
|--------|----------|----------|
| **混淆频率与频率/组距** | 频率 = 纵坐标 × 组距 | 直接把纵坐标当频率 |
| **中位数计算错误** | 中位数是面积平分点，不是最高矩形中点 | 取最高矩形中点横坐标 |
| **平均数用组端点** | 平均数用组中点，不是组端点 | 用组下限或上限 |
| **概率语句不写** | 必须写"用频率估计概率" | 直接写$P = 0.3$ |
| **互斥与独立混淆** | 互斥用加法，独立用乘法 | 互斥事件直接相乘 |
| **"至少"问题直接算** | 正难则反，用$1 - P(\text{对立})$ | 逐个情况相加，漏算 |

<details>
<summary>▶ 第1题详解（直方图参数·面积之和为1）</summary>

组距 $d=10$。所有矩形面积之和为 $1$，即各组频率之和为 $1$。

各组频率：
- $[50,60)$：$0.010\times 10=0.10$
- $[60,70)$：$0.020\times 10=0.20$
- $[70,80)$：$a\times 10=10a$
- $[80,90)$：$0.015\times 10=0.15$
- $[90,100]$：$0.005\times 10=0.05$

由 $0.10+0.20+10a+0.15+0.05=1$，得 $10a=0.50$，故 $a=0.050$。

$[70,80)$ 组频数 $= 10a\times 100 = 0.50\times 100 = 50$。

**答**：$a=0.050$，该组频数为 $50$。

> **易错提醒**：①必须显式写出"所有矩形面积之和为 $1$"作为列方程的依据（广东卷评分要点）；②频率 $=$ 频率/组距 $\times$ 组距，不要把纵坐标当频率。

</details>

<details>
<summary>▶ 第2题详解（中位数·面积平分）</summary>

中位数 $x$ 使其左右两侧面积各为 $0.5$。

左侧累计频率（从小到大）：
- $[50,60)$：$0.10$
- $[60,70)$：$0.20$
- 累计到 $[70,80)$ 前：$0.10+0.20=0.30<0.5$，故中位数落在 $[70,80)$ 组内。

设中位数为 $x\in[70,80)$，则左侧累计面积为：
$$0.30+(x-70)\times 0.050 = 0.5$$
$$(x-70)\times 0.050 = 0.20$$
$$x-70 = 4.0，\quad x=74.0$$

**答**：中位数为 $74.0$ 分。

> **易错提醒**：中位数**不是**最高矩形的中点，而是使左右面积各为 $0.5$ 的横坐标。必须先确定中位数落在哪一组，再列方程求解。

</details>

<details>
<summary>▶ 第3题详解（分层抽样 + 古典概型）</summary>

$[80,90)$ 组频率 $0.15$，频数 $15$；$[90,100]$ 组频率 $0.05$，频数 $5$。两组总人数 $20$ 人。

**分层抽样**（按 $15:5=3:1$ 的比例）：从 $20$ 人中抽 $5$ 人，则
- $[80,90)$ 组抽 $5\times\dfrac{15}{20}=\dfrac{15}{4}=3.75$——

——题目给定抽 $5$ 人，比例 $15:5=3:1$，故 $[80,90)$ 组抽 $4$ 人、$[90,100]$ 组抽 $1$ 人。（取整后校验 $4+1=5$ ✓）

**古典概型**：设事件 $A=$ "选出的 $2$ 人都来自 $[80,90)$ 组"。

- 样本空间总数：$n(\Omega)=\dbinom{5}{2}=\dfrac{5\times 4}{2}=10$；
- 事件 $A$ 包含的基本事件数：$n(A)=\dbinom{4}{2}=\dfrac{4\times 3}{2}=6$；
- $P(A)=\dfrac{n(A)}{n(\Omega)}=\dfrac{6}{10}=\dfrac{3}{5}$。

**答**：选出的 $2$ 人都来自 $[80,90)$ 组的概率为 $\dfrac{3}{5}$。

> **易错提醒**：①分层抽样要按比例分配，先确定两组各抽几人；②古典概型必须**设事件**、**列总数**、**列事件数**、**套公式**——四步缺一扣分；③"用频率估计概率"的统计语句在本题中不适用（本题是抽样后纯古典概型），但若是"从总体中任取"则必须写。

</details>
